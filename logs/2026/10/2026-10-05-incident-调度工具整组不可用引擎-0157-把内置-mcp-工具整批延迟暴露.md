# 调度工具整组不可用：引擎 0.157 把内置 MCP 工具整批「延迟暴露」

## 背景
用户 10-04 报「调度工具用不了」。截图里 `expert_list` 与 `agent_invoke` 双双
`unsupported call`（会话 `01a1078e`，模型 `cn:space-bunny`）。而宿主的调度开关是开着的、
会话里还挂着「【调度已开启】…可派对象：知微…」的告知 —— 看起来像"开关开着、工具却坏了"。

## 结论
不是开关坏了，是**引擎改了工具面策略**：`@openai/codex` 0.157 起，内置 MCP server 的工具**整批延迟暴露**
（不再出现在发给模型的工具清单里），`codex features list` 里 `tool_search_always_defer_mcp_tools` 已是
**`removed / true`** —— 这是永久默认，不会自己变回来。⇒ 「只走内置 MCP」的能力对模型**全不可达**。
唯一可见通道 = 宿主在 `thread/start` / `thread/resume` 注册的 **dynamicTools**。

## 依据
- 截获引擎**真实请求体**（独立 `CODEX_HOME` + mock provider）：`input[0].additional_tools` 只有
  3 组 11 个内置工具（`functions` / `clock` / `collaboration`），`agent_invoke` 出现 **0 次**；
  `functions.exec` 的说明自己写着 deferred 工具 "…listed in `ALL_TOOLS`"。
- 裸名与 `mcp__harness-dispatch__expert_list` 都是 `unsupported call`（`tool_source="direct"`）。
- MCP 服务端本身没坏：隔离实例 `initialize 200` + `tools/list 200`（21 个工具）；
  引擎 `mcpServer/startupStatus` = `ready`、`error: null`；全天 `built MCP tool list` 日志只有 1 条
  （北京 17:25:11，由宿主的 `mcpServerStatus/list` 触发），失败窗口里 0 条。
- 反向验证：同一套 app-server 握手（`initialize` + `initialized` → `thread/start{dynamicTools}`）注册后，
  `agent_invoke` **非延迟**出现在 `functions.exec` 的描述里（带完整签名），模型调用后引擎以
  `item/tool/call {tool:"agent_invoke", arguments}` 发回客户端执行。

## 影响面
- 修法（`9b98341`）：`part08/01-seg.tsx` 注册 `agent_invoke` / `agent_archive_sessions`；
  `part05/.../02-request.tsx` 把 `item/tool/call` 分发到**现有 IPC**（`agents:invoke` →
  `runDelegatedTask` / `agents:archive`）⇒ 与内置 MCP 走**同一个权限闸**，约束一条没丢。
- ⛔ 注册**刻意不带运行态开关条件**：dynamicTools 只在 `thread/start` / `resume` 生效，
  按开关注册会让"中途打开调度"不重建工具面（正是用户报的第二个症状）。
- ⛔ **已存在的会话不会自动拿到新工具面**，必须重开 / 切走再切回一次。这条只能由用户验证。
- 其余内置 MCP 工具（`scheduler_*` / `knowledge_*` / `ui_component_*` / `video_*` / `workflow_*` /
  `voice_generate` / `expert_list` / `expert_save` / `subagent_save` / `connector_register`）
  **仍不可达**；要恢复得同样镜像成 dynamicTools，且 `dispatchRpcCall` 还需补一条显式 `callerThreadId`
  入参（它现在的身份证据来自**只有 MCP 路径才有**的 `dispatchProbes`）。属未开工欠账，改前先问用户。

## 回滚
还原 `part08/01-seg.tsx` 的两个工具注册与 `02-request.tsx` 的两个分发分支（守卫 11f ⑦段与 04 会红）。
