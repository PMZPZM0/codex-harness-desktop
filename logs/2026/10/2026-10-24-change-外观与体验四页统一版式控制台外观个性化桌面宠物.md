# 外观与体验四页统一版式（控制台/外观/个性化/桌面宠物）

## 背景
用户 10-24 截图圈出设置侧栏「外观与体验」四项：
「对应的界面都优化布局和展示顺序，方便小白快速上手，卡片做好看一点」。

## 结论
- 四页共用 `SettingsPageHero`（图标 + 标题 + 一句话说明 + 新手提示）与 `SettingsGroupHead`
  （常用 / 对话与显示 / 维护与更新 等分组），统一卡片皮肤（圆角 16、渐变底、图标胶囊、悬停）。
- 控制台：权限 → 工作区 → 启动行为 → 对话与显示 → 维护与更新；自动更新移到最后。
- 外观：基础外观（主题 + 字号）→ 功能入口 → 更多外观（壁纸 / 代码高亮 / 开机动画），
  全部收成卡片；壁纸提前到代码/开机动画之前。
- 个性化：语气自适应插到回复风格之后；自定义指令与校验归「进阶」。
- 桌面宠物：显示 + 选择宠物优先；目录 / 导入 / 自制教程收进「高级」折叠；
  宠物选择卡放大、当前宠物有高亮环。
- 只改版式与展示顺序，所有控件、类名与行为保留（验收/守卫依赖它们）。

## 依据
- `npm run check` 退出码 0（含 CSS 类覆盖与 31 页设置页）。
- 验收 `settings-pages` 2/2（31 页逐页打开无 ErrorBoundary）、`boot-intro` 8/8。
- 截图：`.e2e-artifacts/shots/01-exp-控制台.png` 等四张（探针已删）。

## 影响面
- 四页的视觉层级、卡片间距、分组顺序；不影响数据与 IPC。
- 桌面宠物的目录/自制说明默认折叠（点「高级」展开），功能仍在。
- 个性化页的渲染由两段改成 `PersonalizationPage` + `adaptiveToneSlot`（语气自适应插在风格后）。
