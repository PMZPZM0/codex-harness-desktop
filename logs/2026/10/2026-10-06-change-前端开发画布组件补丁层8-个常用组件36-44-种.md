# 前端开发画布：组件补丁层（8 个常用组件，36 → 44 种）

## 背景
- 用户（10-06，附组件面板截图）：「3800个组件你从中调一些常用的组件做成图里面这些组件啊，现在默认组件太少」。
- 关键约束：组件面板与 kind 体系**写死在上游 m3e-canvas 产物里**，加组件必须改上游源码再重新构建 —— 官方产物"照原样嵌"的既定立场被用户指令覆盖。

## 结论
- 画布升级为**「上游钉死提交 + 本仓补丁层」**：`scripts/sketch-fork/build.mjs`（克隆上游到 .workbuddy/tmp，源码**不进仓** → checkout PIN `039ec31` → 拷 overlay → **29 处锚点唯一的定点补丁** → `next build` → 出货一条龙）；产物出处记进 `public/sketch/CANVAS-BUILD.json` 的 `fork` 字段（repo / pin / 补丁清单 / 时间）。
- 新增 **8 个常用组件**（从 3800 组件库挑的常用类型，全部与现有 36 种同级：可拖放、可检视、可连导航、进提示词、进校验）：`avatar` 头像 / `skeleton` 骨架屏 / `rating` 评分 / `tooltip` 提示气泡 / `expansionPanel` 展开面板 / `segmentedButton` 分段按钮 / `stepper` 步骤条 / `timeline` 时间线 —— 面板可见、四语文案（KIND_TEXT）、提示词描述与实现说明、检视器字段（文字/条目/分值/宽高）全接。
- 同轮跟到 44 的每一处引用：kind 枚举（sketch-doc.mjs）/ 工具描述列全 / 组件手册技能（表格行 + 数量）/ 常驻指令 / 守卫对账脚本 / 验收探针（加 avatar 真落盘）。
- ⛔ 上游更新流程 = 换 PIN 重跑（锚点失配**当场报红**，不许静默套用）；加组件 = 改 overlay + 补锚点 + 重跑。

## 依据
- **上游自带测试 758/758 全过**（22 个测试文件：i18n parity / prompt / tidy / project 校验 / 快照 —— 新 kinds 在作者自己的严格测试网下也干净）；`next build` 的 TypeScript 全绿（`Record<Kind, KindSpec>` 穷尽约束等）。
- **产物级真跑**：验收 ⑧ —— 探针文档带 `avatar` 写进**真实上游**，load-doc-result ok:true、摘要「2 屏 / 3 部件」；截图里 avatar 渲染成紫色圆「李」、面板「操作」段出现「分段按钮」tile。
- 图标名字逐个对过随包字体清单（material-symbols.json 3903 项）——`expand_more` 不在 Rounded 集里，已换 `expand_circle_down`（这类名字错了会退化成**单词**，是最难发现的假绿同型）。
- 守卫【283】**158 → 162 条**：补丁层来源（CANVAS-BUILD.fork ↔ build.mjs PIN 同源）/ 8 个组件在枚举里 / 产物 chunk 含 8 个中文名 / overlay 在位 + 枚举对账 regex 适配补丁后的 KIND_ORDER；**5 处变异全被抓**（枚举删 avatar / fork 清单删一项 / PIN 改坏 / 描述删 timeline / 技能表删 stepper —— 最后一条**当场暴露弱断言**：技能覆盖原先只判"名字出现过"，散文提一嘴也算 ⇒ 收紧成必须锚表格行 `| \`kind\` |`）。
- 全套：guard 162/162、tsc 0、accept 11/11。⚠️ 提交时点的两处红（【wp】timeline×WallpaperLayer、【32】BootSplash 最短显示阈值）都是并行线刚提交的实现改了写法/在制品，与本轮无关（BootSplash.tsx 在工作区未改 = HEAD 的既有红）。

## 影响面
- 新增 `scripts/sketch-fork/`（build.mjs + extra-kinds.tsx overlay）；`scripts/build-sketch-bundle.mjs`（fork 元数据写入）；**`public/sketch/` 整份产物重建**（4.2MB，含补丁）；`src/features/ui-sketch/sketch-doc.mjs`、`src/features/app-state/parts/part08/01-seg.tsx`、`electron/developer-instructions.ts`、`electron/builtin-skills/20-skill-frontend-canvas.ts` + 中文导读、`scripts/guards/11h-ui-sketch.mjs`、`scripts/accept.mjs`、AGENTS.md / ARCHITECTURE-RULES.md。
- ⛔ 桥与写回通道一行未动；组件库面板保持删除（负向断言未动）；官方 agent.md 只**追加**一节（不删原文）。
