# 表格改成卡片+底部横向滚动（聊天/灯箱/右栏预览通用，自适应）

用户（截图是 WorkBuddy 的宽表格）：「加个类似图片里面的这种格式，汇总消息，表格展示补齐，卡片底下左右滑动条，灯箱文件预览也是，还有右侧侧边栏的文件预览也是，这个要是自适应的」。

## 事实（改之前的形态）

- `.markdown table { width: 100% }`（03-messages-turns.css）—— 表格被**硬压**进容器宽度。
  列多的表：中文可在任意字间断行 ⇒ 一行被压成一列几个字，长到溢出时直接被容器裁掉。
- `.md-table-wrap` 只有 `position: relative`（给右上角「复制表格」按钮当定位锚），没有任何滚动能力。
- 三个落点共用同一个渲染器 `MdTable`：聊天消息（`session-queue/ItemView.tsx`）、
  灯箱文件预览（`app-view/AppView/09-file-preview-editor.tsx`）、右栏文件预览（`03-workspace-files.tsx`）
  —— 都走 `src/features/markdown/Markdown.tsx` 的 `<Markdown>`。

## 改法（一处改，三处生效）

1. 结构分两层：
   `div.md-table-wrap`（卡片：边框 + 圆角 + panel 底 + `position:relative`）
     → 复制按钮（绝对定位，**不滚动**）
     → `div.md-table-scroll`（横向滚动：`overflow-x:auto`）
        → `table`
2. 表格 `width: max-content; min-width: 100%`：窄表撑满卡片、宽表按自然宽度去滚；
   单元格补 `min-width: 88px` + `vertical-align: top`，表头浅底 —— 不再一列一个字。
3. 滚动条：高度 10px + 轨道/滑块实色（第一版用 `--line` 做滑块，截图里根本看不见，用户要的就是这条）。

## 两个坑

- ⛔ **复制按钮不能放进滚动层**：`position:absolute` 在滚动容器里会跟着表格一起被横向滚走
  （代码块那条注释里踩过同一个坑）。所以滚动容器必须是内层。
- ⛔ **`overflow-x:auto` 之外还要 `overscroll-behavior-x: contain`**：否则滚到表格尽头时
  会接着把整个对话横向带动（触控板尤其明显）。

## 验证

- tsc 通过；vite build 通过。
- 守卫 12o-md-block-copy 30 → 35 条（新增：有滚动层且 table 在里面 / 复制按钮在滚动层外 /
  `overflow-x:auto` + `overscroll-behavior-x:contain` / 滚动条有高度和滑块底色 / 表格 `max-content + min-width:100%`）。
- 真机实测（右栏文件预览，面板宽 259px）：`.md-table-wrap` 卡片宽 259、圆角 10px、
  内层 `.md-table-scroll` 的 `scrollWidth 857 > clientWidth 257`、滚动条槽位 10px、
  复制按钮在滚动层外 —— 即"宽表在卡片里横向滚、卡片自适应面板宽度"。
- 截图核对：右栏预览里的宽表格显示为带边框卡片，列保持自然宽度、底部有横向滚动条。

## 备注

聊天消息里的表格走同一个组件与同一套 CSS，机制相同；本轮没在历史会话里找到含表格的样本做逐帧截图，
改由右栏预览（同一渲染器、同一 CSS）实测几何 + 守卫结构断言覆盖。
