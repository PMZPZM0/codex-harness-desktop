# 长会话滑动渲染窗口（全量加载后仍只挂5回合）+ 刻度尺联动波浪与点击

## 背景
用户实测：滚到最上面（全部历史加载过）后切到别的会话明显变慢，或者再滚到最下面时懒加载像失效；同时提出刻度尺要「当前阅读位置自动带起上下两根刻度的波浪、压缩绿线保持普通长度、刻度线可点击」。

## 结论
- 渲染从「最后 N 个回合」改为**固定 5 个回合的滑动窗口**：`turn-history.windowTail` 表示窗口后面（最新方向）折叠的已加载回合数；上滚把窗口整体上移（`loadEarlierTurns` 本地/网络拉一页后 `setTurnWindowTail`），下滚用 `slideTurnWindowDown` 本地滑回，贴底 `tail=0`。
- 顶部 `.timeline-history-spacer` + 底部 `.timeline-history-bottom-spacer` 都用「隐藏回合数 × 估算高度」；窗口移动时一增一减，总高度不变。渲染必须用 `historyPlan.visible`（旧代码用 `visibleTurnWindow` 的尾窗，导致占位区在动、内容不动 = 滑进空白）。
- 滑窗/水合交接 `HistoryPinState`（direction / expectedTail / expectedLength），layout effect 在 paint 前补 scrollTop；窗口收缩/滑回 tail=0 时贴回内容真底。
- 切回缓存会话恢复阅读位置时 `setScrollUserDetached(true)` + 按「距底偏移」连续校准 20 帧：openThread 末尾那次 rAF jumpToBottom 会落到文档底 = 底部占位区空白；且第一帧的 scrollHeight 可能还没包含顶部占位区，单次定位会被通用 spacer-follow 再推到底部。
- `data-history-total` = `hiddenStubs + 已加载回合`（旧公式把已加载隐藏回合重复算成 113）。
- 刻度尺当前刻度改用 `contentOffsetTop`（旧 `offsetTop` 相对 `.turn-group` 恒接近 0 ⇒ 永远高亮最后一条）；自动 `wave-0/1/2`（26/18/15px）以当前阅读位置为中心，hover 优先；压缩绿线静止 12px、**波浪扫过时与相邻刻度同宽**、本身可点击；刻度点击走滑窗挂载 + 内容坐标对齐到顶部 12px。

## 依据
- 复现（真实 44MB / 59 回合会话，e2e profile）：点击加载全部 → `groups=53`，切走/切回 1884/2059ms；改为滑窗后 `groups=5`，切回 464~529ms；全量加载后 `data-history-total=59`（旧为 113）。
- 滚轮滑动：窗口向下滑时真实回合切片变化（顶部 2038/617 → 378/1331），视口始终有内容；向上滚回 `below` 减少、`hidden` 增加，DOM 恒 5。
- 验收 `scroll-wheel-release` 9/9：真实 59 回合会话，全量加载后 DOM≤7、切回位置 625px 保持；`ruler-wave` 6/6：中心 26px / 邻 18px / 远 15px，滚动 12000 后 current 从 ee80d441 → e2f62d8c，刻度点击 top=10、绿线点击 top=12；守卫 12r 29 条。

## 影响面
`src/lib/turn-history.mjs`（windowTail）、`src/lib/turn-order.mjs`（turnHistoryPlan 增加 tail/hiddenBelow）、时间线渲染/双占位/滑窗锚点、part07 的 load/slide/jump、part09 collapse、open-thread 冷开重置、send 时 tail=0、part04 只补偿顶部占位 + 恢复阅读位置时关自动跳底、刻度尺组件与样式、守卫 03/04/12r、验收 `scroll-wheel-release` / `ruler-wave`。用户可感知：全量加载后切会话仍快；上下滚都有内容、无空白/无回弹；刻度尺波浪跟随阅读位置、绿线等长、可点击跳转。

## 回滚
回退本轮提交。滑窗是 `windowTail` 与 `historyPlan.visible` 两条主链；只删其一会出现「占位在动、内容不动」的空白。刻度尺回滚只需恢复 `offsetTop` 当前判定与绿线 26px（但不建议回退点击/波浪）。
