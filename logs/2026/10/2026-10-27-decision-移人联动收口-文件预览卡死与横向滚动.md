# 移人联动收口 + 文件预览卡死与横向滚动

## 结论

两条 UI 报障是同一类根因：**把「整篇东西」塞进一个会被频繁重排的盒子里**。

1. **移人联动**（4a17c12c7）—— 状态与生命周期没有单一出口：
   - `member.status` 有 5 处直接赋值 ⇒ 打回/通过逻辑会把 `removed` 改回 `locked`/`idle`。
     收口到 `setMemberStatus`，removed 变终态。
   - 移出成员时删了会话却没结清在办任务 ⇒ 任务永远 `running`（界面「正在做」卡死、占着并发闸）。
     现在 `removeMember` 一并把任务标 failed 并把标题回传给中枢；迟到的交活回调直接丢弃。
   - 「在群成员」口径散在 4 处各自 filter ⇒ 办公室按 `activeMembersOf` 一处收口（传参处过滤，
     展示组件不认识群成员语义）。

2. **文件预览卡死 + 没有左右滚**（a8f353be8）—— 158KB / 5086 行 / 最长行 5925 字符：
   - 横向滚动条原来属于代码块自身 ⇒ 钉在内容最末尾（滚到第 5000 行才见）。
     改为**容器当唯一滚动体**（代码块 `overflow: visible`，用 `!important` 压过高亮主题的内联样式）。
   - 卡死 = 整篇高亮 + 行号 + 超长行盒。重文件（>20K 字符 或 有 >300 字符长行）走纯文本渲染，
     右栏只取前 60K 字符；实测该文件预览 DOM 节点从「上万」降到 **3**。

## 判据

- `guards/22` 真跑状态机 + 8 条跨层接线断言；`tests/boss-groups-state.test.mjs` 19/19。
- `guards/11p` 钉「容器滚动体 + 两档截断 + 重文件纯文本」；`guards/11s` 钉「弹层跟内容走 + 按实测空间挑边」。
- headless 探针实测：权限弹层 150→116px 且无滚动；大文件 `renderMode=plain-heavy`。
- `npm run check` 全链 EXIT=0（含 check-preflight / bag-types / dead-imports / require-paths）。

## 踩到的坑（下次别再踩）

- **守卫比实现更脆**：把断言写成整条字面量（`setNotices([{ id, text, threadId, scope }])`、
  `(text: string, threadId?: string)`），实现多一个可选字段就假红。判据锚「结构契约」，不锚字段清单。
- **函数签名锚点**：`indexOf("function startNewThread()")` 在加了可选参数后恒不匹配（守卫静默变红）。
- **数据依赖断言**：`子智能体类非 0` 在「出厂无内置子智能体」后永久红 ⇒ 结构用探针条目验，数据只作参考。
- **内联样式压不过 CSS**：高亮主题把 `overflow:auto` 以内联 style 打在 `<pre>` 上，
  这处必须 `!important`（作用域被外层容器类名限死，不外溢）。
