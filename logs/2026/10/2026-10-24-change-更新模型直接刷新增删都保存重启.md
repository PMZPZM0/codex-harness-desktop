# 更新模型直接刷新，新增/下架模型都保存重启（10-24 八轮）

## 结论

用户：「点击更新模型，直接更新就好了，还进来了编辑界面，又要点一遍更新；新增了模型，和减少了模型都要保存重启，才能刷新出来；修改了密钥和 API 地址也是一样」。

- 卡片「更新模型」不再打开二级编辑弹窗：直接用该供应商的地址与已保存密钥请求 /models。
- 新增模型默认启用；下架模型从列表移除；两者任一发生即 `saveCustomDraft` 保存并 `relaunchApp` 重启应用，回执写「新增 N / 移除 M，应用即将重启」。
- 无变化时只提示「已是最新」，不重启。
- 编辑弹窗里改 Key / Base URL 后点保存仍走同一条保存链：`saveCustomModel` 写配置 + `applyCustomModel` 重启引擎，随后 `relaunchApp` 重启应用。
- PPtoken 未配置卡仍是「配置」（没有 Key 无法拉模型）。

## 判据

- 主仓验收 `provider-autosetup` 新增 ⑤c/⑤d：本地 mock 先加 `mock-gamma` → 点卡片更新 → 列表出现 gamma 且不打开编辑弹窗；再改成只剩 `mock-alpha` → 点更新 → 列表只剩 alpha（移除并保存）。默认轮 23/23。
- 守卫 12ad 60 条：更新按钮直接触发 `refreshCardModels`，函数内同时处理 `addedIds`/`removed`、保存与 `relaunchApp`。
- 截图与构建：主仓 `npm run build:vite` + 默认验收 23/23；PPcode/云助手渲染层已重建，云 UI 已部署。
