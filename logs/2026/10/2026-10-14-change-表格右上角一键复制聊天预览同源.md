# 表格右上角一键复制（聊天/预览同源）

## 背景
用户 10-14（截图：一份「提交汇总」消息，正文就是一张 markdown 表格）：
「对话框里面，Codex harness 汇总输出**类似这种格式内容**的时候，在右上角加一个复制小图标，图标两段过渡动画」。
此前正文里的代码块、表格**都没有任何复制入口**（消息脚部只有「复制消息」= 整条正文）。

## 结论
- 渲染层 `MD_COMPONENTS` 增加 `table` 覆盖 → 每张表包进 `.md-table-wrap`，右上角挂
  **复用** `FeedbackIconButton` 的复制按钮（两段反馈：变对勾 → 1.1s 淡回原样；动画本体是 CSS
  `[data-phase="done"]`，这次把 `.md-table-copy` 一并列进那条选择器）。
- 点一下复制的是**整张表的 TSV**（单元格 Tab、行换行）—— 贴进 Excel / 文档 / 表格就是一张表；
  拼装抽成纯函数 `src/lib/md-table-text.mjs` 的 `tableToTsv()`（纯函数 ⇒ 预检能跑真值表）。
- 显隐（10-14 二改，用户口径「常驻且更醒目」）：**常驻可见**，配色跟主题按钮一样（不透明底 `--panel`
  + `--line` 边框 + 一点阴影，压在表头文字上也看得清），悬停只是**配色加重**（不是显隐开关）。
  ⛔ 首版做的是"悬停才显形"，用户当场报「旧消息我没看见」—— 悬停显形等于"不知道有这功能的人
  永远发现不了"，守卫 12o 加了负向断言：默认态不许再出现 `opacity: 0` / `pointer-events: none`。
  ⛔ 另一个当场踩到的坑：**用户那个应用实例是在构建落盘前 17 秒启动的**（进程 22:09:46 vs
  构建 22:10:03）⇒ 他看到的还是旧界面，"压根没有"其实是**没刷新**。改渲染层后要让用户
  `Ctrl+R` / 重启，否则改了也看不见。

## 依据
- 验收 `md-table-copy`（**7/7 真机**）：右栏项目树 → 打开含表格的 .md（同一渲染组件）→
  默认态（右上角 dRight/dTop=4、opacity 1、pe auto、不透明底色 + 边框 + 阴影）→ **真鼠标 hover 到按钮上** → 配色加重 →
  点击后 `data-phase=done` + 对勾 + `animation-name=message-action-pop` →
  **真 Ctrl+V 把系统剪贴板粘进测试 textarea**（不粘输入框：>200 字会被存成 .txt 附件）比对形状
  （3 行 4 列、首格=表头首格、无 markdown 竖线）→ 1.1s 后回位。
- 守卫 `scripts/guards/12o-md-table-copy.mjs` **19 条**（独立守卫，登记进 check 链）：组件复用 +
  TSV 真值表 + 4 条 CSS 形态（定位/默认不可见/悬停显形/减弱动效）+ 验收项登记；**5 处变异全抓**。
- ⛔ 真机抓到并修掉的真 bug（列进真值表防复发，新增一条类数组用例）：
  真 DOM 的 `table.rows` / `row.cells` 是 **HTMLCollection（类数组）**，实现里用 `Array.isArray` 判
  ⇒ 整张表静默拼成空串、点了没反应；另有一条：整串 `.trim()` 会吃掉首列为空单元格的**前导 Tab**（列串位）。

## 影响面
- 三处入口**同一份组件**：聊天正文 / 文件预览 / 复审报告；`Markdown.tsx` 是唯一渲染入口。
- 只加渲染层：不动主进程、IPC、引擎；不改既有 `.markdown table` 边框样式。
- 10-14 三改（用户截图「上面没有，下面有了」）：**代码块也挂同一套复制按钮** —— 上面那块不是表格，是围栏代码块（竖线是字面文本）。复制的是代码原文（`code` 变量在手，不从 DOM 反推），按钮锚在外层 `pre` 右上角（`pre` 横向滚动时不会跟着滚走）。验收项/守卫随之改名 `md-block-copy`，真机 10/10（表格 TSV + 代码块原文两条都实测）。
- 边界（仍不做）：工具卡里的输出块（`ToolCodeBlock`）没挂；那是我没动过的另一条渲染路径，要的话说一声。

## 回滚
- 回退本提交即可（新增文件 + 三处小改）。只想关按钮不删代码：去掉 `MD_COMPONENTS` 里的
  `table:` 一行即可（`.md-table-wrap` 不再生成，其余不动）。
