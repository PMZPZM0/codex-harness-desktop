# 新手引导重写为图示加文字详细版，并扩成新手/高级双教程

## 背景
用户 10-18（截图：原 7 节的迷你设置式引导）：「这个新手教程优化一下吧，你把应用功能都扫一遍，
做一个详细的新手教程，画图+字结合起来」。

同日二轮（看过首版后）：「你写这个太草率了，前端UI开发，组件库 生图工作流，视频工作流，
专家 专家团 子智能体 codex个性化人格市场，等等这些你都没写」。

同日三轮：「还有功能拓展那些接口，怎么做自己加自己的功能，等等都有接口的啊，基础教程有，
高级教程也要有，懂不，写好看一点，，分新手和高级教程」。

## 结论
- **22 节**，按 `tier` 分两组：**新手 12 节**（快速上手 / 界面速览 / 配置模型 / 一次对话 /
  上下文 / 功能地图 / 个性化 / 人格市场 / 声音与宠物 / 进阶技巧 / 数据与隐私 / 开发工具）；
  **高级 9 节**（前端开发 / 组件库 / 生图 / 视频 / 专家团队 / 记忆知识 / 扩展能力 / 自动化 /
  拓展开发）；更新日志不分组、置底。
- 二轮补齐的专节全部按**实测入口与工具名**写：
  - 前端开发：侧栏「···更多 → 前端开发」、44 种组件、手机/电脑/网页、预览、交给 Codex 实现；
  - 组件库：11 类 3802、复制代码、`ui_component_search`；
  - 生图：`生图插件`、图像工坊、生图工作流、改图 vs 重画；
  - 视频：8 家厂商、异步提交不干等、拼接要 FFmpeg、白模/短剧工作流、HTML→MP4；
  - 专家团队：专家 / 专家团 / 子智能体、顶栏「调度」、办公室、调度独占；
  - 记忆知识：常驻记忆 / 项目共享记忆库 / 金字塔 / 后端二选一 / 项目级知识库；
  - 个性化：称呼 / 回复风格 / 自定义指令 / 语气自适应 / 项目 AGENTS.md / 外观；
  - 人格市场：重写旧错口径（写入全局个性化、**下一个新会话**生效，不是在会话里选）。
- 三轮新增**拓展开发**（高级）：以「设置 → 拓展接口」的四个分组为入口，讲清不写代码的扩展
  （技能/插件/MCP/钩子）与写代码的固定套路：`electron/ipc-channels.manifest.json` 加一条 →
  `npm run gen:ipc` → `electron/ipc-registry.ts` 登记 → `electron/features/<域>.ts` 的
  `ipcHost.handle` 实现 → 渲染层 `window.codex.<方法>`；另含界面板块、模型工具、主题/快捷键/
  斜杠命令、守卫 + 验收 + FEATURE-LEDGER，以及三条硬规矩（单一真相源 / 生成物禁手改 / 安全边界）。
- 视觉：左导航加「新手教程 / 高级教程」组标题；正文标题旁加层级徽章（新手蓝 / 高级紫）；
  关键章节加 12 条重点提醒卡（主题色高亮）。图示仍为数据驱动（flow/panes/layers/window），
  ⛔ 不用截图 / 生成图 / 位图资产。

## 依据
- 守卫 `11x-newbie-guide` **45/45**：新增二轮/三轮必含章节与真实入口名、tier 覆盖除日志外全部章节、
  日志不分组、旧人格错话负向、标签 ≤6 字、分组导航/徽章/提醒卡的结构与样式、每节带图（21 图 / 22 节）。
- 验收 `newbie-guide` **11/11**：②a 两组组标题 + 默认「新手」徽章；②d 左选项 22 节且八个点名章节都在；
  ②e 点开「拓展开发」→ 高级徽章 + 正文含 拓展接口 / harness-api / `npm run gen:ipc` / scripts/guards + 提醒卡；
  原有入口不被遮、映射跳转、日志真数据、Esc 关闭全保留。
- 渲染层 `npm run build` 通过；`npm run check` 只剩并行云同步线的两条红
  （cloud 4 条通道未登记 / cloud 域 id 与组合表不符），与本轮无关；下游 bag-types / dead-imports /
  require-paths 单独跑均通过。棘轮 accept.mjs 2369→2390（实测净行）。
- 真机截图：新手组首页（分组 + 新手徽章 + 流程图 + 提醒卡）、拓展开发（高级徽章 + 六格图 + 真命令）、
  视频节（流程/厂商清单）均已目视确认。
