# 新手引导重写为图示加文字详细版

## 背景
用户 10-18（截图：原 7 节的迷你设置式引导）：「这个新手教程优化一下吧，你把应用功能都扫一遍，
做一个详细的新手教程，画图+字结合起来」。

## 结论
- **15 节**（原 7 节）：快速上手 / **界面速览** / 配置模型 / **一次对话** / **上下文（压缩）** /
  功能地图 / **扩展能力** / **自动化** / **创作设计** / **声音与宠物** / 进阶技巧 / **数据与隐私** /
  开发工具 / 人格市场 / 更新日志（仍置底；三个设置页映射保留）。
  内容按 `settingsNav`（28 页）、侧栏「···更多」、内置命令目录的**实测名字**逐条写。
- 新增 `figures.tsx`：**数据驱动示意图**四种形态 ——
  `flow`（流程盒子+箭头）/ `panes`（并列 2 列）/ `layers`（分层缩进）/ `window`（**内联 SVG 窗口五区图**：
  侧栏 / 顶栏 / 对话区 / 输入框 / 右栏 + 状态胶囊）。颜色全走主题变量 ⇒ 浅色深色自动适配、零资产、改版零维护。
  ⛔ 刻意不用截图 / 生成图 / 位图资产：截图会过期（过期图 = 主动误导）、生成图与真实界面对不上、
  JS import 的位图还会被 before-pack 当陈旧死块删掉（v0.0.27 事故同型）。

## 依据
- 守卫 `11x-newbie-guide` 扩到 **24 条**：四形态齐全 / SVG 窗口图 / 右页渲染位置（intro 之后、步骤之前）/
  每节带图（实测 14 节）/ 类型带 `figure` 拓展字段 / 图示样式在 / ⛔ 不用位图资产。
- 验收 `newbie-guide` 加 **②b/②c/②d**：界面速览的 SVG 可见（高 298px、22 个文字标注）/ 流程图 4 个盒子 + 图注 /
  左选项 ≥12 节 —— 真机 **9/9 通过**（含原有的入口不被遮、映射跳转、日志真数据、Esc 关闭）。
- `npm run check` 预检通过；棘轮 accept.mjs 2339→2369（实测净行）。
