# 设置内页统一版式（10-24）

## 结论

技能 / 插件 / 组件库 / MCP / 命令 / 人格市场 / 记忆 / 知识库 / 自动化 / 定时任务 / 钩子 / SSH / 专家-专家团 / 使用统计 / 数据管理 / 收藏夹（以及会话备份 / 归档管理）统一收进 `settings-exp-shell` 版式：

1. **页头两行**：标题与右侧操作固定第一行，说明整宽第二行。实现方式是设置内容的 `.settings-copy` 用两列 grid，并用 `display: contents` 摊平标题包装层；长说明不会再把按钮挤到标题下，也不会把标题压成窄列。
2. **切页回顶**：设置内容是一个滚动容器，切页不重置会把上一页的滚动位置带过来，页头卡片被截在容器上沿（截图实测）。在 `settingsPage` 变化时 `scrollTo({ top: 0 })`。
3. **长卡片、不留空格子**：自动化 / 专家团的三张入口卡改一列横向长卡；定时任务模板两列，落单的最后一张占满整行；记忆两张内容卡改一列；收藏夹页脚由 flex 改单列（flex 把文本节点拆成四块）。
4. **页面自身**：定时任务标题由「自动化」纠正；知识库补页头、「本地文档」降为分组标题；人格市场刷新收进页头；SSH 搜索框可收缩，导出/导入不再落单；各页补一句 ≤40 字的新手说明（长说明仍在 ? 里）。

## 为什么

用户 10-24 截图框住四个分组并令「你也全部优化一下布局，还有那个收藏夹」「对应里面界面都做好看一点，风格统一，方便新手」。上一轮已经确认：**不要强制等宽/方卡网格**，内容卡一律长卡片、高度随内容（「很多这种空白，长卡片就好了」）。

- 验收 `settings-unified`：7/7，16 页逐页量真实 DOM —— 统一壳、页头完整不被截断、无横向溢出；自动化入口卡最窄 676px、专家团 686px、记忆内容卡 676px；收藏夹页脚 `display:block`。

## 影响面

只改渲染层版式与文案，不动 IPC、状态、控件类名与行为；`settings-exp-shell` 只挂在 18 个目标页，账户/模型/外观等页不受影响。
