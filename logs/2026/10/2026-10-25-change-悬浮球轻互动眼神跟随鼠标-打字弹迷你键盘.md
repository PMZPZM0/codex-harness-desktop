# 悬浮球轻互动：眼神跟随鼠标 + 打字弹迷你键盘

## 背景
用户：「能不能做点互动啊，比如眼睛跟着鼠标走，打字有键盘出来等等」。
悬浮球此前只有状态变色、眨眼和音量脉冲，缺少「它注意到你」的感觉。

## 结论
- **眼神跟随**：`--bot-gaze-x/y`（±3px / ±2.2px）由 `useBallReactions` 直接写到球元素上，
  rAF 合并 pointermove，**不进 React state**；两只胶囊眼包在 `.voice-bot-gaze` 位移层里，
  眨眼动画仍作用在各自的眼上，两者不互相覆盖。
- **打字小键盘**：在输入框 / 多行输入 / contenteditable 里敲字符、空格、退格、回车时，
  球上方弹出 3 排 6/6/4 键的迷你键盘，停手 1.1 秒自动收起；中文输入法 composition 也算。
  Ctrl/⌘/Alt 组合键、方向键、修饰键不触发；打字期间随机提示气泡让位。
  ⛔ 键盘绝对定位、`pointer-events:none`：不顶动球、不挡点击。
- 监听只在球可见时挂（互斥置灰态也保留，避免反复摘挂）；组件卸载 / 失焦 / 隐藏时移除变量与监听。
- 减动效（`prefers-reduced-motion` 且未强制）不跟随鼠标，键盘动画由 CSS 关闭。

## 依据
- 纯函数 `src/lib/ball-reactions.mjs`：`gazeOffsets` / `isTypingKey` / `isTypingTarget`，
  守卫 11z 新增 10 条（含真值表与接线），214/214。
- CDP 实测：指针移到球左上 → `--bot-gaze-x=-2.1px / y=-1.54px`；右下 → `3 / 2.2`；
  在 `.composer-editor` 敲 `a` → 键盘出现（3 排 16 键、提示气泡隐藏），约 1.1s 后消失；
  放大截图确认键盘气泡与小尾巴。
- 验收新增 `voice-ball-reactions` 3 条，默认全量跑通（22/30；8 条红全在 function-menu，
  属并行改动后的侧栏文案/入口数变化，与本功能无关）。

## 影响面
仅悬浮球视图层与语音设置不受影响；设置页外观预览不带互动（没有监听）。
额外每帧只写两个 CSS 变量，无 React 重渲。

## 回滚
移除 `useBallReactions` 调用与键盘 JSX / CSS，眼睛恢复为直接子元素；纯函数与守卫断言一并删除。

## 后续补充（同日）
用户追加：「加上鼠标移动时的瞳孔缩放」。
- 新增纯函数 `pupilScale(speed)`：不动 = 1x，慢移 1.04x 起，快速划过上限 1.18x，非法速度回落 1x。
- `useBallReactions` 按相邻 pointermove 的距离/时间算速度，写 `--bot-eye-scale`；
  停手 140ms 复位，由 `.voice-bot-eye { transition: scale .18s }` 平滑回落。
- 眼型用 CSS **独立 `scale` 属性**（不是 transform）⇒ 与眨眼/眯眼动画互不覆盖。
- 判据：守卫 11z 216/216（含速度真值表/接线/CSS）；干净 worktree 构建通过，
  验收 `voice-ball-reactions` 5/5（gaze -2.1/-1.54、瞳孔 1.05、回落 1、键盘 3 排 16 键、1.1s 收起）。
