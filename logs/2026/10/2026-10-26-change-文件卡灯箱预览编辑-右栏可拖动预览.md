# 文件卡灯箱预览/编辑 + 右栏可拖动预览

# 文件卡恢复灯箱预览/编辑；右栏文件预览可拖动并向上拉满

## 背景
用户截图：
① 消息里的文件卡「…」菜单只有「复制路径 / 在文件夹中显示」，找不到之前的**灯箱预览**和**编辑**；
② 右栏「文件」页的文件树 + 预览上下分栏，预览被挤在底部、内容被裁，想要能上下拖、底部预览能往上展开，并给对应按钮/按键。

## 结论
- `FileRefCard` 的「…」菜单新增：
  · **灯箱预览** → `onOpenEditor(path)`（居中大预览弹窗，Markdown 渲染；弹窗内仍有「编辑」）；
  · **编辑** → `openFileTextEditor(path, name)`（与回合汇总卡右键「编辑」同一通道）；
  · 图片/二进制文件不给「编辑」（避免写坏）；菜单高度随条目数自适应。
- 右栏「工作区文件」：
  · 文件树与预览之间加 **7px 拖动分栏条**（row-resize，高度按会话记 localStorage
    `workspace-files-tree-h`，120px ~ 容器高-180px 硬钳）；
  · 预览头部加「**展开 / 恢复**」按钮：展开时文件树收起（max-height:0），预览吃掉全部高度；
  · **Alt+↑ 展开、Alt+↓ 恢复**（只在「文件」tab 生效）；按钮 title 写明快捷键。
- 视觉：分栏条 3px 圆条 + hover 拉长；展开后 tree 区不残留边框。

## 依据
- CDP 实测（package.json）：默认 tree 304 / preview 396；点展开 → tree 20 / preview 685、splitter 消失；
  点恢复 → 回到 304/396；合成拖动 pointermove → tree 211 / preview 489；Alt+↑↓ 与按钮同效。
- 预览头部「在编辑器打开」→ `.file-preview` 弹窗，按钮含「编辑」（灯箱能力本身在）。
- 守卫 11p 新增 3 条：卡片菜单两项/二进制禁编辑、分栏+Alt 接线、CSS 与展开按钮；
  验收新增 `file-preview-controls` 4 条，真机 4/4。

## 影响面
只改文件卡菜单与右栏「文件」页布局；预览读取、编辑器、默认应用、定位等既有动作不变。

## 回滚
移除菜单两项、分栏条/展开按钮与 CSS/守卫/验收，恢复固定 38vh 文件树；预览又会挤在底部。
