# 模型供应商页改版：大卡片 + 二级配置弹窗（功能不删）

## 背景
用户 10-24 截图圈出模型页左下角的「测试当前供应商 / 添加供应商」：
「为啥下面还有这种旧的供应商卡片，供应商旧的改造成大卡片+二级弹窗预览，旧的模板直接删了，
只是改造UI，不要删功能」。

## 结论
- 旧的小行供应商列表与右侧常驻表单模板从 JSX 删除，改成供应商大卡片网格：
  图标 / 名称 / 模型数 / 模型芯片 / 当前生效 / 启用开关 / 配置入口。
- 「测试当前供应商」「添加供应商」移到页头工具栏；付费/免费供应商卡都保留。
- 点击卡片打开二级配置弹窗，原表单（名称 / BaseURL / Key / 上游协议 / 模型列表 /
  勾选 / 测试 / 保存 / 删除 / 添加模型）整体迁入，功能不删。
- 免费模型网关推荐卡保留在「更多供应商」；PPtoken 推荐卡仍保留。
- 卡片仍保留 `.provider-item` / `.provider-switch` / `.provider-dot` 类，验收与守卫的
  「有 dot 的真实供应商行」判据继续有效；视觉由 `.provider-card` 覆盖。

## 依据
- 验收 `provider-autosetup` 加 ⓪：大卡片数量、点击打开 `[data-testid="provider-editor"]`、
  弹窗内 `.provider-form` 字段 / `.model-list-block` / `.settings-actions` 齐全、旧
  `.provider-list .add-provider-btn` 数量为 0。
- 主仓 `npm run check` 退出码 0；默认验收 11/11（含 ⓪）；PP/Cloud 验收 8/8。
- 守卫 11x 适配功能入口「顶部 / 底部」两种位置；守卫 04 适配 `selectProviderDraft` 单源。

## 影响面
- 模型页布局与交互变化；供应商编辑必须点卡片打开二级弹窗。
- 旧 CSS（`.settings-model-layout` / `.provider-list`）不再被该页使用，但保留给其它共享选择器；
  新样式全部收在 `42-provider-setup.css`。
- 云端模式锁定 / 限时福利过滤在云助手仓保留（卡片开关 disabled + 文案）。

## 回滚
回滚本轮提交即可恢复旧小行 + 右侧表单；数据层（custom-model:* / cloud-models:*）未改。
