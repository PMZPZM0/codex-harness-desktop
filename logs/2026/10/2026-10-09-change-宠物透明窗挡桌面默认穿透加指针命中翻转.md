# 宠物透明窗挡桌面：「透明罩」默认穿透 + 指针命中翻转

## 现象

用户报：**应用有「透明罩」问题——打开应用后，部分用户会出现「软件外面无法点」**（桌面/其它应用点不动）。

## 根因

「透明罩」= **桌面宠物浮窗**（`electron/features/pet-window.ts`）：透明 + 无边框 + 置顶的
BrowserWindow，随启动自动恢复（boot.ts 的 `applyPetSettings`）⇒ 「打开应用后」；只有开了
桌宠的用户会遇到 ⇒ 「部分用户」。

关键在两个事实叠加：

1. 宠物窗是**矩形**窗口：图集帧四周的透明留白、顶部气泡区、落地余量，全是**看不见的窗口实体**；
2. `src/styles/22-pet.css` 的 `.pet-float` 整块 `-webkit-app-region: drag`（无边框窗靠它拖动），
   且从未调过 `setIgnoreMouseEvents` ⇒ **整个矩形默认都吃鼠标事件**。

于是压在宠物窗矩形底下的桌面图标 / 其它窗口全部点不到（能点的只剩宠物本体那一格）。
代码头注释里其实早就写了这条纪律（「窗口比宠物大一圈时，那一圈透明区域会挡住桌面上的
鼠标事件」），但只把「改倍率 = 改窗口尺寸」当作对策——矩形内的透明区域依旧挡鼠标。

排查时逐一排除了其它「全屏不可点」候选：截图覆盖层（screenshot.ts，用完即 destroy + 2 分钟
超时兜底）、browser:popout（普通有框窗）、独立会话弹窗（常规尺寸）、pet scale（钳制 0.6~1.8，
最大 414×540）、win-rounded-corners（只是 DWM 属性，不产生窗口）。

## 修法（Electron 透明窗标准姿势：默认穿透 + 命中翻转）

1. **`electron/features/pet-window.ts`**：新增 `setPetMouseIgnore(ignore)` ——
   `win.setIgnoreMouseEvents(ignore, { forward: true })`；宠物窗在 `ready-to-show` 与
   `hide()` 时都回到**穿透态**（后者防止下次 show 时指针恰好停在窗上、一出现就挡桌面）。
   ⛔ `forward` 只有 Windows 有实现：mac 上保持旧的整块可点行为——贸然开穿透却收不到
   mousemove，宠物会变得完全点不到（比挡桌面更糟）。
2. **`electron/features/pet-ipc.ts`**：新通道 `pet:ignore-mouse`（域内第 11 条）——
   `setIgnoreMouseEvents` 只能主进程调，渲染层没有任何旁路；`ctx.effect` 卸载摘除同步补。
3. **IPC 三件套**：manifest 登记_pet:ignore-mouse → `npm run gen:ipc` 生成 preload 桥
   （`petIgnoreMouse(ignore)`，`invokeArgs` 带参——⛔ 这张表漏写 = preload 层静默丢参）与
   vite-env.d.ts；`ipc-registry.ts` pet 域 count 10→11；`extensibility-catalog.mjs` 通道总数
   431→432（生成器同步）。
4. **`src/features/pet/PetFloat.tsx`**：mousemove（rAF 节流）→ `document.elementFromPoint`
   取**最深处**元素再 `closest(".pet-sprite, .pet-missing")` 判「指针是否在宠物本体上」，
   在本体上 = `petIgnoreMouse(false)`（可拖可点），四周 = `petIgnoreMouse(true)`（穿透放行）；
   **光标离开窗口（mouseleave）强制回到穿透**——透明态下页面收不到收尾的 mousemove，
   不兜这条的话「从本体直接移出窗口」会把整块窗留在可交互态继续挡桌面。
   ⛔ 命中判定必须取**最深**元素：`pet-stage` 铺满整窗，直接判它恒真 = 白修。
   ⛔ 精灵盒是**近似**命中（图集帧内可能有透明留白），不逐像素测 alpha——逐像素要常驻
   canvas 采样，成本与收益不成比例；盒子已把挡桌面的范围从「整个窗口」缩到「本体那一格」。

## 判据（守卫 06【232】⑯ 组 +4，总账基线 3236→3240；棘轮两处随实测回填）

- 默认穿透（ready-to-show / hide 都回穿透态）；IPC 通道接线；渲染层命中翻转
  （elementFromPoint + closest 最深元素）；光标离开窗口回穿透。
- **变异测试**：摘掉 mouseleave 回穿透 ⇒ 「离开窗口」断言精准红。
- 预检回到 19 项环境类基线（`06-app-behavior.mjs` 2712→2731、`vite-env.d.ts` 804→805
  两处棘轮随实测回填）。

`tsc -b` + `tsc -p electron` 0 错；`npm run build` 全过；预检 19 项环境类（无新增硬失败）；
