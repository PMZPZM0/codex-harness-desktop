## 背景
用户两条令：①「侧栏底部加一个新手引导常驻板块，点击后弹窗，左边选项右边内容，迷你版设置界面；
第一个模型配置界面映射，第二开发工具下载界面映射，人格市场映射；版本更新日志默认在最下面；
留好 UI 拓展接口，反正要适合新手快速上手，你从专业角度给新手定制一个」+ 追问「这个新手引导
不能被对话框选项遮住」（配合选择题确认为：红框处 = 账户行正上方；滚轮 = 列表整体滚 + 单项目内滚）；
②「把那个首次安装启动的那个引导弹窗删了吧，反正现在也新手引导选项了」（= 首启「环境体检」）。

## 结论
- **新板块 `src/features/newbie-guide/`**（自包含、不进 bag）：侧栏底部常驻入口（`.thread-list`
  之外、账户行之上；`flex:none`）+ 迷你设置弹窗（400 模态档；左导航/右内容；✕/遮罩/Esc 三路关）。
  五节注册表 `GUIDE_SECTIONS` 作拓展接口（数组加一项）：快速上手（默认）/ 配置模型 / 开发工具 /
  人格市场 / 更新日志（置底）。三处设置映射的 page id 与 settingsNav 真值对账防死链。
- **版本日志单一真相源**：新 IPC `whatsnew:history` 复用 `whats-new-notes.ts` 的 WHATS_NEW_ENTRIES
  （Release 链接主进程拼）；渲染层零硬编码。
- **首启「环境体检」整体删除**：组件 + 自动弹出 + 安装队列/角标状态机 + CSS + bag 16 字段
  （bag-types 1407→1386）；守卫翻负向（组件不许回来 / app-ui 清零 / 样式清零 / NewbieGuide 必须在位）。
