# 右栏默认变更 + 主题界面 + 搜索 + 自适应展示

## 背景
用户截图右栏展开后一片空白：「侧边栏展开感觉空唠唠的，展开默认展示变更界面，
浏览器那个界面，设计一个主题界面把，做好看一点，加一个搜搜索框可以直接搜索内容，
然后里面展示的内容要根据尺寸，自适应展示全，不要裁剪展示」。

## 结论
- 右栏 `rightTab` 初值 = **review**；切换按钮展开时若为空也兜底 review ⇒ 不再出现空白页。
- 「变更」页重做为**主题总览卡 + 文件卡片流**：
  · 顶部：分支图标 + 范围名 + 工作区、文件数、+增/-删、刷新；
  · 搜索框：按**文件路径或 diff 内容**双匹配，命中内容时显示一行片段；
  · 文件卡片：文件类型图标 + 完整路径（`overflow-wrap:anywhere` 换行展示全，⛔ 不 ellipsis 裁剪）
    + 增删统计；窄宽度卡片自动换行。
- 删除旧 `.review-bar` / `.review-refresh` 死样式；新增 `.review-hero / .review-search / .review-file-*`。

## 依据
- CDP：右栏展开后 active tab = 变更、hero 与搜索框在位；`head` 范围内文件卡片渲染；路径/文件名
  `scrollWidth <= clientWidth`（无裁剪）。守卫 12aa 39/39（默认 tab、主题卡+双匹配搜索、路径换行）。
- tsc / vite build 通过。

## 影响面
仅右侧面板「变更」页与右栏默认 tab；Git 数据与刷新逻辑不变。

## 回滚
`rightTab` 初值回空；恢复旧 ReviewPanel JSX 与 review-bar 样式；守卫 12aa 的【118 变更页】段删除。
