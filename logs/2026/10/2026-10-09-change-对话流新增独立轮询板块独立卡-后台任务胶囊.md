# 对话流新增独立轮询板块（独立卡 + 后台任务胶囊）

# 轮询板块：对话流里的独立卡 + 输入框左上角的后台任务胶囊

用户原话要点：在对话流新增**独立**的「轮询」板块，承载模型等待异步任务结果时的轮询过程，
**不得复用或塞入 thinking 板块**；卡要能看状态/次数/间隔/耗时/进度且点开看每轮；
间隔与超时可配、失败自动重试、错误与超时有明确提示、可手动中止、轮询结束后照常输出最终结果；
输入框左上角「N 个后台任务运行中」（无任务隐藏、面板与输入框同宽、最多 3 条超出滚动、单条查看与中止）；
配色圆角字号动效与现有对话流一致；**通过新增独立渲染分支实现，不改动现有消息渲染逻辑**；
顺带检查输入框上方已有卡片的层级与顺序，避免互相遮挡。

## 为什么不能塞进 thinking

思考是模型的**内部推导**，轮询是**外部世界的等待**。两者都会"卡住不动"，但用户要的东西完全不同：
思考要能折起来别占地方；轮询要能看见「查了几次 / 多久了 / 现在到哪一步 / 我去按停」。
混在一起只能二选一地糊掉一半 ⇒ 独立板块。

## 落地三层

1. `src/lib/poll-config.mjs`（纯函数）：钳制（**超时必须 ≥ 间隔×2** —— 两个数字各自合法、
   放一起不成立，属"自洽地错"，不兜住的话第一轮还没发出就被判超时）、指数退避封顶、
   五态文案、时长/时刻格式化、实测间隔 vs 配置间隔。
   ⛔ 放 `src/lib/` 是硬约束：build.files 只收 `src/lib/*.mjs`，放域目录安装版会 require 不到直接崩。
2. `src/polling/poll-store.ts`（模块级任务表 + 看门狗 + 配置持久化，useSyncExternalStore 消费）。
3. `src/features/polling/`：PollCard / PollTaskBoard / BackgroundTaskCapsule / PollBridge。

渲染分支是 `<PollTaskBoard turnId={turn.id} />` —— 挂在既有 `<Slot id="turn.after-content">`
**旁边**的兄弟节点，既有消息渲染逻辑一字未动（守卫用负向断言钉死：ItemView / SessionQueue /
ReasoningCard 里零 poll 字样）。

## 状态机两条铁律（本板块最容易糊的地方）

- **终态不可复活**：迟到的 round 一律丢弃。主进程超时判掉的那一刻，后面还在飞的那一轮结果已经没有意义；
  复活 = 用户刚看到的「成功」自己变回「轮询中」，面板永远停不下来。
- **超时两侧都判**：主进程 wait 循环判 + 渲染层看门狗判。只判一侧的话，模型自己循环调
  `video_status`（不带 wait）时没人判超时 ⇒ 卡永远挂在「轮询中」。

## 主进程

新域 `poll`（`poll:config-read` / `poll:config-save` / `poll:abort`，插件形态 defineFeature）
+ `electron/poll-config.ts`（真相源 `userData/poll-settings.json`，惰性求值 userData）。
`video_status` 每次查询广播 `poll:round`；`wait: true` 时由主进程托管轮询 ——
间隔/超时/重试取配置，查询失败按指数退避自动重试，等待切成 250ms 小段（否则间隔配到 2 分钟时
点「中止」要等两分钟才停，那就不叫随时中止了）。成功后**照常走原有下载落盘分支**，
最终结果仍由工具返回值交给模型写进对话。

⛔ 两侧各有常量字面量（electron 与 src 互不 import）⇒ 守卫【284】逐字比对默认值与三组钳制边界。

## 顺序与层级（需求第 5 条）

输入框上方卡片栈从上到下：方案确认 → 目标条 → Agent 提问 → 回合状态胶囊 → 审批 → 限流重试 →
上游重连 → 排队消息 → 供应商重启提示 →（两个 fixed 浮层：语音舞台 z60 / 播报条 z58，
它们锚的是 `.composer-wrap` 顶边 ⇒ 浮在整栈之上，不与任何一行重叠）→ **后台任务胶囊** → 输入框。
胶囊面板 `left:0/right:0` 相对 `.composer-wrap` ⇒ 宽度恒等于输入框（写视口坐标会随窗口变歪）；
层级取 10000（DESIGN.md 的 composer 浮层带，与 `.edited-files-pop` 同档，同值比 DOM 顺序）；
并会在点面板外 / 按 ESC / 在别处打字时自动收起 —— 否则它会盖住命令面板（35 档）。
