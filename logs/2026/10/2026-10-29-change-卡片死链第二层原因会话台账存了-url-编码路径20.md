# 卡片死链第二层原因：会话台账存了 URL 编码路径（%20）

# 卡片路径是死链（第二层原因：台账存了 URL 编码路径）

## 用户两问

「是这个文件不存在了嘛，还是这个路径问题」——**路径问题**（已用磁盘与 rollout 双重证据确认）。

## 事实链

1. 面板显示 `文件不存在或不可读：D:\测试\src\lib\command-display.mjs`。
2. 磁盘核对：`D:\测试` 下**连 `src` 都没有**（只有 AGENTS.md / ego-test / news-tmp…）。
3. 真文件在 `D:\Codex Harness Desktop\src\lib\command-display.mjs`（30,411 字节）。
4. 会话 cwd = `D:\测试`；模型命令是 `cd 'D:\Codex Harness Desktop'; … .\src\lib\command-display.mjs`。
   ⇒ 卡片把相对路径按**会话目录**拼 ⇒ 死链。命令卡那条链已在上一轮改成「按命令自己的 cd 解析」，
   但这张是消息里的文件卡 / 回合产物卡，没有命令上下文。

## 为什么"按台账回落"一开始也没救回来

`collectKnownPaths` 从会话文本里抽绝对路径，而会话里出现的那条是 **URL 编码形态**：

```
D:/Codex%20Harness%20Desktop/src/lib/command-display.mjs      ← 来自 file:// 链接
```

原样入库 ⇒ 拿它去 stat **永远不存在** ⇒ 台账里等于没有可用路径（实测：`command-display.mjs` 只有 1 条候选，且带 `%20`）。
解码后立刻命中真文件。

## 改动

1. `src/features/app-view/helpers/paths.ts`：`decodeMaybeEncodedPath()`，台账**入库前**解一次百分号编码
   （解不开按原文存，不丢候选）。
2. 新增 `src/lib/path-fallback.mjs`：
   - `pickKnownPathFallback({ requested, known, workspace })`：**只在路径不存在时**用；文件名必须完全相同，
     目录尾段必须对得上（有 workspace 用相对尾段，没有则用「倒数第二段目录 + 文件名」）；
     对不上返回空串 —— 宁可报"文件不存在"，也不点开一个不相干的同名文件。
   - `resolveExistingFile(requested, { workspace, lookup, notify })`：探存在 → 查台账 → 解编码 →
     再确认存在 → 返回真实路径并提示（`lookup` 由调用方注入，保持纯逻辑可离线测）。
3. 两处预览面都接：`useFilePreview`（居中编辑器）+ `03-workspace-files`（右栏）；
   右栏顶部路径改为显示**回落之后的真实路径**（否则内容对了、标题还写着死链）。
4. 守卫 07【127】+7：3 条真跑纯函数（含"死链落到磁盘真实文件"）+ 台账解码两条结构 + 两处接线一条；
   11p 的读通道断言跟到 `readFile(target)`。EXPECTED_CHECKS 3350 → 3357。
5. ⛔ 顺手去掉自己引入的 `any`（any 基线只许缩，不靠记账绕）。

## 判据

- 纯函数自测 7/7（含反例：目录尾段对不上不回落、文件名不同不回落、同路径不回落、大小写/斜杠混写要认）。
- **真实会话数据**端到端 4/4：解析 rollout → 台账收集（同正则 + 解码）→ `pickKnownPathFallback` →
  磁盘上确实存在。
- `npm run check`：本轮改动 0 红；仓里仍剩 2 条红（【153】harness-api 清单过期、【180】功能入口默认顺序）
  属并行线在途的 function-menu / skills-ipc。
- ⚠️ **界面点选没跑成自动化**：并行线活动期间渲染进程两次 crash（`renderer-gone` + network service crashed），
  点卡片后右栏没来得及渲染就被杀。数据层 + 守卫证据齐全，界面待用户实机确认。

## 口径教训（写进记忆）

- 这类"打不开"**先查磁盘、再查 rollout**（`codex-home/sessions/**/rollout-*.jsonl` 有模型真实命令），别读代码猜。
- 扫 rollout 必须**解析 JSON 之后**再看字符串：生 JSONL 里反斜杠是双写、空格是 `%20`，
