# 播报默认语速 1.25×（v4→v5 迁移，老用户同步生效）

用户令（10-21）：「语音播报速度默认改成 1.25*」。落点 = `DEFAULT_VOICE_SETTINGS.tts.speed` 1.0 → 1.25。

⛔ 关键：只改常量对老用户无效（档案里存的是 1.0，`loadVoiceSettings` 读文件值）——
这是 voice-settings.ts 注释里记过的坑（rule2 / autoGainControl 两次同型）。⇒ 同轮
`VOICE_SETTINGS_VERSION` 4→5 + `migrateSettings` 补 v4→v5：
判据 = 「值缺失或仍等于旧默认 1.0」才迁到 1.25；用户显式调过的档位（0.75 / 1.5 / 2）保持不动。
⚠️ 无法区分「手设 1.0」与「从未设」⇒ 两者都迁（有意取舍，想回 1.0 一档点回）。

单一真相源：播报与通话共用 `tts.speed` ⇒ **通话语速同步变 1.25×**，不另开字段。

实测（真跑 migrateSettings，非读码）：空档案→1.25 / v4+1.0→1.25 / v4+1.5→1.5 /
v4+0.75→0.75 / v5+1.0→1.0 / v4 无 tts→1.25。守卫 11z 159→161（版本断言 4→5 + 默认常量 +
迁移判据两条）。三仓：主仓 65d5fa0 / PP 672d702b / AS f80e8b5f，各自 build:electron 与 11z 实测
（AS 160/161，唯一红为既有文案差异）。⛔ 语速属主进程设置、本机编译，重启应用生效，无需部署渲染层。
