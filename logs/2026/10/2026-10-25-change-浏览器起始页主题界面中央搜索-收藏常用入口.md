# 浏览器起始页主题界面（中央搜索 + 收藏/常用入口）

## 背景
用户：「我让你设计的浏览器界面主题呢」。此前浏览器空态只有一个小地球 + 一句
「粘贴或输入 URL 以打开网页」，右栏展开时显得空。

## 结论
- `BrowserPane` 空标签页改为**主题起始页**：
  · 柔和主题底（accent 径向光 + 线性渐变 + 极淡点阵）；
  · 居中卡片：图标环 + 「从一个网址，或一个问题开始」+ 说明；
  · 中央搜索/网址输入（回车或「打开」走同一个 `navigate`；关键词自动走 Bing）；
  · 下方收藏夹（最多 6 条）；没有收藏时给 GitHub / Bing / 知乎常用入口；
  · 提示支持直接粘贴网址。
- 自适应：卡片 `max-width:560px`、`width:100%`、入口 `auto-fit minmax(104px,1fr)`、
  文字 `overflow-wrap:anywhere`；右栏 308px 下列表两列、无横向裁剪。

## 依据
- CDP：面板宽 308px、卡片 263px、`scrollWidth-clientWidth=0`；起始页/搜索框/3 个入口都在。
- 守卫 12aa 42/42（主题页、收藏回退、自适应与换行断言）；tsc / vite build 通过。

## 影响面
仅浏览器空标签页；地址栏、webview、收藏逻辑不变。

## 回滚
恢复旧 `.browser-pane-empty` JSX/CSS，删掉 `.browser-start*` 样式与守卫断言。
