# 配置引导用专家档案选择成员与配套工具

## 背景
配置引导原先只保存个人偏好；用户无法从确认页判断某位专家需要哪些工具，也不清楚安装会在何时发生。

## 结论
最后一步默认只保存。选择已启用团队中的专家后，展示团队与成员的实际能力声明；基础工具按组件展开，缺失且受支持的工具允许显式安装，重新读取清单后显示结果。保存可直达成员会话，或打开四个已有工作入口。

## 依据
三仓 npm run check 通过。主仓 node --test tests/expert-equipment.test.mjs 验证合并去重、别名和六种工具状态；node scripts/accept.mjs --only profile-expert-guide 在构建后的桌面窗口验证专家选择、工具清单、切换起步卡和跳过。测试没有真实下载组件。

## 影响面
配置引导与专家中心共享 expert-equipment 解释工具声明；复用现有安装、排查和成员会话能力，不增加 IPC，不把一次性工作入口写入长期档案。

## 回滚
回退引导显示、工具解析及相应测试；不需要迁移用户档案，也不卸载用户主动安装的工具。
