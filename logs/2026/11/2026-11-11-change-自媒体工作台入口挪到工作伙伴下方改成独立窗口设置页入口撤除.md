# 自媒体工作台入口挪到工作伙伴下方，改成独立窗口；设置页入口撤除

## 背景
用户原话：「把自媒体工作台在工作伙伴下面加一个选项吧，做主界面一样的弹窗大小，然后设置这边就不要了」。此前它是「设置 → 能力与内容 → 自媒体工作台」里的 iframe 页。

## 结论
- 侧栏快捷入口新增「自媒体工作台」，**紧跟「工作伙伴」之后**（同组：新建任务 / 指挥中枢 / 工作伙伴 / 自媒体工作台 / 拓展功能）。
- 点它开**独立窗口**（`?mediaDesk=1`）：窗口尺寸默认取主窗口当前 bounds（与工作伙伴同一套 `createAuxPopoutWindow` 语义：单例、随主窗口关闭、frameless + 自绘窗钮）；窗口里是标题拖拽栏 + iframe + 开源声明/跳转按键。
- 设置页入口整体撤除：`settingsNav`、`HelpDialog` 总览、`capabilities.tsx` 页面注册、`SettingsPage` 联合类型、`SETTINGS_PAGES` 白名单五处一起删。
- 通道新增 `media-desk:popout`（preload `mediaDeskPopout`），`media-desk` 域仍只有自己的前缀。

## 依据
- 验收 `media-desk` 13/13：入口调用返回 ok；`?mediaDesk=1` 独立窗出现且只有 1 个；尺寸对照主窗（实测主窗 1296×808 / 独立窗 1296×808）；上游界面渲染；声明/主题/弹窗可见；设置页导航里已无该入口。
- 真机截图：`media-desk-popout.png`（标题栏「自媒体工作台」+ 原版界面 + 底部声明）。
- 守卫 12bi 37/37；三处变异（拆侧栏入口 / 改窗口识别参数 / 加回设置导航）全部抓红。

## 影响面
- 入口位置与打开方式变化；数据与 Codex 工具完全不变（同一 `mediaDeskRequest` / 同一 state 文件）。
- 设置页少一项；帮助总览少一项；侧栏多一项。

## 回滚
回退本轮提交即回到设置页 iframe 形态；数据不受影响。
