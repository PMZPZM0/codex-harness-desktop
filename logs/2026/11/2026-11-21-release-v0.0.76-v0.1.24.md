# 发版 v0.0.76 / PPcode v0.1.24（2026-11-21）

用户令：「打包发一下新版本，两仓同步，mac也同步发布」。

## 一、包内容（0.0.75 之后）

- **精选技能包装态修复**（3c76a7866）：随包包以前拿「源目录里有没有技能」当「用户装没装」⇒
  每台机器恒显示「已安装」、界面无「安装」按钮、装完看不出变化；且随包包不写包级凭据 ⇒ 装完卸不掉。
  改为 `installedBundledOf`（用户技能目录 + 凭据 packId）、下发 `bundledSkills` 与 `installed` 分离、
  随包包写包级 marker、卸载兼容旧安装、重启失败不报安装失败、前端按真实状态给安装/更新/卸载。
- **压缩后「等待模型回复」行消失**（82e695d1f）：结算判据反转 fail-safe（回合找不到不结算）。
- **更新链三处断点**（9383c0fb7）：主窗口加载完成重放快照 / 包丢失回落 failed / NSIS 用 `--updated`
  识别更新路径跳过旧全机安装拦路。
- **首回合瘦身**（651ba2846）：内置 MCP 走网关按需调用、常驻指令精简。
- **语音播报硬超时**（26dda8c11）：不再卡「正在播报」。

## 二、门禁

- 两仓 `npm run build` 全绿；批量守卫（不中断跑法）113/113；完整 `npm run check` EXIT=0。
- mac 审计：主仓 4 条、PPcode 4 条，逐条判读（说明文案里的 Windows 示例路径 / JSON 转义正则 /
  同段重复归类）**无真缺口**，脚本自带正则自证；结论已写进两份发版说明。
- **本轮首次把 `build/installer.nsh` 的 `--updated` 判据带进 CI 打包**：本机 electron-builder
  解包阶段被 EPERM/EBUSY 卡死（环境问题），只能用缓存里的 `makensis` 单编验证语法；CI 真编译通过
