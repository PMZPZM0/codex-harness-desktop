# 发版 v0.0.74 / PPcode v0.1.22（2026-11-21）

用户令：「更新彻底删了，重新做，一点残留不要」→「两仓同步发布新版本，发版技能更新一下，现在没有差分更新功能了」。

## 一、包内容（主仓 5f5efb56f + 70507cbc9 / PPcode ac0e3897 + f12cfc63）

- **更新链整份重写**：旧实现（updates.ts / updates-ipc.ts / update-splash.ts + 渲染层三个组件）全删，
  新状态机 `update-service.ts`（idle→available→downloading→ready→installing）+ `update-ipc.ts`
  三通道（check / download / install）+ 一条推送；跨重启保持 ready（`update-state.json`）。
- **安装包认领**：下载前先校验复用 + `adoptLegacyPackage`（sha512 流式比对旧目录同版本包），
  修「下载到 100% 又重下」「自动重启后又要重下」的无限循环。
- **安装动作**：`spawn(exe, ["--updated"])` → 等 900ms 确认进程存活 → 退出；不再静默 `/S`，
  安装器自带进度窗口（用户令「安装要有进度」）。
- **记忆金字塔连根拔**：`MEMORY_PYRAMID` / layerWatermarks / PyramidView 等前后端 + 死样式全删，
  记忆工具与技能文案全部对齐新版记忆架构。
- **差分更新删除**：CI 资产 blockmap / latest.yml 改软挑；`jobs.mac` 条件修为
  `push || inputs.with_mac`（push 下 inputs 为空，旧写法把 mac 静默跳过）。
- 发版技能 `codex-harness-release-publish` §0.5 重写为「只有完整包」口径。

## 二、判据

- 两仓 `npm run check` EXIT=0；`tsc electron` / `npm run build` 全绿。
- 新守卫 `12e-app-update.mjs` 19/19（含 electron-updater / blockmap / download-silent 等
  旧概念全仓 0 命中的负向断言）。
- 用户机器仍停在 0.0.73（坏链路），需手动安装一次 0.0.74 才能走新链路。
