# 发版 v0.0.75 / PPcode v0.1.23（2026-11-21）

用户令：「内置的都要能更新」→「Playwright 浏览器自动化更新一下…更新 codex 引擎」→「两仓同步发布，mac 一起，更新日志就写修复已知问题」。

## 一、包内容（19548fad6 / 69454a88 + 版本提交 e626fd4f3 / d5935934）

- **台账收编**：`agent-desktop`（默认桌面后端，原先只在电脑操作卡片能更新）、`feishu-cli`
  进 `COMPONENT_SPECS`；Ego Lite 从编排层手工行收编为 `kind: "external"`（官方更新器执行），
  `updateRow` 特判删除；后台循环按 `kind === "external"` 判断「无版本号也跑」。
- **Playwright**：进 `UPDATEABLE_TOOLS` + 台账；放行 postinstall，浏览器下载强制
  `cdn.npmmirror.com/binaries/playwright`；⛔ 不进后台自动更新（约 300MB）。
- **引擎**：两仓 `@openai/codex` 0.167.0 / 0.170.0 → **0.171.0**（`^0.171.0` + lock）。
- 守卫：12l 新增第⑭节 5 项；12k Ego 断言改查台账；265 棘轮两仓 1315→1323 实测记账。

## 二、本机实装与实测

- `agent-desktop@1.3.1` 装进 userData npm-global（`--allow-scripts` 才跑 postinstall）；
  Playwright 1.65.1 + Chromium 159（124MB 镜像 CDN）`chromium.launch()` 实测可用。
- 清掉 check 守卫卡住的 3 node + 3 codex.exe 残留（保留 WorkBuddy 自身的）。

## 三、发版核验（匿名视角）

- 主仓 CI success；资产 5 件全 uploaded：win exe 672.2MB / arm64-mac 906.3MB / x64-mac 911.9MB
  + blockmap、latest.yml（软资产）；latest.yml size 704813220 与 exe 一致。
- PPcode CI success；win exe 673.2MB / mac 两件 897.2 / 913.4MB，latest.yml size 705869350 一致。
- mac 审计：主仓 0 命中；PPcode 63 条逐条判读无真缺口（门控 / 注释 / 夹具）。
- 更新日志按用户令只写「修复已知问题」（应用内要点 3 条 + Release 正文同口径）。
