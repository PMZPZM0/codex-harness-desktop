# v0.0.82 发布：右栏放大改为绝对定位覆盖 + 同大版本依赖升 7 项

## 背景

右栏「放大」按钮连续三版都不对（用户连拍四张：主区被压成 20px 竖排、跨列后仍是一条缝 + 空白）。
本轮同时积累了两个版本（v0.0.81 之后 25 个提交）：中枢/团队会话归位、无限画布重构、生图参数对齐。

## 结论

1. **放大 = 绝对定位整块覆盖**：`.context-panel[data-max="1"]` 走 `position:absolute`，
   `left:calc(var(--side-w,236px)+3px)` / `right:bottom:0` / `top:50px`；网格一列都不动
   ⇒ 主区在底下原样待着（滚动位置、草稿都不丢），面板用不透明背景盖住；缩回 = 撤属性回第 4 列。
   ⛔ 三条旧路全部钉死：压窄列宽（`--right-w` 吃满整行）/ 跨列 `grid-column:2/-1` / 藏主区。
2. **弹窗（popout）单独覆盖**：绝对定位的 grid 子项一旦带 `grid-column`，containing block 变成
   那个 grid area（宽 = `--right-w`）⇒ popout 里会塌成 308。用
   `.app-shell.popout-shell > .context-panel[data-max="1"]{grid-column:auto;grid-row:auto;left:3px}` 撤掉。
3. **依赖**：同大版本升 7 项（飞书 SDK 1.77 / jimp 1.7 / lucide 1.81 / sherpa-onnx 2.0.3 /
   vite 8.4 / @types/node 26.6.11 / @types/react 19.3.3）；electron 留 44.2.0（跨 11 个 minor +
   原生模块 ABI，单独一轮）；@xyflow/react 13 / jimp 2 / typescript 7 属跨大版本不动。
