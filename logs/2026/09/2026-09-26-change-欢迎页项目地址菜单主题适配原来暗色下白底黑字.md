# 欢迎页项目地址菜单主题适配（原来暗色下白底黑字）

主题色适配：欢迎页项目地址菜单（welcome-cwd-chip / welcome-cwd-menu）

用户 09-26 截图：暗色主题下该菜单白底黑字（亮色 fallback 永远生效）。

根因：整块样式引用了从未定义的变量（--color-background-primary / --color-text-primary /
--color-border-tertiary / --text-secondary / --blue —— 全仓库没有一处定义）⇒ 永远落亮色 fallback。

修法：换成主题真 tokens（--bg/--panel-2/--line/--text/--muted/--faint/--accent(--soft)/--shadow，
:root[data-theme=dark] 有整套暗色值），与 composer-quick-pop 菜单同一模式。

验证：真机 CDP 双主题计算值——亮色逐值不变（#ffffff/#23231f/…回归零），
暗色 menuBg=#1b1b1a、itemText=#ececea、activeBg=rgba(124,171,248,.12) 全部跟随；
守卫【160】3 条（负向断言不许退回未定义变量），变异测试红；
预检 0 条真红。波及面报告：同病残留还有 --blue 25 处、19-misc-hints 的 --color-* 2 处
（亮色 fallback 在两主题下尚可看），待用户拍板再全库扫。
