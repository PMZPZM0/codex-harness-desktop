# 专家团办公室 v4「活起来」：动画导演 + 员工交接 + 随机行为 + 家具动效

## 需求

「把这个办公室预览做好看一点，用点心，动画效果做出来，类似马维斯那种，各种员工之间交接做出来，
各种预设动画和随机动画」

## 现状

v3（09-25）是单张 SVG 静态插画 + 两个动作（打字 / 打盹）。形状站住了（v2 的 div 色块被否），
但**人是死的**：没有时间维度、没有员工之间的互动。

## 做法（v4：给形状加上时间维度）

team-office 域内新增 4 个文件：

- `office-director.ts` —— 动画导演（纯逻辑：不 import react、不碰 DOM、不认识名字）。
  每 1.2s 一拍产出姿势快照。工作中 → 敲键盘（偶发查资料/看消息）；空闲 → 喝咖啡 / 伸懒腰 /
  看手机 / 打盹 / 翻资料（随机抽 + 随机时长 + 三种变体）；另有 10% 概率**串门**（走到同事工位旁
  并顺带递一份资料）、10% 概率**跑腿**（接水 / 翻资料架 / 打印）。随机源可注入（固定种子可复现）。
  **交接两层**：真实层 = 运行态迁移（idle→running 派任务、running→idle 交成果）；
  装饰层 = 串门递资料 / 同事间对口径。同屏最多 3 条飞行（多了像弹幕）。
- `office-palette.ts` —— 色板 + 按成员序号**稳定派生**的外貌（肤色/发色/三种发型/眼镜/衣色/领子）：
  同一成员每次进办公室都是同一张脸，不是每帧随机。
- `OfficeWorker.tsx` —— 两套互斥呈现：坐姿（六种姿势）与站姿全身小人（串门/跑腿，带走路 bob
  与手臂摆动、可拿资料）。⛔ 手必须是手臂的**子元素**，否则抬手臂时手留在原地（一眼穿帮）。
- `OfficeFurniture.tsx` —— 窗（云漂 + 城市剪影）、白板（笔画逐条画出来 + 便签）、
  挂钟（秒/分针 + 钟摆）、吊灯（轻摆 + 光晕呼吸）、书架、饮水机（水泡上升）、打印机（吐纸）、
  盆栽（叶片摇）、地毯、地板木纹。
- `OfficeScene.tsx` 重写：动态 viewBox（多行自适应）、工位布局、走动小人在场景层按地面坐标走、
  交接卡片沿 `animateMotion` 弧线飞行 + 落点脉冲 + 接收者惊叹号。

## 三个必须钉死的点（守卫【168】10 条）

1. **导演是纯逻辑**（不 import react / 不碰 document/window）⇒ 决策与渲染解耦，能离线写断言。
2. **快照单源**：导演在弹窗层持有，场景只收 snapshot prop —— 否则会出现「画面里在喝咖啡、
   右栏写着编码中」。
3. **走路必须是真的过渡**：`transform: translate(var(--wk-x), var(--wk-y))` + CSS transition。
   ⛔ 写 SVG transform 属性是瞬时的，人会「闪现」到终点（第一版就是这样）。

## 验证（这轮的判据是「看见」）

纯视觉改动，靠读代码判断「好不好看」不成立 ⇒ 搭一次性离线预览：
vite dev（root 指到 .workbuddy/tmp）把 OfficeScene 单独挂起来 + Windows 自带 Edge headless + CDP
按**真实时间**多帧截图与 DOM 采样。
⛔ 不能用 `--virtual-time-budget`：虚拟时间会把定时器与 SMIL 动画全部快进到结束态，截出来是错的。
⛔ Electron 在本环境启动会被沙箱拦（GUI 子系统进程），Edge headless 是可行替代。

实测（CDP 采样）：
- 姿势在换：work → note → phone → coffee（mugs:1）→ stretch
- 交接三连都出现：派任务 / 交成果 / 递资料，卡片坐标随时间变化（animateMotion 生效）
- 走动小人 transform 从 692 → 202 → 63 → 60 逐步收敛到目标点 ⇒ 真的在走，不是闪现
- 落座：从串门回来时补了入场动画（否则是闪回座位）

## 判据

tsc 0 错；预检 0 条真红（其中【160】CSS 变量对账抓到 `--wk-x/--wk-y` 只引用未定义，已给默认定义）；
验收 4/4；守卫【168】10 条 + 变异三条（派发交接改类型 / 走动改回写属性 / 场景不渲染交接）全部能红。
