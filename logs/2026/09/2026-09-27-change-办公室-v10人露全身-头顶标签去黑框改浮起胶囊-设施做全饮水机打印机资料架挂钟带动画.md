# 办公室 v10：人露全身 + 标签去黑框 + 设施做全并配动画

## 用户四条诉求（原话）
1. 「人坐哪里的时候，能不能把身体展示全」
2. 「对应的桌子…啥都配置动画，都做全」
3. 「饮水机」
4. 「头上那个黑框框太丑了，换一种表达方式」

## 做法

### ① 人完整露出（头 + 躯干 + 手臂 + 椅子）
三处**联动**参数（改一处必须一起看，注释里已钉）：
- `PERSON_K` 0.58 → **0.72**（人放大回正常比例）
- `SEAT_LIFT` → **90**（人的脚落在桌面上方 4px ⇒ 整个人在桌面之上，不被家具切）
- 桌子**降高** 46 → 38、显示器 **52×31 → 44×22**（家具变矮，给人和标签腾出竖向空间）
- 工位行距 **133 → 147px**（`office-iso.deskSlots` v 0.20~0.86）—— 装得下「标签 + 人」

⛔ 同时把人物 zIndex 定在**家具之前**（`slot.y - 0.55` vs 家具 `slot.y - 0.4`）：
人后画会让**腿叠在显示器上**（实测截图确认），家具挡人才是参考语言的正确表达。

### ② 头顶标签换表达（去掉黑框）
原来是 124×36 白底 + 深色描边圆角框（用户：「黑框框太丑」）。
改为**无描边的浮起小胶囊**：白底 95% + 偏移 2.5px 的柔阴影 + 状态点（运行绿带脉冲环 / 空闲灰）
+ **单行**「● 名字  动作」，宽度按文字自适应（不再是固定尺寸框）。
参考画面里标签也是靠阴影"浮"着，没有线框。

### ③ 设施做全 + 全部带动画（`office-render.drawAmenities`）
| 设施 | 位置 | 动画 |
|---|---|---|
| 饮水机 | 与 director 的 errand `water` 同点 (0.84, 0.62) | 水桶内 3 个气泡循环上升淡出 |
| 打印机 | 同 `printer` 点 (0.80, 0.16) | 出纸口往复吐纸 |
| 资料架 | 同 `shelf` 点 (0.18, 0.13) | 彩色书脊静态陈设 |
| 挂钟 | 后墙 (0.508, 104px) | 分针/时针真的在走 |

⛔ **位置与跑腿目标同源**：员工「去接水」会真的走到饮水机旁 —— 设施画在 `ERRAND_SPOT_UV`
那个点上，渲染层不另定坐标（两边漂移就穿帮）。
动画部件用 `PropTicker[]` 返回，由 `animateScene` 里 `scene.props.forEach` 逐帧驱动
（与人物动画共用同一个 ticker）。

## 守卫
