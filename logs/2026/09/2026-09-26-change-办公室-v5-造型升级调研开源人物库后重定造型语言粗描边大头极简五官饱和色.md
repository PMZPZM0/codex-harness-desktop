# 办公室 v5 造型升级：调研开源人物库后重定造型语言（粗描边/大头/极简五官/饱和色）

## 需求

用户两次反馈：「人物还是好丑哦，去 GitHub 看看有没有类似卡通人物」→「办公室场景也很丑」。

## 调研（真的去看了现成库）

- **DiceBear**（代码 MIT / 各风格独立许可，63 种风格，可 npm 离线生成）
- **open-peeps**（Pablo Stanley，CC0，手绘风，官网有半身/全身/坐姿三类）
- **avataaars**（MIT，卡通头像）、**notionists**（扁平黑白）

实际下载样本 SVG 并渲染对比后确认两件事：

1. **不能直接采用**：这些库输出的都是**半身或头像**（viewBox 704×704 正方形），而且 DiceBear
   产出的 SVG 是**扁平化**的（16~31 个元素、只有 `viewboxMask` 一个 id，无部件分组）
   ⇒ 拆不出可动画的手臂，没法用在工位上做「坐姿 + 打字 / 抬杯 / 伸懒腰」的**部件级**动画。
2. **但造型规律可以照抄**：粗描边 + 大头 + 极简五官（点眼 + 高光 + 短线嘴 + 眉毛）+ **饱和纯色**。

## v4 丑在哪（对着参考逐条复盘）

- 人物：描边 2.4 太细（像线稿没画完）、五官太碎（腮红/耳朵/领口/腰带堆叠）、头偏小、眼睛小没神；
  手臂压在躯干两侧且同色 ⇒ 放大看像「背带裤的两根背带」；打字动画围绕**垂直线**摆 ⇒ 像摊手不像打字。
- 场景：配色一路往淡调（墙 #eef3f9 近乎白、地板 #f5ebdd 灰米、地毯 #e8d6c0 与地板几乎同色）⇒ 整屏像褪色照片；
  墙纸铺了 40 条竖纹（纯噪音）；所有元素一个明度、没有纵深。

## v5 改了什么

**人物**（OfficeWorker.tsx）
- 描边统一 `INK_W=3.2`（细节线仍 2.2）；头径 17.5 → 20.5；眼睛 2.1 → 3.1 并加白色高光；补眉毛；删腮红。
- 手臂移到躯干**外侧**（只搭 3px 在肩上）+ 袖子压深一档（brightness .9）做层次。
- 打字动画角度改为围绕「朝桌前伸」的基准（左臂负角 / 右臂正角 —— 符号写反就会变摊手）。
- 中分发型不再单挂两片鬓角（放大后像戴耳机，已合进整片头发）。

**场景**（OfficeScene + OfficeFurniture + 色板）
- 配色重定：墙分上下两段（腰线做层次）、暖木地板、明确的地毯色、墨色加深一档。
- 删掉 40 条墙纸竖纹；地板木纹改宽板稀疏（去噪）；书架/饮水机/打印机结构精简。
- 家具统一退到「后排」（y 200~310）、工位在前排（y 370+）⇒ 靠 y 序形成纵深；每件家具加落地投影。
- 吊灯加灯罩 + 光晕；白板线条加粗、便签减少；窗加大（太阳 + 云 + 城市剪影）。
- CEO 头顶浮标改**桌沿徽章**（原浮标与白板/吊灯抢墙面位置）。
- 显示器 58×44 → 52×40（原来比人物头还大），偏移跟着工位宽度走。
- 马克杯改「杯身 + 把手 + 咖啡液面」（原来只画一个白方块，被看成一张纸）。

## 判据（这轮靠「看见 + 定位」而不是靠读代码）

一次性离线预览（vite dev + Edge headless + CDP 按真实时间截图），并逐轮做**几何诊断**：

- `bbox 相交`：CEO 显示器与他头部重叠 **17×35px** ⇒ 调偏移后 **0**（修好并复验）。
- `elementFromPoint` + 全元素相交扫描：确认「脸上那块白」不是遮挡而是显示器尺寸/位置问题
  （先怀疑遮挡、被数据否掉，再改尺寸才解决问题 —— 避免了瞎改）。
- 放大截图（CDP clip + scale 2.6）暴露了三个只能"看"才能发现的问题：
  显示器挡脸、手臂像背带、鬓角像耳机。
