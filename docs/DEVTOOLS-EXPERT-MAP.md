## 一、判定标准（三条全过才算"已联动"）

1. **有专家**：`expert-teams.json` 里真实存在的专家或专家团（不是文案里提一句）；
2. **有清单**：该专家声明了至少一个**技能**（skills）与一个**专业工具**（tools）；
3. **有串联**：工具卡上有一条「交给 X 专家」的动作（开该专家会话 + 预填任务），⛔ 不是只给安装按钮。

## 三、建议新建的 9 个专家（缺口 → 专家）

> 命名沿用现有体系：中文名（2 字）+ 岗位。技能列的是本机/仓库里**真实存在**的技能包；
> 工具列的是"开发工具"页里已能装的东西。⛔ 不再新增第三个真相源。

### ① 桌面自动化工程师 ·「掌舵」
- **工具**：`computer-use`、`nuphus`、Ego Lite（浏览器自动化）
- **技能**：`ego-browser`、`computer-use-acceptance`
- **第一任务**：「打开这个网址，走到下单页，截三张图并报告每步耗时」
- **联动**：工具卡 →「交给掌舵」→ 会话预填；产出图自动进产物档案

### ② 环境工程师 ·「筑基」＋巡检
- **工具**：Git / PowerShell 7 / Miniconda / MinGW / Docker / OpenSSL；**工具自检与清单 / 当前能力链路 / Laya**
- **技能**：`codex-engine-config-probe`（版本与配置探测）、环境诊断类
- **第一任务**：「把这台机器的开发环境体检一遍，缺什么列清单并给安装命令」
- **联动**：自检面板「交给筑基」→ 会话直接带体检结果

### ③ 文档工程师 ·「转文」
- **工具**：`markitdown`、Filee、`bundled-tool`（pandoc/ffmpeg）
- **技能**：`month-report`（月报结构）、`lark-doc`（文档读写）
- **第一任务**：「把这 5 个 PDF 转成 Markdown 并出一份对照表」

### ④ 知识库管理员 ·「编目」
- **工具**：`kb-embedding`
- **技能**：`harness-memory-and-skills`（记忆/技能落点）、知识库检索（bigram 中文分词）
- **第一任务**：「把这些资料建成知识库，问 3 个问题验证召回」

### ⑤ 移动端工程师 ·「掌控」
- **工具**：`phone-harness`、ApkStart、Husk
- **技能**：adb/scrcpy 截图、侧载流程
- **第一任务**：「连上手机，装这个 APK 并截图首屏」

### ⑥ 办公协作 ·「通译」
- **工具**：飞书 CLI（`@larksuite/cli`）
- **技能**：`lark-im` / `lark-doc` / `lark-sheets` / `lark-calendar` / `lark-task` / `lark-approval` …（23 个）
- **第一任务**：「把这个群的待办整理成任务，同步到飞书任务与日历」

### ⑦ 视觉设计 ·「造物」
- **工具**：Craft 全家桶（19 App）、`image-lab`
- **技能**：`frontend-ui-design`、`buddy-image-processing`
- **与画意的分工**：画意 = 电商生图（单品/主图）；造物 = 视觉体系（品牌/版式/动效）
- **第一任务**：「按这个品牌词做 3 套视觉方向 + 落地页首屏」

### ⑧ 音乐制作 ·「谱声」
- **工具**：MoeKoe（酷狗 API）、`bundled-tool`（ffmpeg）
- **技能**：音频处理/转码
- **第一任务**：「找 5 首同风格参考曲，分析 BPM 与结构」

### ⑨ 课程设计 ·「讲席」
- **工具**：OpenMAIC
- **技能**：课程大纲、测验生成
- **第一任务**：「把这个主题做成 6 节互动课，含测验与模拟」

## 四、落地顺序（建议）

1. **P0：先建 ② 筑基 + ① 掌舵**——覆盖工具自检、环境、桌面自动化三块最高频的"装了不会用"；
2. **P1：③ 转文 + ④ 编目 + ⑥ 通译**——办公与内容侧的日常刚需；
3. **P2：⑤ 掌控 + ⑦ 造物 + ⑧ 谱声 + ⑨ 讲席**——垂类。

每建一个专家，同步做三件事（缺一不算完成）：
- `expert-teams.json` 写入专家/团队（lead + members + profession）；
- 在专家卡上声明 `tools[]` 与 `skills[]`（缺的显示「一键安装」）；
- 对应工具卡加「交给 X 专家」按钮（开会话 + 预填首个任务）。

## 五、守卫（防回归）

- 【devtools-expert】新增卡片时，必须在文件头映射表里出现一行（否则红）；
- 缺口表是**棘轮**：条目只减不增（新增工具却没专家的会被计数）；
- 专家卡的 `tools`/`skills` 里每个 id 必须能在 registry / skills 目录里找到（⛔ 编造即红）。
