# v0.0.42 发版说明

本版主题：**云账号从"能用"做到"可靠"** —— 登录不再踢设备、会话同步真正落地、知识库 401 根因修复，另加 HTML 预览板块与一批引擎维护。

> 版本号说明：0.0.41 之后直接到 0.0.42，中间无跳号。

## 一、修了什么

### 1. 知识库连接 401（根因修复）

**现象**：配置好知识库与记忆空间后，连通测试报 401，连接器用不了。

**根因**：连接器令牌只在启动时读一次环境变量，且请求头少了 `Bearer ` 前缀——服务端收到的是裸 token。

**修法**：每次启动都注入 env，请求头补齐 `Bearer` 前缀。

### 2. 登录会把同账号另外两台设备踢下线

**现象**：同一账号在两台以上设备登录，先登录的那台突然掉线。

**根因**：每次登录都强制重签密钥（`force: true`），旧设备的凭据立即失效。

**修法**：改为**先尝试非强制同步、失败才重签**；手动「重签密钥并同步」按钮保留，需要主动踢人时仍可用。

### 3. 会话同步：勾选被静默忽略

**现象**：在同步弹窗里取消勾选某些分类，实际仍然全部上传/下载。

**根因**：`pull` 的第二个参数是 `{ keys }` 对象，代码里按数组判断（`Array.isArray(keys)`），恒为 `false` ⇒ 选项被整体丢弃。

**修法**：按对象解构取值。同步弹窗同时改为独立浮层（原来 `fixed` 被设置面板的 `transform` 降级成相对祖先定位并被裁切，看起来像内嵌）。

### 4. 云账号页登录按钮看不见

**现象**：未登录状态下登录按钮背景透明、文字是白的，等于隐形。

**根因**：样式里用了 `var(--brand)`，但项目里**不存在**这个变量 ⇒ 整条规则失效。

**修法**：改用全站主色 `var(--accent)`。同时优化了输入框圆角、焦点环与折叠行默认三角。

### 5. 右栏「变更」四个范围显示不对

**现象**：切换「未暂存 / 已暂存 / 未跟踪 / 全部」时列表内容不跟随。

**根因**：四个范围共用同一份取数逻辑；顺带修了 IPC `minArgs` 把 12 条通道拒死的问题（参数校验过严 ⇒ 调用直接失败）。

### 6. 引擎侧维护（用户不可见，但影响长期稳定性）

- **SQLite WAL 定期 checkpoint**：WAL 文件不再无限增长。
- **引擎日志库归档**：保留 14 天 + `VACUUM`，避免历史库把磁盘吃满。
- **IPC 参数校验测试**：生成器的 `minArgs` 规则 + 真实 manifest 全量校验。

## 二、新增

### HTML 预览板块

写 HTML 时自动在右栏打开预览，可加宽、保存即实时重载。独立板块，不占用既有右栏面板。

### 新手 / 高级双教程

新手引导拆成两条路径：首次使用者走基础流程，老用户可直达高级配置。

### 设备上报

登录时上报 `machineId` / `machineName` —— 云端设备列表从此能区分来源（此前恒为 0 台）。

### Laya 判断工具

给 Codex 一个可调用的本地判断工具（仅在安装后暴露）。

## 三、mac 适配审计结论

运行 `node scripts/mac-audit.mjs v0.0.41 HEAD`，正则自证 8 条全部通过（0 命中是"真的没有"，不是正则坏了）。

命中 **71 条**，逐类判读结论：

| 类别 | 条数 | 判读 |
|---|---|---|
| `winpath`（Windows 绝对路径） | **0** | 最危险的一类，实际为零 |
| `exe` | 10 | 全部是 `toolExists("x.exe") \|\| toolExists("x")` 双写法兜底，mac 走第二支 |
| `ctrl-key` | 8 | 断言夹具，或 `ctrlKey \|\| metaKey` 的正确跨平台写法 |
| `backslash` | 39 | 正则字符类 `[\\/:*?"<>|]` 用于清洗文件名，不是路径分隔符 |
| `powershell` | 3 | 类型定义与注释 |
| `appdata` | 1 | `USERPROFILE \|\| HOME` 双兜底 |

**结论：无真缺口。**

## 四、mac 首次打开自救（带路径）

未做 Apple 公证，首次打开会被 Gatekeeper 拦下。

1. 在「下载」里解压 zip；
2. 把应用拖进「应用程序」；
3. 打开「终端」，**把应用图标直接拖进终端窗口**（自动填出你的真实路径，不用手写）；
4. 在拖出的路径前面加上 `xattr -cr `，回车：

```bash
xattr -cr "/Applications/Codex Harness Desktop.app"
```

5. 重新双击应用即可打开。**只需执行一次**，升级后不用重复。

**如果提示错误 640**：说明当前用户对该 app 无写权限，改用 `sudo xattr -cr <路径>` 并输入密码。

**不想用终端**：在「系统设置 → 隐私与安全性」页面底部点「仍要打开」，效果相同。

## 五、已知问题

- **`jvszzp.ltd` 发布页偶发慢**（Cloudflare 跨境回源），下载页已把图片切到直连域缓解；页面本身仍可能等待数秒。
- **亮色主题下部分边框偏弱**：`rgba(255,255,255,.0x)` 类硬编码在浅色背景上几乎不可见，属观感级问题。
- **会话同步走账号 token 时 `machineName` 为空**：多设备来源仍无法完全区分。
- **知识库/记忆上游需自行部署**（WeKnora / TencentDB Agent Memory），对接说明见云端管理面板内「对接指南」。
