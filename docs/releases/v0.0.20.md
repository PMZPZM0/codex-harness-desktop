# Codex Harness Desktop v0.0.20

> 本文件是应用内「发现新版本」弹窗展示的更新说明，由 `.github/workflows/release.yml` 读取。
> 每次发版都要新建 `docs/releases/v<版本>.md`（缺失会直接让发布 job 失败）。

## mac 全面适配（第二轮）

- **语音首次取麦不再闪退** —— 之前 mac 上一开语音通话 / 听写就整个应用退出：系统要求 App 声明麦克风用途，缺声明时 macOS 是**直接终止进程**而不是弹授权框。已补上声明，现在会正常弹系统授权框。
- **关窗后点 Dock 图标重开，应用仍然完整可用** —— mac 上关掉窗口不等于退出，之前关窗会把后台引擎、本地服务、调度器一起停掉，重开的只是一个空壳窗口（发不出消息、手机连不上）。现在 mac 上关窗保持后台运行，真正退出时才清理。
- **手机扫码配对恢复可用** —— mac 版此前没带公网隧道程序、路径也只按 Windows 找，导致公网地址从不启用、只能同 WiFi 局域网。现在 mac 包内置对应芯片的隧道程序。
- **渠道语音消息（如飞书语音）能正常转写** —— mac 上找不到音视频转码程序，已按 mac 布局修正。
- **app 内快捷键提示全部显示 ⌘** —— 包括语音通话的默认快捷键（现在是 ⌘⇧M）与设置面板里的录音快捷键；自定的组合键在 mac 上也按 ⌘ 记录与识别。
- **「开发工具」页文案按平台修正** —— mac 上不再显示「安装 Git 约 90 MB」（mac 用的是系统自带 Git）、Docker 说明改为 Docker Desktop、装了 Docker 也能正确识别为已安装。
- 终端面板在 mac 上使用 shell 风格提示符（不再是 PowerShell 风格），并正确按 POSIX 规则解析工具路径。

## 调度

- **一键释放调度**：调度面板被其他会话占用时，新增「释放并删除该会话」——确认后先把调度权收回，再删除那条旧调度会话（连消息、工具记录与成员会话一起清理）。
- **修复「都关掉了还提示被别的会话占用」**：被占用提示会一直挂在一个已经找不到的旧会话上（永久占着调度权、没有入口能关）。现在会话被归档/删除时会自动清掉它的调度记录，界面发现占用者已不在会话列表也会自动释放。

## 消息与界面

- **发送消息不再「先看到旧内容、过一会儿自己的消息才冒出来」**：发送后自己的消息会立刻出现并保持在界面上，直到引擎回声接管（此前它只闪现几毫秒就被收回，中间 2~3 秒看不到自己的消息）。
- **发送动画不再中途卡断**：入场动画现在由接管它的真实消息接着播，并按已过去的进度续播，不再从 0% 重来一遍。
- **排队消息点「立即发送」不再必报错**：以前在上一轮已结束（失败/中断）时会拿过期的回合去插队，必失败且消息卡在队列里；现在会先确认真的有回合在跑，引擎侧没有活动回合时自动改为开启新回合。
- **生成状态条不再跑到刚发出的消息上方**，顺序与真实阶段一致。
- **弹窗自适应**：执行计划/待办清单、429 限流重试条不再被右侧或左侧裁掉，窄窗口下文案完整换行；附件/快捷菜单、浏览器抽屉、上下文弹层里的长名字也做了防护。

## 安装说明

### Windows

下载 `Codex.Harness.Desktop-0.0.20-win-x64.exe` 直接安装。安装包**未做代码签名**，首次运行若出现 SmartScreen「未知发布者」提示：点「更多信息」→「仍要运行」。

### macOS（未签名）

下载对应芯片的 zip，解压后把 App 拖进「应用程序」：

- Apple 芯片（M 系列）：`…-arm64-mac.zip`
- Intel：`…-x64-mac.zip`

首次打开若被 Gatekeeper 拦住：

1. **右键**点 App → 选「打开」（不要双击）；
2. 或在终端执行：`xattr -cr "/Applications/Codex Harness Desktop.app"`。

首次使用语音通话 / 听写时，系统会询问麦克风权限，选择「允许」即可。

### 应用内更新

Windows 版可直接在应用内「检查更新」下载并安装。macOS 版请手动下载替换（更新包未签名，应用内自动替换会被系统拦截）。
