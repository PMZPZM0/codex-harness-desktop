# v0.0.69 发版说明

本版主题：**安装过程看得见了** —— 点「立即重启」后出现安装器自己的进度窗口。

> 如果更新提示先出现 0.0.68：**直接跳到本版**（0.0.68 的进度窗实现不可靠，见下）。

## 一、两周没解决的原因（两层，之前只修了其中一层）

用户两次报「安装的时候没有进度条提醒」，其实是两个独立问题叠在一起：

**第一层：安装本身经常失败。** 静默安装被 `installer.nsh` 的「旧版全机安装」提示框拦住
（`MessageBox` 没人看得见、`Quit` 照常执行），`taskkill /T` 之后又只等 0.8 秒，文件还被占用。
失败时应用已经退了 —— 自然什么都看不到。**这一层 0.0.67 已修**（静默模式不拦路 + 连杀两次 + 等 1.6 秒）。

**第二层：即使安装成功，也没有任何窗口。** 因为我们传的是 `/S`（完全静默），
而先前的「自绘小窗」两个实现都不可靠：

| 实现 | 为什么不行 |
|---|---|
| PowerShell + WinForms（11-16 起） | `Add-Type` 现场编译 C#，冷启动 **2–4 秒**；静默安装 5–10 秒就结束 ⇒ 窗口出现时已经装完。精简系统缺 csc.exe 时编译失败还会被 `SilentlyContinue` 吞掉 = 完全无窗 |
| 独立 Electron 入口（0.0.68） | 打包后的 exe 是否接受「脚本路径」当入口没有保证，赌错就是第三次没弹窗 |

**本版解法：把 `/S` 去掉，让安装器自己显示进度页。**

- 差分路径：`quitAndInstall(false, true)`（非静默 + 装完自动启动）；
- 完整包路径：`spawn(exe, ["--updated"])`（同样不带 `/S`）；
- oneClick 安装器（`nsis.oneClick = true`，守卫 12h 钉着）只有 `MUI_PAGE_INSTFILES` **一个页面**：
  没有安装目录页、没有许可页、没有「完成」按钮 ⇒ 用户看到的就是一条真实进度条，装完自动关、自动启动新版本。
- 自绘小窗的两套实现**全部撤掉**（`electron/splash-main.ts` 删除，`update-splash.ts` 只留 macOS 通知）。
  ⛔ 守卫 12h 改为钉「两条路都不许带 `/S`」，防止有人把它加回去。
