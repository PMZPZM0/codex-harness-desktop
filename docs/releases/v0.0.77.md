# v0.0.77 发版说明

本版：修掉几处「卡住」，并把链接 / 文件与上下文弹窗做顺。

## 主要变化

- 语音模型卸载不再把应用卡到「未响应」：有进度，失败会说清哪个文件没删掉。
- 装语音引擎快数倍：Python 依赖换清华、PyTorch 换上交镜像；装成 CPU 版会直接报错，不再悄悄装错。
- OpenMAIC 安装不再卡在 20%：修掉 PostgreSQL 启动的等待死锁，任一步 3 分钟无输出会中止并说明原因。
- 上下文弹窗：鼠标可移进去；点图标常驻、点外面或 Esc 关闭；「压缩上下文」常驻，用量到 30% 可点（运行中不可点）。
- 正文与输入框里的网址自动变链接、文件路径可点开预览，群聊同款。
- 视频接口新增 Muse Video 1.0（Meta，文生/图生，10 秒 720p 带声音）。
- 卸载失败的提示延长到 9 秒，并在弹窗里就地保留。

## macOS

本版一并发布 arm64 / x64。首次打开被拦时：右键 → 打开；仍被拦就打开终端，输入 `xattr -dr com.apple.quarantine` 后**把应用拖进终端**补全路径，回车即可。

## 其它

- 组件体检：引擎 0.171.0 / nuphus 0.3.4 / agent-desktop 1.3.1 / ponytail v5.3.3 均为最新；open-computer-use 升到 1.1.5，lucide-react 升到 1.77.0。TypeScript 7 / Electron 45 / xyflow 13 属跨大版本，本轮不升。
- mac 适配审计：14 条命中全部在平台门控或跨平台正则内，无真缺口。
- 仍是完整包（Windows 约 670MB）。点「⬇ 更新」才会下载，不会在启动时自动下载或安装。
