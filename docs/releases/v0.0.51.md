# v0.0.51 发版说明

本版主题：**文件与命令卡片「点哪儿都通」，另加 CLI 智能体板块，mac 修掉三处硬伤。**

> 版本号说明：**0.0.48 / 0.0.49 / 0.0.50 的构建均未对外发布**，内容并入本版。上一对外版本是
> **v0.0.47（10-23）**，本版是之后约 600 个提交的合集，**装本版即可，不需要中间版本**。

## 一、主要更新

- **文件在哪都能打开**：卡片路径是死链时按「命令自己的 cd → 会话台账 → 扫盘找同名文件」三级找回；
  预览与编辑不再弹授权框，任意位置的文件直接可看、可改、可在文件管理器打开。
- **命令卡看得懂了**：图标按动作区分、重复文件名去重、文件名可点并联动右栏预览、改了文件后面标
  `+N −M`、运行中补「正在」；折叠头那个容易误会的红叉删掉了。
- **新增 CLI 智能体板块**：6 个本机 CLI 预设，可分类筛选、搜索、检测是否安装、复制安装命令；
  `@` 点名与派活都接通，成品回流到同一套验收流水。
- **`@` 列表跟着调度开关走**：没开通专家团调度时那一项置灰不可选，开关一开立刻恢复高亮。
- **侧栏功能入口可自定义**：默认加「开发工具 / 收藏夹」，入口可排序、可删、可收进「更多」；
  设置页可批量添加。
- **技能**：共享技能池改两段式、删掉占地方的汇总条；精选与第三方技能包按需下载（国内镜像 +
  字节进度 + 落盘回读校验），自动更新可用可卸。
- **飞书**：已配置后可「重新配置」换应用。

## 二、mac 适配审计结论

按惯例只扫本版新增行：脚本汇总 400 处模式命中、落成 273 条带位置条目，逐条判读后 **4 处真缺口，已修**：

1. mac 没有 `/proc` ⇒「清理上次遗留引擎」是死代码（孤儿引擎占着会话 writer）→ 改用 `ps -o comm=`；
2. 写死 `where` ⇒ 中枢「本机 CLI agent」整列显示未检测 → 抽 `binOnPath()`（win `where` / 其余 `which`）；
3. 写死 `cmd /c` ⇒ **派给 CLI 成员的活 100% 失败** → 非 Windows 走 `/bin/sh -c`；
4. `file-locate` 把 POSIX 的 `/` 当「盘根」⇒ 1.2s 扫整个文件系统且必进 `~/Library` → mac 退到
   「头两段」，并按绝对路径跳过 `~/Library` 等重目录。

其余命中都是断言夹具、注释、平台门控分支。⛔ 这 4 处**只做了类型检查与平台分支复核，没有 mac 真机回归**。

## 三、mac 首次打开自救（带路径）

未做公证，首次打开会被 Gatekeeper 拦。打开「终端」，**把图标拖进终端窗口**（自动补全路径），
在路径前加 `xattr -cr ` 回车：

```bash
xattr -cr "/Applications/Codex Harness Desktop.app"
```

只需一次，升级后不用重复。若提示 **错误 640**，是同一个 quarantine 属性，执行上面的命令后重开即可。

## 四、已知问题

- mac 未签名未公证，只有 `xattr -cr` 一条路；分发包不是 universal 二进制（资产名带 `x64` / `arm64`）。
- mac 的应用内更新仍是手动：下载 zip → 覆盖「应用程序」里的旧 app。
