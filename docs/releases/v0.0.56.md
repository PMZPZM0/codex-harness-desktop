# v0.0.56 发版说明

本版主题：**工作伙伴（群聊）全面对齐主对话 + CLI 智能体自动跟随你的模型配置。**（内容与 v0.0.55 一致，为修构建流水线重发）

> **版本号说明（必读）**：上一版 **v0.0.55 没有产出可下载的安装包，请用本版**。
> 原因不在应用代码 —— GitHub 的 `macos-14` runner 镜像已于 **2026-11-02 正式退役**，
> 而三个仓的 mac 构建矩阵都写死在这个标签上 ⇒ 任务一入队就被直接 `cancelled`，
> Release 建出来但资产为空。本版把矩阵标签改为 `macos-15` 并重发。
> v0.0.55 的 Release 保留作记录（无资产，勿下载）。

## 一、修了什么（按用户感知排序）

### 1. 工作伙伴（群聊）与主对话对齐
- **回合视图**：群里回复改成一回合一条消息、**逐条实时上屏**；过程收进大折叠挂首条，轮末出收尾汇总卡。
- **用量 / 推理 / 来源**：补齐主对话那三样 —— 用量页脚、推理浮窗（两种展示）、网页来源条。
- **交互一致**：复用主对话滚轮与「回到底部」、记录懒加载、思考档位按官方规格联动。
- **@ 与引用**：输入框 @ 变行内 chip；引用改居中弹窗可多选；伙伴资料卡、@ 候选面板、群内搜索各成独立板块；成员头像可自定义（只作用于本群）。

### 2. 群伙伴直接用本机 CLI 回话
- 群里的 CLI 成员改为**本地进程直接回复**，不再经引擎转交 ⇒ 更快，也不再「回了但没正文」。
- 修掉一批真实故障：**Qwen Code 协议不匹配（405）**、**Kimi 配置焊死在旧中转地址**、**Claude 注入错参数族（未登录）**、stdin 未关闭导致 Claude 等 3 秒且正文丢失。
- 出错时给「下一步怎么做」，不再甩原始 JSON。

### 3. CLI 智能体自动跟随模型配置
- **装好即配**：安装完 / 启动 / 切供应商都会把这台机器上已装的 CLI 配置跟上。
- **模型配置页「同步给 CLI」弹窗**：每个 CLI 一个定制按键 ——
  - Claude Code、iFlow：写自己的配置文件（`~/.claude/settings.json` / `~/.iflow/settings.json`），**提示密钥明文、仅本机**，需二次确认；
  - Codex、Kimi：重写配置，密钥不落盘；
  - Qwen 等：派活时自动注入环境变量；
  - Gemini、Comate、OpenClaw、Qoder、QwenPaw：如实标注「需自己登录」或「用它自己的模型」，不假装同步过。
- 写入修正：内容已一致算成功（不再假报失败）、用户配置是坏 JSON 时**放弃写入**（不覆盖原文件）、首次改动留 `.harness.bak`。

### 4. 远控与更新
- **手机看屏**（只读）+ 桌面可见提示与停止键；远控 RPC 白名单 + 运行中排队（入队 / 立即 / 撤回）。
- **组件更新加官方源兜底**：原来滞后镜像会把官方源挡在后面导致永远显示「已是最新」；现在所有候选源都查、取真正最大版本。19 个运行时依赖升到最新。

## 二、mac 适配审计结论

`node scripts/mac-audit.mjs v0.0.54 HEAD`：命中 115 条，逐条判读后本版新增逻辑**无真缺口**（平台门控 / 守卫夹具 / 页面文案）。CLI 相关两处命中为误报：`04-cli.ts` 的 `win32` 三元门控分支完整；`cli-command.mjs` 的正则 `\s` 被路径模式误判。

## 三、mac 首次打开自救（带路径）

1. 在「下载」里**双击解压** zip；
2. 把 `Codex Harness Desktop.app` **拖进「应用程序」**；
3. 第一次被拦时，**把图标拖进「终端」窗口** —— 终端会自动填出完整路径（不用自己敲）；
4. 在路径前加 `xattr -dr com.apple.quarantine `（后跟一个空格）回车；
5. 报 **错误 640** 时改用系统「归档实用工具」重新解压再放行。
