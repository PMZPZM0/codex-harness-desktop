# v0.0.26-a 发版说明

> 发布日期：2026-09-20　|　基线版本：v0.0.26

**这是 v0.0.26 的修订版（`-a`）**：修掉 5 个用户实测反馈的问题，外加本轮新增的一处界面提示与自动化能力加固。macOS 与 Windows 同步发布。

## 修复（均为用户实测反馈）

- **导入的会话改名不生效**（一直显示「导入：…」）。根因是两层：① 引擎在会话**收到第一条用户消息时会用消息内容覆盖会话名**，我们设的名字被它冲掉（改完立刻读也一样）；② 我们的乐观更新紧接着被一次整表刷新抹平。现在改名以**本地覆盖为权威**（与既有的「项目地址覆盖」同一机制），并在**所有**引擎回包落地处贴回，重启也不丢。
- **视觉插件「配好了不生效」**。`[mcp_servers.nuphus]` 段此前**只有 command/args、没有 env**，插件里配的 baseUrl / apiKey / model 根本没进 nuphus 进程 —— 而 `desktop_vision` 读的是 `NUPHUS_MCP_VISION_*` **环境变量**，不是我们那份插件配置。现在按插件配置下发（provider 恒 `openai`，与插件同为 OpenAI 兼容协议），并加**漂移检测**：改 key / model 后配置会自动重写，不用等重启。
  - 顺带说明：**「调用就空转」是它的症状**，不是独立故障 —— 视觉通道是死的，模型只能回落本地 OCR，在完整桌面上每次 2~5 秒、返回 36KB 原始文本，再自己啃。
- **增强提示气泡太频繁、太大**。触发条件从「每次启动后首次**输入**必弹 + 每 5 次发送」改为「**第 1 次发送后一次 + 之后每 10 次**」，**打字期间一次都不弹**；长输入阈值 50 → **120 字**；冷却 1 → **3 分钟**；气泡停留 6 → **3 秒**。气泡也收小了（宽 260 → 200px、字号 12 → 11.5px、文案统一 ≤16 字）。
- **折叠头的「N 项失败」文字已删除**（用户明确要求）。失败信号保留为左侧红点。
- **工具安装的「验证」不再连坐整个安装**：验证是收尾快照，任一条抛错都会被上层当成「整个安装失败」（Miniconda 误报就是这么来的——文件其实已装好）。现在所有 verify 一律非致命。

## 新增

- 输入框下方一行居中提示：**「内容由AI生成，请核实重要信息」**。

## 自动化能力

- **两个总闸改为硬控制**：关「桌面自动化」或「浏览器自动化」时，用 `disabled_tools` 掩码真正摘掉对应工具，不再只靠提示词劝阻；两者解耦（关桌面不再把浏览器一起带走）。**界面开关与写进配置的值同源**，不会出现「界面显示开着、配置里已禁用」。
- **内置执行层升级 nuphus 0.2.3**（桌面 15 + 浏览器 23 个工具），技能与指令改为**首选已注册的 `browser_*` MCP 工具**，判据是「工具列表里有没有 `browser_navigate`」而不是写死通道；不可用时也会给出正确回应（引导去「设置 → 自动化」开）。

## 工具下载

- 下载**显示速度**、支持**后台下载**；所有工具都能**选下载源**；默认「国内优先」真的生效（此前首启体检的默认源不是国内）。
- 首启体检**去掉「工作区」项**（它不该算缺失工具）。

## 输入框与回合

- **钉顶口径定稿**：运行中钉在顶部、**运行完成不钉**（此前「短会话靠底」会压缩钉顶留白，已撤回）。
- 运行中的**自动跟随**未改动，本轮补了 3 条预检守卫把它钉住（跟随步长、归属未知也算自己、补差门槛）。

## macOS 说明

- 安装包**未签名**，首次打开请**右键 → 打开**（不要直接双击）。
- ⛔ **在「下载」里解压，别把 zip 拖进「应用程序」再解压** —— 归档实用工具会报
  「无法将 … 解压缩到“应用程序”（错误 640）」：那是受保护目录，而且解压还要再占一份空间。
  报 640 就用（`ditto` 是 mac 解 `.app` 最可靠的方式，符号链接与权限都保住）：

  ```bash
  cd ~/Downloads && ditto -x -k "Codex.Harness.Desktop-0.0.26-a-arm64-mac.zip" .
  ```

- 若提示「已损坏」/「无法验证开发者」，终端执行：

  ```bash
  xattr -cr "/Applications/Codex Harness Desktop.app"
  ```

  **路径不用手打**：把 App 图标从访达**拖进终端窗口**，路径会自动填上。
  若报 `xattr: No such file: /Applications/Codex Harness Desktop.app`，意思是**这个位置没有 App**
  （还没把它拖进「应用程序」，或者放在了别处）—— 先 `ls -d /Applications/Codex*Harness*.app` 确认位置。

- **磁盘空间**：mac 包约 **578 MB**（x64 约 590 MB），解压再占一份，首次启动还要按需下载运行时与工具链 ⇒ **建议留 10 GB 可用空间**。只剩 1~2 GB 时的典型症状就是解压报 640、更新下载失败、工具装到一半出错。
