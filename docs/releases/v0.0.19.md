# Codex Harness Desktop v0.0.19

> 本文件是应用内「发现新版本」弹窗展示的更新说明，由 `.github/workflows/release.yml` 读取。

## 修复：应用内「下载并安装」会直接失败（重要）

v0.0.18 的客户端点「下载并安装」会报 `HTTP 302`，更新走不完。原因在更新下载器：

GitHub Release 的资产直链**不是文件本身**，而是一个 **302 重定向**（跳到 `release-assets.githubusercontent.com` 的签名地址）。而下载器过去用裸 https 请求，代码里写着「状态码不是 2xx 就报错」，**不跟随重定向** —— 所以它在第一跳就放弃了。

这个缺陷此前一直没暴露，因为 09-15 才把更新源收敛为 GitHub 单源，而当时仓库**一个 Release 都没有**，检查更新根本拿不到东西，从来没走到下载这一步。v0.0.18 是首个 Release，才第一次踩到。

现在：下载器跟随最多 5 跳重定向，**并且每一跳都重新校验必须是 https**（防止被降级到明文——安装包下载完会被系统直接执行，明文通道等于把安装包交给中间人替换）。原有的 sha256 完整性校验不变。

## 同时包含 v0.0.18 的全部内容

如果是从 v0.0.17 或更早升级，这一版会一并带来：

- **专家调度**：把活派给内置专家 / 专家团 / 子智能体去干；独占调度锁、受保护会话、顶栏入口 + 头像轨。
- **内置代码审查专家「洞明」**：纯角色 + 自带技能包，直接对话即可审查代码。
- **目标与进程面板**、**任务运行状态行**（61 句状态词库）。
- **思考等级改为 低 / 中 / 高 / 最高 / 极高**，档位跟着模型保存，不用二次保存。
- **本地协议桥**：只支持 chat 协议的网关（火山 coding、Kimi Coding 等）现在能直接对话。
- **Windows 11 原生圆角外边框**（系统级 DWM，保留原生阴影与系统按钮）。
- **自动化工具拆细**：开发工具页按能力逐条显示（Nuphus / Playwright CLI / CloakBrowser / 两类浏览器内核 / ponytail）。
- **Nuphus 桌面自动化 + Playwright CLI + ponytail 插件随包开箱即用**；**CloakBrowser 与浏览器内核改为按需下载**，日常浏览默认走内置浏览器视图。
- **首次启动自动安装 Git**。
- **安装包显著瘦身**：有国内加速源的工具链与浏览器内核全部改为按需下载（Windows 包从约 500MB 降到约 350MB）。
- **一轮集中修 bug**：配置写入面（点一下权限格会把配置写成非法 TOML、名字带空格/中文的 MCP 服务器被静默删除、手写配置被覆盖）、会话面（导入的 `.jsonl` 会话打不开、设置页「会话记录」占用恒为 0、侧栏显示内部提示词）、供应商与阅读体验等共 14 项，另有一项「数值字段注入可让引擎执行任意命令」的安全问题。

## 安装说明

### Windows

下载 `Codex.Harness.Desktop-0.0.19-win-x64.exe` 直接安装。安装包**未做代码签名**，首次运行若出现 SmartScreen「未知发布者」提示：点「更多信息」→「仍要运行」。

> 已经是 0.0.18 的用户：直接在应用内「检查更新」即可，本版已修复下载链路。

### macOS（未签名）

下载对应芯片的 zip，解压后把 App 拖进「应用程序」：

- Apple 芯片（M 系列）：`…-arm64-mac.zip`
- Intel：`…-x64-mac.zip`

首次打开若被 Gatekeeper 拦住：

1. **右键**点 App → 选「打开」（不要双击）；
2. 或在终端执行：`xattr -cr "/Applications/Codex Harness Desktop.app"`。

### 应用内更新

Windows 版可直接在应用内「检查更新」下载并安装。
