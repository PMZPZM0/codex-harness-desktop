# v0.0.26 发版说明

> 发布日期：2026-09-20　|　上一版本：v0.0.25

**macOS 与 Windows 同步发布**。本版是两天里 47 个提交的合集，主题是**模型接入更宽容、会话之间彻底独立、通知不再互相打架**，外加一批稳定性与安全修复。

## 模型接入

- **本地模型一键适配**：供应商配置顶部新增 `Ollama` / `LM Studio` / `vLLM` / `llama.cpp` 预设，
  点一下填好地址与名称，并发默认给 **1**（单卡多路会让 KV cache 成倍占用，明显变慢甚至 OOM）。
  这类本机服务**不需要 API Key**，现在也能正常启用（原先「无 Key = 存成禁用」，配好却发不出消息）。
- **Claude 原生协议**：上游协议下拉新增 **Anthropic（Claude 原生 `/v1/messages`）**。
  引擎只发 Responses 格式，由本机协议桥双向转换（含系统提示、工具调用往返、思考块）；
  认证头自动从 `Bearer` 转成 `x-api-key` 并补 `anthropic-version`。
- **上游协议可手动指定**：`自动`（先按 Responses 试，上游明确说「没这个接口」才转 Chat）/ `Chat 兼容` / `Anthropic` / `强制 Responses`。
  ⛔ 有些网关对未知路径返回 **400 而不是 404**，旧逻辑会当成「端点正常」直接透传 → 对话失败且看不出原因。
  现在 400 会读一小段响应体判措辞，**只在明确是「没有这个端点」时才切** —— 宁可漏切（你可手动指定），
  也不会把「参数错误」误判成「端点不存在」而把本来能用的网关改坏。
- **供应商级并发上限**（默认 3，可自定义）：降低并发是防 429 最直接的手段。
- 首次安装**不再默认启用任何供应商**（未配置密钥 = 未启用），避免「默认那个 + 新配的这个」同时亮着。
- 模型配置引导重做：tab 式排版 + 内嵌中转站登录 + 入口移到侧栏，**配过之后不再弹**。

## 会话之间彻底独立

- **429 限流重试改为按会话独立**：后台会话的限流不再影响你看的这个，也不会因为切走就断。
- **不再放大重试**：把引擎侧重试参数退回默认（曾设成 10/10，实测是 429 放大器 ——
  峰值从 83 次/分降到 2~6 次/分），应用层退避也改保守。
- **重试条不串会话**、会话一运行就取消重试、编辑重发改回原会话、上游重连可见。
- **修「切走再切回，agent 回复没了」**与「回合结束了停止键还亮着」。
- **多窗口并发时前台会话不再「只转圈不出内容」**。
- **会话血缘（rollout lineage）从根上修**：删除源会话不再拖死它的子会话（接力/专家团派生）；
  已断链的会在启动时自愈，不再出现「会话打不开」。

## 通知不再互相打架

- **通知改为多条并存**：以前是一条把上一条顶掉，多会话同时告警时你永远只看得到最后一条。
- **位置跟随来源**：设置页里产生的贴在**设置弹窗内**居中，对话产生的贴在**对话区**居中；
  设置弹窗开着时，会话来源的通知不再横跨盖在弹窗上面（改为静默进通知中心）。
- **顶栏新增通知中心**（调度图标左边，带未读数徽标）：按对话分组，可单条/批量标记已读、删除，
  已读整条灰显；**只收纳「别的会话」产生的通知**（那才是你可能漏掉的），设置里的保存提示、
  对话框里的「已复制」这类即时反馈不再误收。
- 会话名以 **id 后 4 位短码**兜底：未命名/后台会话也能区分开。

## 输入框与回合

- **草稿按会话持久化**：打一半切会话、切回来还在；关应用也不丢。
- **思考被上游截断的空转会自动续接**：识别「思考很长 + 正文为空 + 无工具动作」并承接续写
  （15 分钟内最多 2 次），不再出现「跑着跑着就没动静了」。应用**不对思考或输出做任何限制**。
- 复制/图片复制等即时提示、附件名含方括号不再泄漏协议文本。

## 安装与工具

- **依赖/工具安装全程不弹窗**（原先会弹 `cmd.exe` 黑框），改为应用内进度条。
- 修「安装目录漂移」：应用搬家后 config.toml 里的绝对路径会失效且**永不自愈**，现在检测到就重写。
- `npm run preview:fresh`：一键拉起全新临时实例，方便人工查看。

## 安全

- fs 通道收敛到可信根、shell/updates/terminal 入参校验、CSP 加固（09-19 深度审计修复）。
- 移除 `browser-automation` 内置技能，替换为指引 playwright-cli 实操的 `browser-skill`
  （升级时按指纹自动清理旧版本；你改过的目录不会被动）。

## macOS 说明

- 安装包**未签名**，首次打开请**右键 → 打开**，或执行：
  ```bash
  xattr -cr "/Applications/Codex Harness Desktop.app"
  ```
- **发版前 mac 适配审计（本版自 v0.0.25 起全部新增行，扫描器 8 条正则先自证通过）：命中 74 条，其中真缺口 1 处，已在本版修复。**
  1. **【已修复 · 真缺口】`electron/main.ts` 的「安装目录漂移」检查写死了 `;` 切分 PATH**（Windows 分隔符）。
     mac 上 PATH 用 `:` 分隔 ⇒ 整条 PATH 会被当成一个元素、与期望首项永不相等 ⇒
     **每次启动都误判「漂移」并整份重写 config.toml**。已改为 `path.delimiter`（与同函数里的 `expectedFirst` 口径一致），
     并加预检守卫防止回退。
  2. 其余命中均为**无害**：平台门控内的 Windows 调用（`process.platform === "win32"` 分支里的
     `.exe` / PowerShell / `cmd.exe`）、**断言夹具里的路径样本**（纯字符串，不碰文件系统）、
     文案与注释、正则转义里的反斜杠（如 `-\\d+`）。
  3. 反向检查通过：`PATH` 相关的其余处理（`toolchain.ts` 的 `augmentedPath()`、终端候选目录、
     docker 检测）**都已用 `path.delimiter`**，且 `augmentedPath()` 在 POSIX 侧额外补了
     `/usr/local/bin`、`/opt/homebrew/bin` 等 mac 常见目录。
- Intel 与 Apple Silicon 分别出包，更新器按架构名匹配（`arm64` 不会误配 `x64`）。
