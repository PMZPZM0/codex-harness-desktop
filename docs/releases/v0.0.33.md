# v0.0.33 发版说明

2026-10-06。本版是**消息区体验 + 层级修复**的一版：把「我在改哪些文件、改了多少」变成运行中随时可见，
并修掉思考浮窗压住其他窗口、收尾汇报卡偶发不出现两个问题。

本版范围较小（上一版 0.0.32 之后共 6 个提交，全部是界面层与守卫，**没有新增主进程文件**）。

---

## 一、新增与改进

### 1. 运行中「已修改文件」胶囊

模型正在干活时，输入框上方会出现一条胶囊：**`N 个文件已修改 +X −Y`**。

- 鼠标放上去**展开文件清单**（类型图标 + 文件名 + 该文件的 `+N −N` / 已删除）
- 数据**跟着运行实时刷新**，回合结束**自动消失**（由下面的汇总卡接管）
- 它是输入框卡片栈里的**普通一行**，与排队消息、询问卡、审批卡是上下排序关系，**不会互相遮挡**
  （刻意没做成浮层 —— 那样遮挡问题从形态上就不该存在）

### 2. 汇总行悬停看 diff

回合结束后的文件汇报卡，鼠标放到**某一行**就直接预览这个文件改了什么，不用点开。

### 3. 弹层自适应普查

把所有弹层过了一遍，统一按空间**自动选边、超高就收窄、贴边夹进视口**——
贴右边缘/下边缘也不会被裁掉。本版补上了**画布右键菜单**的视口钳制。

## 二、重要修复

### 1. 思考浮窗会盖住办公室预览 / 设置页 / 画布

**现象**：运行中展开思考浮窗后，办公室预览被盖住，其他窗口也会。

**根因**：`app-shell` 是一个 `isolation` 层 —— 壳内所有层级（办公室/模态 400、设置内 80~97、画布 90）
**只在壳内比较**；而思考浮窗原先挂到 `body` 上、以 `z-index: 8` 参加**根层**竞争，
于是外面那个 `8` 把整个壳压住了。

**修法**：浮窗改挂**壳内宿主**（`.reasoning-float-host`，新增 60 档：高于消息流、低于设置页/画布/整屏浮层），
宿主是穿透层、浮窗自身保持可交互。`DESIGN.md` 加了层级表一行 + 一条硬规则
（**壳内浮层不许挂到 body 参加根层竞争**），守卫【198】加 4 条断言钉住。

### 2. 偶发「运行中有记录、收尾汇报卡却没出现」

按回合 id **反查快照**做双保险，收尾结算不再依赖单一路径。

## 三、macOS 适配审计（发版清单第 0 步，本版逐条判读）

用 `node scripts/mac-audit.mjs v0.0.32` 扫 `v0.0.32..HEAD` 的**新增行**，共 **1 条命中**。

扫描器内置**正则自证门禁**（8 条正则的正/负人造样本都必须符合预期，否则直接失败退出）
—— 本版自证**通过**，所以下面不是"0 命中式"的假通过（0 命中与"正则写错了"在输出上完全一样）。

| 命中 | 位置 | 判读 |
|---|---|---|
| `backslash` × 1 | `scripts/accept.mjs:703` | **误报，无害**。原文 `replace(/\\s+/g,' ')` 位于 CDP `eval` 的**模板字符串**内，`\\s` 是转义写法、求值后是正确的空白正则 `\s`，**不是路径**。且它在验收脚本里，不参与产品运行 |

**其余 7 组（`exe` / `win32` / `darwin` / `ctrl-key` / `winpath` / `powershell` / `appdata`）均为 0 条。**

**结论：本轮无 macOS 真缺口。**

**mac 打包链路复核（照做，未改动）**：

- `build/electron-builder.mac.cjs` 的 `artifactName` 含 `${arch}` ⇒ arm64 / x64 两个包名都自带架构名。
  这是**更新器契约** —— 应用内按「`mac` + `.zip` + 架构名」匹配资产，名字错了用户端会**静默**显示「已是最新」，不报错。
- `afterPack` 缺 `expert-skills` / `voice-presets` / `install-runtimes.cjs` / `install-automation.cjs` 时**直接中止打包**
  （不是静默跳过）。
- mac 侧随包工具由 `build/copy-mac-tools.cjs` 整体铺开（不走 `automation-tools.zip` 那条路），开箱即用。
- mac 侧 ONNX Runtime 上游**只在 `osx-arm64` 提供**（Intel 已放弃）⇒ 脚本降级为警告：
  **Intel Mac 缺语音/OCR 能力，其余功能正常**。

## 四、macOS 首次打开（安装包未签名，Gatekeeper 会拦）

1. **在「下载」里解压**（别在「应用程序」里解压，会报错误 640）；
   报 640 就用终端：`cd ~/Downloads && ditto -x -k "<zip 文件名>" .`
2. 把 App **拖进「应用程序」**（别在「下载」里直接双击运行 —— 那样会被挂到只读的临时卷上跑）
3. **右键 → 打开**（不要直接双击）
4. 仍提示「已损坏」时，终端执行（**把 App 图标拖进终端窗口，路径会自动填**）：

```bash
xattr -cr "/Applications/Codex Harness Desktop.app"
```

> 若终端回 `xattr: No such file`，说明该路径下没有 App —— 用 `ls -d /Applications/Codex*Harness*.app` 自查。
> 建议留 **10 GB** 磁盘空间（解压占一份，首次启动还要按需下载运行时/内核）。
