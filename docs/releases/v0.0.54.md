# v0.0.54 发版说明

本版主题：修「Git 自动安装失败」与「QQ 机器人连不上」两个用户反馈，压缩完成后并入回合过程列表。

## 一、修了什么

1. **Git 自动安装失败（四条下载通道全挂）**
   - 现象：开发工具页装 Git 时，npmmirror / gh-proxy / ghfast / 直连四条通道全部失败，
     最终报 `curl: option --retry-all-errors: is unknown`。
   - 根因：**不是网络**。`--retry-all-errors` 是 curl 7.71.0（2020-07）才加入的选项；
     Windows 自带的系统 curl 常年停在 7.55~7.6x，在参数解析阶段直接退出。
     截图里"文件大小 37.2 MB"能取到恰是反证——大小探测不带这个参数，网络其实没问题。
   - 修法：先探测本机 curl 版本，≥ 7.71 才使用该参数；旧 curl 退回默认重试语义
     （通道级回落本来就是我们自己的循环，不依赖它）。

2. **QQ 机器人连不上**
   - 现象：取令牌的接口返回 404。
   - 修法：统一改走 `api.bot.qq.com` 正确接口。

3. **上下文压缩完成后进回合过程列表**
   - 压缩完成后不再是时间线上一条孤零零的线，而是进到回合的过程列表里
     （和已深度思考 / 请求接口排在一起，跟着折叠收起）；在哪里压缩就显示在哪里。
   - 压缩运行中仍可随时点停止。
   - 连带修复：用户点「停止」后压缩线不再消失；压缩失败不会再显示成"正在压缩"。

4. **长会话往上滚被弹回**
   - 上翻历史时不再被历史水合的下滑判据自动拉回底部。

5. **子会话对齐与复用**
   - 侧栏里子会话缩进与父行标题列对齐；
   - 向同一目标重复派活时复用已有子会话，不再各开一个；主会话可查看自己的子会话。

## 三、mac 首次打开自救（带路径）

下载的是 `.zip`，macOS 默认会拦一下。按顺序做：

1. 在「下载」里双击解压，得到 `Codex Harness Desktop.app`；
2. 把它拖进「应用程序」文件夹；
3. 打开「终端」，输入 `xattr -dr com.apple.quarantine ` （**末尾留一个空格**），
   然后把**应用图标直接拖进终端窗口**——路径会自动填好，不用自己找；
4. 回车，再回到「应用程序」双击打开。

若提示 **错误 640**（"没能打开，因为 Apple 无法验证"），说明隔离属性没清干净：重复第 3 步，确认拖入的是「应用程序」里那个图标（不是「下载」里的）。
