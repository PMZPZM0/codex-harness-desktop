# Codex Harness Desktop v0.1.0

> 首个功能正式版。0.0.x 是内部验证序列，从本版起按语义化版本走正常节奏。

## 本版主题：开发工具管理重构 + macOS 适配收口

### 1. 下载：实时进度 + 速度 + 可取消

- 工具卡在下载过程中显示**进度条 + 实时速度 + 已下载/总量**（采样 500ms）。
- 新增**「取消」按钮**（安装/下载进行中才出现）。取消会：
  1. **杀进程树**（Windows `taskkill /T /F`、macOS `pkill -P` + kill）——
     只杀父进程会留下还在写文件的孤儿 `curl`，那样「清理临时文件」就是句空话；
  2. 按安装脚本上报的下载落盘路径（`@@TARGET`）**删掉半截压缩包**；
  3. 回执「已取消下载，临时文件已清理」—— 取消**不是失败**，不弹红色报错。
- npm 包类（cloakbrowser）与浏览器内核下载同样登记子进程，可取消。

### 2. 卸载：进度 + 明确结果

- 卸载改为**先盘点（文件数 + 字节数）再分批删除**（4MB / 200 文件一批），
  按字节比例推进度条；批次之间让出事件循环，保证进度真的能刷出来。
  实测 3000 个文件的目录树：16 个进度事件、0→99% 推进、696ms 删净。
- 逐个目标的安全校验**原样保留且仍在删除之前全部通过**
  （每个目标必须落在 `tools` / `codexHome` 之内，且不得等于根本身）。
- 卸载前**行内二次确认**（卸载是真删本地文件，不可恢复）。
- 卸载完成/失败都有明确提示；卸载中按钮区显示「卸载中…」而不是空白。

### 3. 界面：分类重划 + 统一视觉

开发工具页由 4 组细化为 7 组：**基础运行时 / 桌面与浏览器自动化 / 开发工具链 /
媒体与文档 / 本地智能 / 系统级安装 / 其它按需下载**。
末组是**兜底**：以后新增工具忘了归类时只会落到「其它」，不会从界面上凭空消失。
新增 `.runtime-cancel` / `.runtime-confirm` / `.runtime-badge.busy` 三个样式类，
沿用既有按钮与间距规范，不改全局风格。

### 5. macOS 段（发版清单第 0 步：mac 适配审计）

`scripts/mac-audit.mjs v0.0.33` 实跑：**8 条正则全部通过人造样本自证**（应命中的命中、
不应命中的不命中），因此下述 0 命中是真的没有。改动规模 `v0.0.33..HEAD` = 35 文件 / +989 / −97。

命中 26 条，逐条判读：

- `[exe]` 5 条 —— 全部在**注释与 install-runtimes 的 Windows 侧常量**里
  （如 `marker: "bin\\ffmpeg.exe"` 属 win 分支），mac 分支用的是 `ffmpeg/bin/ffmpeg`。**无害**。
- `[win32]` 4 条 —— 全部是**平台门控**（`process.platform === "win32"` 分支内：杀进程树走
  taskkill、npm 双布局探测、mac 品牌行 CSS 分支），else 分支完整。**无害**。
- `[darwin]` 10 条 —— 注释、守卫夹具与门控为主；反向检查「是否只判 win32 漏了 darwin」：
  新增的 darwin 分支（`DARWIN_MARKERS` 补 `platform-tools`、npm 双落位）**已成对存在**。**无害**。
- `[backslash]` 5 条 —— `replace(/\\/g, "/")` 归一化、守卫正则与注释。**无害**。
- `[powershell]` 2 条 —— 分类标题文案里的「PowerShell 7」字样。**无害**。
- `[winpath]` / `[appdata]` / `[ctrl-key]` **各 0 条** —— 无 Windows 绝对路径硬编码、
  无 `APPDATA` 直读、无 Windows 快捷键写死。

结论：**本版改动无 macOS 真缺口**。

## 安装

**Windows**：下载 `Codex.Harness.Desktop-0.1.0-win-x64.exe` 双击安装。

**macOS**（未签名，首次运行需手动放行）：

1. 在**「下载」里解压** zip —— 别在「下载」里直接双击（会被挂到只读的临时卷上跑），
   也别拖进「应用程序」再解压（会报「错误 640」，包约 578MB，解压再占一份）。
   若报 640，用：`cd ~/Downloads && ditto -x -k "<zip>" .`
2. 把 `Codex Harness Desktop.app` **拖进「应用程序」**。
3. 首次打开：右键 App → **打开** → 确认。若被 Gatekeeper 拦，用终端执行
   （把 App 图标拖进终端窗口，路径会自动填上）：
   ```bash
   xattr -cr "/Applications/Codex Harness Desktop.app"
   ```
   报 `No such file or directory` 说明该路径下没有 App，用
   `ls -d /Applications/Codex*Harness*.app` 自查实际路径。
4. 磁盘建议留 **10GB**（首次启动还会按需下载运行时与浏览器内核）。
