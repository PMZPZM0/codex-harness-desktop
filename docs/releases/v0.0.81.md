# v0.0.81 发版说明

本版：生图浮窗与看图体验重做，顺手修掉一批上传、登录、预览问题。

## 主要变化
- 生图浮窗可拖动、可最小化：成品留在右下角不会自己消失，点图看大图、悬停有放大镜。
- 侧栏实时看 PPT：模型做演示稿时右栏同步显示，成品可用本机应用打开。
- 图片不再变破图：正文与汇总缩略图都能显示，刷新或重启后缩略图仍在。
- 本轮产物加办公文档卡（pptx / xlsx / docx / pdf），文件右键操作统一。
- 插队消息带的图片模型能读到了；粘贴图片自动压缩体积（几十 MB → 几百 KB）。
- 验证码站点改走「网页登录」窗口，设备码登录补代理兜底，删掉引擎 90 秒无响应误报。

## macOS
本版一并发布 arm64 / x64。首次打开被拦：右键 → 打开；仍被拦则终端执行
`xattr -dr com.apple.quarantine` 后**把应用拖进终端**补全路径。

## 其它
- 组件体检：引擎 0.171.0 → 0.172.0，open-computer-use 1.1.5 → 1.1.6；nuphus 0.3.4 / agent-desktop 1.3.1 / ponytail v5.3.3 已最新。electron 45、TypeScript 7、@xyflow/react 13、jimp 2 属跨大版本，本版不动。
- mac 审计：`v0.0.80..HEAD` 命中 5 条，逐条判读均为注释 / 断言夹具 / 跨平台正则，无真缺口（8 条正则先跑人造样本自证通过）。
- 仍是完整包（Windows 约 670MB）。点「⬇ 更新」才会下载，不会在启动时自动下载或安装。
