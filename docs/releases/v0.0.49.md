# v0.0.49 发版说明

本版主题：**指挥中枢（创世 boss 群）从「能派活」走到「能自己拉人、验收、出成品」——并把它从
一个假的群聊界面改回一个真正的会话；另加语音悬浮球换脸、语音合成引擎可选、新人引导。**

> 版本号说明：**0.0.48 的构建未对外发布**（CI 建出 Release 后发现两处布局缺陷，已撤回重打）。
> 本版 0.0.49 = 0.0.48 的全部内容 + 下面第 1 节的布局修复，装本版即可，无需先装 0.0.48。
> 上版 0.0.47（10-23），本版 10-26，三天累计 298 个提交。

## 一、改了什么（按用户感知排序）

### 1. 输入框与弹窗：缩小时不再把字挤没（本版新增）
- 输入框底栏按「**有位置就缩图标、没位置才隐藏**」重排了整条降级阶梯：权限胶囊、模型名、
  推理强度在中等宽度**保留文字**（原来一到 480~640 就整段 `display:none`，只剩一个图标，
  而那一档行尾其实还空着），上下文环也从"中等宽度就藏"改成"最窄才藏"。
- 全站扫了两类成因：**硬隐藏**（媒体查询里把信息整段抹掉）与**硬裁**（`overflow:hidden`
  切掉却没有任何省略号）。修了 4 处：引擎更新页的运行体积、体验页的页头新手说明、
  供应商卡描述（改两行 clamp）、语音字幕（clamp 挂到文本子元素——容器是 flex 时挂容器无效）。
- 真机三档（1280 / 900 / 700px）验证：设置弹窗越界元素 0 个，输入框中等宽度下内容宽
  364px == 容器 364px（不裁切）。

### 2. 指挥中枢：自己拉人、自己派活、自己验收
- **改名**：原来叫「BOSS 会话」，现在整套文案统一叫**指挥中枢**（侧栏、欢迎页、帮助、快捷键清单）。
- **它就是一个普通会话**：之前那套「群聊专属界面」整块删除——点进去是正常时间线、正常输入框、
  正常消息渲染。群的信息（成员、任务、汇报）叠在这个会话上，而不是替代它。
- **拉人**：拉人面板改成**专家成员列表**，中枢右侧常驻一列**成员轨**（头像 + 状态环，最多 6 个，
  超出可滚动）；成员进出、谁在忙一眼看见。中枢右侧成员轨末位是**办公室预览**入口。
- **群广播**：成员交活在中枢会话里显示为「头像 + 名字 + 内容」，和用户自己说的话区分开。
- **投递机制重做**：群事件不再一律塞进引擎的用户消息队列——**中枢有回合在跑就直接追加进当前回合**
  （立刻送达、不进队列、不产生 pending turn），空闲才进队列。原来「一卡就堆几十条、界面炸开」
  的根因就在这。

### 3. 群汇报卡：成品出文件卡、位置挪到回复下方
- 成员交活的正文**落盘成 `群交付/<taskId>-<标题>.md`**，广播里带一行路径 ⇒ 界面出**文件卡**，
  点开即预览全文；气泡里只留摘要。动辄几千字的成品不再铺满一屏。
- 群汇报从「消息上方」移到「回复下方」——它是宿主注入的机器消息，不该占你的消息位置。
- 卡片从「粗竖条 + 面板底色 + 双层方框」改成一张轻卡片（成员头像按名字取色 + 徽标 + 标题）。
- 书名号幂等：任务标题自带《》时不再套成 `《出《…》》`。
- **历史刷屏提示不再渲染**：预算 80% / 预算用尽 / 停滞看门狗 / 待审看门狗这几类一次性提醒
  （宿主侧已不再产生）在界面上也一并隐藏；纯系统事件不再套「群汇报」空卡。

### 4. 交活结算的两处真缺陷（真实任务端到端测出来的）
- **失败的回合被当成「成员交活」**：引擎对失败回合也发 `turn/completed`（只是 status=failed），
  原实现不看 status ⇒ 落盘一个空文件、给中枢投一条假交活、任务永远卡在「待评审」。
  现在非 completed 一律按失败处理：释放成员 + 回投引擎原文（中枢看到的是「执行失败：…」）。
- **事件里的 turn 不带 items ⇒ 交活正文取空**：`turn/completed` 的 turn 只有 id/status，
  正文要按 `itemsView:"full"` 另拉一次。现在拿不到就补拉（能拿到时不多打一次往返）。
- 顺带删掉停滞看门狗与待审看门狗（用户原话：「Codex 自己哪有那么傻」）——判定该不该做是中枢的事，
  宿主定时催只会制造噪声并卡死队列。

### 5. 语音
- **悬浮球换新脸**：Grok Bot 胶囊眼圆脸，内置 6 套配色（设置 → 语音通话里切换）。
- **眼神跟随鼠标**、瞳孔随距离缩放；**打字时弹迷你键盘**。
- **语音合成可选引擎**：设置里三张引擎卡片，**Kokoro 真接通**并支持按需下载。

### 6. 侧栏与交互
- **功能入口改为右侧浮层**，不再占纵向空间；项目/任务右侧四个工具图标默认隐藏、悬停滑出。
- 会话行改**单行紧凑布局**（标签 → 名称 → 尾部时间，hover 才显示操作键）。
- 项目 ··· 菜单加「编辑项目名称 / 打开项目文件」；改名走全局弹窗并即时刷新。
- 输入框 chip **可拖到文字中间**（真跟手、原位留虚线落点槽、落点有主题色闪烁光标）。
- 快捷键：指挥中枢 **Ctrl+M**（Win/Linux；mac 用 **⌘⇧B**，避开系统最小化）；
  新建任务 / 指挥中枢的键位徽标默认隐藏，悬停或键盘聚焦才显示。

### 7. 文件预览
- 文件卡恢复**灯箱预览 / 编辑**；右栏预览可拖动、能向上拉满。
- 修「预览拉满后文件树顶部残影」。

### 8. 新人引导与应用锁
- 新人登录后走一次**配置引导**：称呼 / 头像 / 职业 / Codex 人格 / 兴趣，一次写入并即时生效；
  之后改用户中心会回读同一份数据（修了职业重复显示）。
- 新人指南章节变多，加**搜索**（按标签 / 标题 / 导语过滤）。
- 应用锁：**未开启时不显示启动检查页**，缓存开关后首帧直接进主界面。

### 9. 其它细节
- 空标签页改成主题起始页（中央搜索 + 收藏 / 常用入口）；右栏主题总览卡 + 搜索 + 自适应展示。
- 欢迎副语每时段扩到 12 条并避免连续重复。
- 检查更新 / 下载进度加悬停进度条。
- 调度告知改为随下一条消息内置注入；专家团加「不亲自干活 / 先派活」铁律。
- 排队面板不再把成员同步消息显示成「你的排队消息」。

## 二、mac 适配审计结论

审计范围 `v0.0.47..HEAD`，脚本 `scripts/mac-audit.mjs`（正则先自证：8 条正则全部通过人造样本）。

**命中 50 条**：`[exe]` 3 · `[win32]` 6 · `[ctrl-key]` 26 · `[backslash]` 15。
`[darwin]` / `[winpath]` / `[powershell]` / `[appdata]` 均为 **0 条**（自证通过，是真的没有）。

**真缺口 2 处（本版已修）**：
- `NewProjectDialog`「粘贴路径」只认 `C:\…` 盘符 ⇒ **mac 上粘贴 `/Users/你/项目` 会被判"不是绝对路径"**，
  新建项目直接走不通。改为跨平台绝对路径判定（盘符 / UNC / 以 `/` 开头），错误文案同步改。
- 知识库设置页路径写死 `\.codex-harness\knowledge` ⇒ mac 上显示成 `/a\b\c`。改按平台取分隔符。

**判读为无害**：
- `[exe]` 3 条：全部是守卫断言夹具（`*.exe.blockmap`、行数基线注释）。
- `[win32]` 6 条：`updates.ts` 差分更新在非 win32 显式抛 `differential_unsupported_platform`
  （mac 走完整包）；`WindowControls` 三条都是 `dataset.os !== "win32"` 直接 return（mac 用原生红绿灯）；
  其余为注释与 e2e 夹具。
- `[ctrl-key]` 26 条：`(e.ctrlKey||e.metaKey)` 的正确跨平台写法、`isMacPlatform()` 分叉
  （侧栏 `mod = mac ? metaKey : ctrlKey`）、以及文案——mac 标签经 `hk()` 转成 `⌘⇧B`；
  其余为守卫夹具与帮助文本。
- `[backslash]` 15 条：文件名清洗（Windows 非法字符集，mac 上多清几个字符无害）、
  `split(/[\\/]/)` 与 `replace(/\\/g, "/")` 归一（归一本身是对的）、守卫夹具。

## 三、mac 首次打开自救（带路径）

未做 Apple 公证，首次打开会被 Gatekeeper 拦。打开「终端」，**把应用图标拖进终端窗口**
（会自动补全路径，不用自己猜），在路径前加 `xattr -cr ` 回车：

```bash
xattr -cr "/Applications/Codex Harness.app"
```

只需一次，升级后不用重复。若提示 **错误 640**（"Finder 无法完成操作"），是同样的 quarantine 属性，
上面的命令执行后重开即可。

## 四、已知问题

- mac 未做公证与签名，只有 `xattr -cr` 这一条路；分发包也没做 universal 二进制，Intel 与 Apple
  芯片是两个包（资产名带 `arm64` / `x64`）。
- 本版 mac 适配的两处修复**只做了代码审读与平台分支复核，没有 mac 真机回归**（构建机之外无 mac 环境）。
- 指挥中枢的真实任务链路已用隔离 profile + 真模型端到端跑通（成功路径 6/6、失败路径 4/4），
  但**多成员并发**（3 人以上同时交活）只在单元层面覆盖，没有长时间压测。
- 历史群消息没有「成品文件」行（旧数据），仍走「查看成品全文」折叠；只有新交活才有文件卡，不做回填。
