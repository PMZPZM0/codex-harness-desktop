# v0.0.63 发版说明

本版主题：**更新体验收口**（进度条 / 安装遮罩 / 每用户静默安装 / mac 原生通知），外加音色选择与自媒体工作台的修复。

## 一、修了什么

### 1. 更新体验

- **下载有进度条、安装有遮罩**；安装期间另开一个小窗提示「正在安装，别重复启动」，避免装到一半被再次拉起。
- **默认手动安装**：不再自己重启，也不再在失败后连环重试。
- **安装方式改为当前用户静默安装**（oneClick），并在 `installer.nsh` 里做了旧「全机安装」的迁移保护：从旧版本升级会自动处理，不需要先手工卸载。

### 2. 更新通道按平台分口径（重要）

| 平台 | 方式 |
|---|---|
| Windows（NSIS） | **差分补丁**：`exe + exe.blockmap + latest.yml` 三件同发；无基线时下整包并登记基线 |
| macOS（zip） | **完整包**：系统层面没有 NSIS blockmap，每次都是整包；更新完成弹原生通知提示拖进「应用程序」 |
| 其它平台 | 完整包 |

⛔ 不要把 mac 当成 Windows 发：mac 段不承诺“几十兆补丁”。

### 3. 音色

- 音色下拉恢复「本机音色」，与「我的音色」同列一个下拉；
- 试听走真实合成链，音色名取模型里的说话人；
- 音色联动当前合成引擎（外部引擎 > 克隆 > MOSS > 本机）；
- 同一时刻只允许一个合成引擎（外部接管时本机不再显示“使用中”）；外部引擎启动中也能关闭，崩溃立即失败。

### 4. 自媒体工作台

- 顶部新增工具条：版本 / **检查更新** / **更新到 x.y.z** / 重载；
- 更新只落 `<userData>/media-desk-vendor/<版本>`，不动安装目录（删 `current.json` 即回退随包版本）；
- 更新后 iframe 自动铺满当前窗口（flex 布局，⛔ 不写死像素）。

### 5. 细节

- 产出文件卡补「用 X 打开」入口；音频芯片包裹不再裁切。

## 二、mac 适配审计结论

`node scripts/mac-audit.mjs v0.0.62 HEAD`：命中 **70 条**，分布在 `exe / win32 / darwin / backslash / powershell / appdata`。

逐条判读：**无真缺口**。
- `exe / win32 / powershell / appdata` 命中全部落在平台门控内（`installer.nsh` 是 Windows 安装脚本；`artcraft.ts` 的 `LOCALAPPDATA` 在 `process.platform === "win32"` 分支里），mac 上这些分支不执行；
- `darwin` 命中是本轮新增的 mac 原生通知实现本身（预期命中）；
- `backslash` 命中是路径归一化正则（同时匹配 `\` 与 `/`）。
脚本自带的「正则自证」已跑，不是“正则写错导致 0 命中”的假阴性。

## 三、mac 首次打开自救（带路径）

1. 在「下载」里双击解压；
2. 把 App 拖进「应用程序」；
3. 首次打开若提示“无法验证开发者”：右键 →「打开」；或把 App 图标拖进终端自动填好路径后执行：
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Codex Harness Desktop.app"
   ```
4. 错误码 640 表示系统仍在隔离态，重复上一步即可。
