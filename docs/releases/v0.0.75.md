# v0.0.75

本版主题：修复已知问题。

## 一、修了什么

- **修复已知问题**：控制台组件更新的覆盖面补齐（Agent Desktop / Ego Lite / 飞书 CLI / Playwright 现在都能在「设置 → 控制台」里检测与更新）；Codex 引擎升级到 0.171.0。
- 更新链路沿用 v0.0.74 重做后的完整包流程：点击账户行「⬇ 更新」→ 下载 → 校验 → 「⬇ 安装」→ 安装器自带进度窗口。本版是完整包（约 670MB），没有任何启动时的自动下载或自动安装。

## 二、mac 适配审计结论

`node scripts/mac-audit.mjs v0.0.74 HEAD`：8 类平台敏感模式命中 0 条（脚本自带正则自证，0 命中可信）。

## 三、mac 首次打开自救

1. 在「下载」里解压 zip；2. 拖进「应用程序」；3. 首次打开若提示无法验证，打开终端执行（把应用图标拖进终端自动填路径）：
   `xattr -cr "/Applications/Codex Harness Desktop.app"`；4. 若仍报错 640，右键应用 → 打开一次即可。

## 四、组件版本体检结论

引擎 @openai/codex 已升 0.171.0（本轮）；随包内置工具与运行时依赖无落后项。

## 五、已知问题

- 从 0.0.73 及更早版本升级的用户，请先手动安装一次 0.0.74 或本版，之后更新链路才可用。
