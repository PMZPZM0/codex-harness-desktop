## mac 首次打开（三步）

1. 在「下载」里解压；2. 把 `.app` 拖进「应用程序」；3. 打开终端，把 App 图标拖进终端（自动填路径），回车：

```
xattr -cr "/Applications/Codex Harness Desktop.app"
```

提示「已损坏」/ 错误 640 都是未公证导致的，用上面这条命令即可绕过 —— 属预期行为。
