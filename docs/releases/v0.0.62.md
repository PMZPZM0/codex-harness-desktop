# v0.0.62 发版说明

本版主题：**群聊只按 @ 说话**（成员不再自动搭话、管理员不再凭空收口），顺带把媒体预览收紧、给补丁更新重建差分基线。

## 一、修了什么

### 1. 没人 @ 时，成员/管理员不再自动回复（本版最大改动）

- **现象**：群里一句「哈喽」，管理员回完礼，另一个成员突然冒出来；或用户只 @ 了某一位，管理员却跳出来"验收/收口"。
- **根因**：宿主在「用户没 @ 任何人」时仍会自动把话头交回管理员（`mustHandBack` / `verdict=continue` 两条路）。rollout 实证：成员收到的信封是 `[系统] 问需 交回了这一环的产出。按 SOP 推进：验收这一环…`——这句话是宿主写的，不是模型、也不是工具调用。
- **修法**：新增总闸 `allowMemberRelay = 该消息里是否 @ 过人`。为假时管理员闭环整体关闭；为真时全部照旧。

### 2. 管理员写的 @ 真正生效，成员之间能接上话

- 只 @ 一位成员 ⇒ 直达他本人；管理员在一条消息里写多行 `@名字：任务` ⇒ 按书写顺序逐个执行（前一位交回再叫下一位）。
- 成员产出里的 `@某某` 会被真的叫起来（用户写的 / 管理员写的 / 成员写的，一视同仁）。
- 收尾权归发起者：A 发起 → B 交回 → 话头回到 A，由 A 决定继续还是了结。

### 3. 媒体预览收紧

- 视频与图片统一 **112×112** 正方形缩略图，首屏 4 个，展开后仍可「收起」。
- 音频不再单独占一张整宽大卡，改成 **168×48** 长条，与缩略图同一排。

### 4. 群列表副行精简

`1 伙伴 · 50 条 · 今日 6 人活跃` → `1 伙伴 · 50 条`。

### 5. 补丁更新：重建差分基线（重要说明）

- **本版仍是完整包**：更新统一交给 electron-updater 下载与安装，这一步会把 blockmap 登记为基线。
- **下一版起**才会只下载变化的块（预期几十兆）。
- 若中途手动装 exe 绕过应用内更新，基线会再次缺失，需要再走一次完整包。

## 二、mac 适配审计结论

`node scripts/mac-audit.mjs v0.0.61 HEAD`：命中 3 条，全部属 `backslash` 类（`DesignLibrary.tsx` 的 `/[\\/]+$/` 路径尾斜杠归一化正则）。
逐条判读：**无真缺口** —— 该正则同时匹配 `\` 与 `/`，在 mac 上行为正确；脚本自带正则自证已跑，非「正则写错导致 0 命中」。

## 三、mac 首次打开自救（带路径）

1. 在「下载」里双击解压；
2. 把 App 拖进「应用程序」；
3. 首次打开若提示"无法验证开发者"：右键 →「打开」；或把 App 图标拖进终端自动填好路径后执行：
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Codex Harness Desktop.app"
   ```
4. 错误码 640 表示系统仍在隔离态，重复上一步即可。

## 四、组件版本体检与名称 / 打包 / 发版核对

- 引擎 / 内置工具表：本轮未升（无安全修复需求）。
- `npm outdated`：7 项落后，本轮**均不升**，理由如下：
  - `electron 44.2.0 → 45.3.2`、`typescript 6.0.3 → 7.0.2`：跨大版本，会动 ABI 与类型面（TS7 与 `@typescript-eslint` 的 peer 冲突），需单独一轮验证，不夹带进发版；
  - `koffi 3.3.7 → 3.3.8`、`tsparticles 4.5.3 → 4.6.0`（含 engine / react）：小版本，留待下轮（本轮不引入无关变更）；
  - `dingtalk-stream v2.1.6-beta.1`：current 与 latest 相同，无动作。
- 名称 / 打包 / 发版：`productName`、`appId`、`win.artifactName` 未变；版本号 4 处对齐（`package.json` / `package-lock.json` 两处 / `whats-new-notes.ts` / 本文档）。
