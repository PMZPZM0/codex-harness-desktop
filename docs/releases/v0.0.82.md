# v0.0.82 发版说明

本版：右栏放大能整块盖住对话区，画布与团队会话的一批问题一并修掉。

## 主要变化
- 右栏放大：标签条一颗图标两段 —— 左半整块盖住对话区，右半缩回原宽。
- 无限画布：右键新建 10 类卡片、复制粘贴剪切，卡片可拖大、可连线；图片右键直接落到画布。
- 模型调画布工作流时右栏自动展开并亮绿灯，卡片随回填同步更新。
- 右栏新增「图片」页，标签条改浏览器式可关，默认回到新标签页入口。
- 生图 / 图生图换成 9 个常用尺寸，画质、背景、输出格式按网关文档对齐。
- 中枢会话能展开派出去的成员会话、右侧有成员运行反馈；修掉异步卡片不消失、回合结束后仍挂「等待你的确认」。

## macOS
本版一并发布 arm64 / x64。首次打开被拦：右键 → 打开；仍被拦则终端执行
`xattr -dr com.apple.quarantine` 后**把应用拖进终端**补全路径。

## 其它
- 组件体检：引擎 0.172.0 / nuphus 0.3.4 / open-computer-use 1.1.6 / agent-desktop 1.3.1 / ponytail v5.3.3 均已最新；同大版本依赖升 7 项；electron 停在 44.2.0（跨 11 个 minor + 原生模块 ABI，单独一轮处理）。
- mac 审计命中 2 条，均为守卫脚本里的断言夹具（正则 / 测试字符串），无真缺口。
- 仍是完整包（Windows 约 670MB）。点「⬇ 更新」才会下载，不会在启动时自动下载或安装。
