# v0.0.45 发版说明

本版主题：**反馈与官网入口换到更快的域名。**

> 版本号说明：**跳过 0.0.44**（该版本已打 tag 但未产出 Release，已撤销），本版号从 0.0.43 直接到 0.0.45。

## 一、改了什么

**反馈页和官网地址从 `www.jvszzp.ltd` 迁到 `dl.ppz123.asia`。**

替换位置：

| 位置 | 说明 |
|---|---|
| `.github/ISSUE_TEMPLATE/*.yml` | 三个 issue 模板里的反馈页链接、config.yml 的官网地址 |
| 更新检查的 base 常量 | 版本检查请求的域名 |
| 账号菜单「问题反馈」 | 点开后跳转的地址 |
| README | 官网反馈页入口 |

### 为什么换

`jvszzp.ltd` 走 **Cloudflare Tunnel**，实测首字节 **3.15s**、总计 **5.25s**。

更麻烦的是它的证书：源站用的是 **Cloudflare Origin Certificate**，这种证书只被 Cloudflare 信任。所以一旦把 DNS 改成灰云（直连），浏览器会报「证书不受信任」——这就是之前「关掉就访问不了」的原因。

`dl.ppz123.asia` 是 **A 记录直连** `124.220.63.4`，证书由 Let's Encrypt 签发，实测 **0.21~0.49s**，比原域名快 **10~25 倍**。

## 三、mac 首次打开自救（带路径）

未做 Apple 公证，首次打开会被 Gatekeeper 拦。

1. 在「下载」里解压 zip；
2. 把应用拖进「应用程序」；
3. 打开「终端」，**把应用图标直接拖进终端窗口**（自动填出真实路径）；
4. 在路径前加 `xattr -cr `，回车：

```bash
xattr -cr "/Applications/Codex Harness Desktop.app"
```

5. 重新双击即可。**只需执行一次**，升级后不用重复。

**提示错误 640**：当前用户对该 app 无写权限，改用 `sudo xattr -cr <路径>`。

**不想用终端**：在「系统设置 → 隐私与安全性」底部点「仍要打开」，效果相同。
