# v0.0.55 发版说明

本版主题：**工作伙伴（群聊）全面对齐主对话 + CLI 智能体自动跟随你的模型配置。**

> 版本号说明：本版从 v0.0.54（11-03）跨了 8 天、319 个提交，所以改动面比平时大。没有跳号、没有撤版重发。

## 一、修了什么（按用户感知排序）

### 1. 工作伙伴（群聊）与主对话对齐

- **回合视图**：群里的回复改成主对话那种一回合一条消息，**逐条实时上屏**；过程收进大折叠挂在首条，轮末出收尾汇总卡。
- **用量 / 推理 / 来源**：补齐主对话那三样 —— 用量页脚、推理浮窗（两种展示）、网页来源条。
- **交互一致**：复用主对话的滚轮与「回到底部」、记录懒加载、思考档位按官方规格联动。
- **@ 与引用**：输入框 @ 变成行内 chip（镜像层），气泡底部那条「补出来」的 @ 行删掉；引用改居中弹窗、可多选。
- **资料卡 / 搜索 / 加人**：伙伴资料卡、@ 候选面板、群内搜索各成独立板块；成员头像可自定义（只作用于本群）。

### 2. 群伙伴直接用本机 CLI 回话

- 群里的 CLI 成员改为**本地进程直接回复**，不再经引擎转交 ⇒ 回复更快，也不再出现「回了但没有正文」。
- 顺手修掉一批真实故障：**Qwen Code 的协议不匹配（405）**、**Kimi 的配置被焊死在旧中转地址（连接错误）**、**Claude 注入错参数族（未登录）**、stdin 未关闭导致 Claude 等 3 秒且正文丢失。
- 出错时不再甩原始 JSON，而是给一句「下一步怎么做」（协议不匹配 / 要自己的账号 / 端口占用 / 连不上）。

### 3. CLI 智能体自动跟随模型配置

- **装好即配**：安装完、启动时、切换供应商时都会自动把这台机器上已装的 CLI 配置跟上（Codex / Kimi / Gemini / Qwen / Claude / iFlow 各有各的写法）。
- **模型配置页新增「同步给 CLI」弹窗**：每个 CLI 一个按键，按它自己的方式定制 ——
  - Claude Code、iFlow：写它自己的配置文件（`~/.claude/settings.json` / `~/.iflow/settings.json`），**会提示密钥明文、仅本机**，需二次确认；
  - Codex、Kimi：重写配置，密钥不落盘；
  - Qwen 等：派活时自动注入环境变量；
  - Gemini、Comate、OpenClaw、Qoder、QwenPaw：如实标注「需自己登录」或「用它自己的模型」，不假装同步过。
- 覆盖了「写配置」的几个坑：内容已一致算成功（不再假报失败）、用户配置文件是坏 JSON 时**放弃写入**（不覆盖你的原配置）、首次改动留 `.harness.bak` 备份。

### 4. 远控与更新

- **手机看屏**（只读）+ 桌面可见提示与停止键；远控 RPC 加了白名单，运行中可排队 / 立即插队 / 撤回。
- **组件更新加官方源兜底**：原来「第一个成功的镜像就 return」，滞后镜像会把官方源挡在后面，导致永远显示「已是最新」。现在所有候选源都查、取真正最大的版本；19 个运行时依赖同步升到最新。

### 5. 其它

- 内置模型参数库更新（补 9–10 月六个新旗舰）；思考档位只显示当前模型支持的那几档。
- 提示词改成人话（去掉公文腔，示范怎么转述，机器标记人话化）。
- 设置页新增自动化入口，与桌面后端联动展示。

## 二、mac 适配审计结论

审计命令：`node scripts/mac-audit.mjs v0.0.54 HEAD`（脚本自带正则自证，避免"正则写错"伪装成 0 命中）。

结论：命中 115 条，**逐条判读后本版新增逻辑无真缺口**。分布与判读：

| 类别 | 条数 | 判读 |
|---|---|---|
| `exe` / `win32` / `darwin` | 主体 | 平台门控内（`process.platform === "win32" ? … : …`），分支完整 |
| `winpath` | 3 | ① `skills-market.ts` 的 tar 候选是 `win32` 三元分支；②③ 是守卫夹具里的测试字面量 |
| `powershell` | 3 | 门控内无害；1 处是页面文案（工具说明） |
| `appdata` | 0 | 无 Windows 环境变量直取 |

本版 CLI 相关新增代码的两处命中已单独核对，均为误报：
- `electron/features/group-talk/04-cli.ts:168` —— `const isWin = process.platform === "win32"`，紧接着用 `isWin ? "cmd" : "/bin/sh"`，门控正确。
- `src/lib/cli-command.mjs:221` —— 正则里的 `\\s` 被路径模式误判为 Windows 转义，实际该函数与平台无关。

## 三、mac 首次打开自救（带路径）

1. 在「下载」里**双击解压** zip；
2. 把解压出来的 `Codex Harness Desktop.app` **拖进「应用程序」**；
3. 第一次打开如果被拦，**把「应用程序」里的图标拖进「终端」窗口** —— 终端会自动填出完整路径（不用自己敲）；
4. 回车前在该路径前加 `xattr -dr com.apple.quarantine `（后面跟一个空格），回车；
5. 如果报 **错误 640**，是解压工具兼容问题：换用系统「归档实用工具」重新解压一次再放行。

## 五、已知问题

- **Gemini / Comate / OpenClaw / Qoder / QwenPaw 不能用主会话的密钥跟随**：它们要么只讲 Gemini 协议（当前供应商只开 OpenAI / Anthropic），要么要自己的 license / 网关配对 / 登录流程。同步弹窗里已逐条标注原因，不会假装同步成功。
- **Aider 装不上**：`aider-chat` 钉死 `aiohttp==3.8.4`，该版本没有 Python 3.13 的预编译轮子，源码编译又会撞上 3.13 已移除的接口。内置 Python 是 3.13 ⇒ 一键安装走不通，点安装会看到明确说明。
- **Trae CLI 无官方安装包**：npm 上没有任何 Trae CLI 包，官方只给安装脚本，所以本应用不提供一键安装（点「复制命令」拿到的是官方文档链接）。
- **nuphus 版本未复核**：见上表（网络原因）。
