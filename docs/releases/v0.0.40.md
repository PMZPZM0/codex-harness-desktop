# v0.0.40 发版说明（Codex Harness Desktop）

本版主题：**修复更新源串线** —— 与云助手（Codex Harness Assistant）产品线彻底隔离。

## 一、修复：更新源按产品线隔离

同一个 GitHub 仓库里现在有**两条产品线**的发布：

| 产品线 | 版本标签 | 安装包名前缀 |
|---|---|---|
| **Codex Harness Desktop（本产品）** | `v*` | `Codex.Harness.Desktop-*` |
| Codex Harness Assistant（云助手） | `cloud-v*` | `CodexHarnessAssistant-*` |

此前桌面版的更新检查取的是仓库的「最新发布」，而 GitHub 的「最新」是**按发布时间**算的——云助手一发新版本，桌面版就会把它误判成本产品的更新并提示安装（装上去的会是云助手）。**本版起桌面版只认自己的产品线**：只认 `v*` 版本标签 + `Codex.Harness.Desktop-*` 安装包，按版本号从高到低挑，云助手的版本再新也不会打扰你。

## 二、安装

**Windows**：下载 `Codex.Harness.Desktop-0.0.40-win-x64.exe` → 双击安装（覆盖安装无需先卸载，安装器会自动关闭旧版）。

**macOS**：下载对应芯片的 zip（Apple 芯片选 `arm64-mac.zip`，Intel 选 `x64-mac.zip`）→ 解压 → 把 **Codex Harness.app** 拖进「应用程序」。首次打开若提示无法验证开发者：终端执行 `xattr -cr `（末尾有空格）后把 app 拖进终端补全路径，回车后再双击。

## 三、本版还包含（此前的修复）

- 覆盖安装不再卡住（安装器先关旧版再继续）；
- 检查更新与下载走国内加速线路（依次尝试加速节点，失败自动回退直连）；
- 自动更新支持进度 / 速度 / 剩余时间，可取消、可稍后安装、可跳过某版本。
