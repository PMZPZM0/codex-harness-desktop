# v0.0.27 发版说明

> 发布日期：2026-09-24　|　基线版本：v0.0.26-b

**这是架构重构版**：应用代码从两块巨型文件（App.tsx 约 2.2 万行、styles.css 约 2.5 万行）拆分为按功能域组织的模块结构，**界面与功能保持不变**，为后续迭代铺路。同版收编了近期的全部实测修复：委派场景「停不下来」、会话内搜索、任务栏/托盘图标、排队消息误报、正文渲染三类问题，以及一轮安全审计的全部整改。macOS 与 Windows 同步发布。

## 架构

- **巨石拆分**：全部界面逻辑按功能域拆进 `src/features/*`（应用状态、会话视图、共享组件等 300+ 模块），主进程拆出 `electron/features/*` 与多个叶子模块；五大巨型入口从 56,638 行降到 1,275 行。
- **守卫体系随迁**：原 200+ 项结构断言全部迁移并通过（含针对拆分引入的共享上下文、活绑定、环形依赖的新守卫），预检断言总数 2,300 项。
- **发布链路不变**：tag → CI 三端构建 → GitHub Release，用户端更新器无感知。

## 修复

- **委派 / 子智能体场景「停不下来 + 反复弹窗」**（用户实测截图）。根因：宿主记录的回合已结束、引擎活跃回合已切换，点停止用的还是旧回合 id ⇒ 引擎拒绝并报错，而旧版弹错后**不复位运行态** ⇒ 界面永远「运行中」、反复点反复弹，真正在跑的回合从头到尾没人停。现在：从报错中捕获引擎报出的**真实回合**并重试中断（真正停掉在烧 token 的回合）；所有失败路径一律复位运行态。
- **顶栏 🔍 搜索改为「当前会话内搜索」并支持跳转**：搜出来的结果点击即滚到那条消息并高亮（↑↓ / 回车逐条跳），不再跨会话列出「看得见打不开」的记录（此前点到已归档会话会报 `Session ... is archived`）。顺带修了一个底层缺陷：**用户自己发的消息此前一律搜不到**（正文存在 `content[]` 而 取文本只看 `item.text`）。
- **任务栏 / 托盘图标**：开发形态启动时任务栏显示 Electron 默认原子图标（AUMID 与快捷方式配对问题）已修；另修复一次回归——**系统托盘注册整段被一个未闭合的块注释吞成死代码**（tsc/eslint/全部守卫都绿，纯肉眼可见级别的事故），已修并新增「注释吞代码」守卫防复发。
- **排队消息误报「队列启动失败」**。排队消息本由引擎自行启动（实测上一回合结束后约 9ms），宿主随后的启动调用必然扑空 ⇒ 消息正常发出却弹红错。现在这类「已被启动」的失败按成功处理，不再弹错；真正的失败照旧提示。
- **正文渲染三类问题**（用户连续三次截图反馈）：
  1. 列表最后一项后面紧跟的结语行被吞进列表项 ⇒ 缩进错位；
  2. `>` 引用块此前**没有任何样式**，走浏览器默认左右各缩 40px 且无可见标记 ⇒ 看起来「凭空歪了一块」——现在有明确的左竖条引用样式；
  3. 行首/行尾的全角空格不被 HTML 折叠 ⇒ 渲染成一块可见空白 ⇒ 已清理（行中间的不动）。
- **安全审计整改 17 项**：远控通道密钥改为常数时间比对、更新器与资产校验收紧、归档计数修正、委派会话启动时序、安装包体积裁剪等（完整清单见仓库 `docs/` 审计文档）。

## macOS 说明

- 安装包**未签名**，首次打开请**右键 → 打开**（不要直接双击）。
- ⛔ **在「下载」里解压，别把 zip 拖进「应用程序」再解压** —— 归档实用工具会报
  「无法将 … 解压缩到“应用程序”（错误 640）」：那是受保护目录，而且解压还要再占一份空间。
  报 640 就用（`ditto` 是 mac 解 `.app` 最可靠的方式，符号链接与权限都保住）：

  ```bash
  cd ~/Downloads && ditto -x -k "Codex.Harness.Desktop-0.0.27-arm64-mac.zip" .
  ```

- 若提示「已损坏」/「无法验证开发者」，终端执行：

  ```bash
  xattr -cr "/Applications/Codex Harness Desktop.app"
  ```

  **路径不用手打**：把 App 图标从访达**拖进终端窗口**，路径会自动填上。
  若报 `xattr: No such file: /Applications/Codex Harness Desktop.app`，意思是**这个位置没有 App**
  （还没把它拖进「应用程序」，或者放在了别处）—— 先 `ls -d /Applications/Codex*Harness*.app` 确认位置。

- **磁盘空间**：mac 包约 578 MB（x64 约 590 MB），解压再占一份，首次启动还要按需下载运行时与工具链 ⇒ **建议留 10 GB 可用空间**。只剩 1~2 GB 时的典型症状就是解压报 640、更新下载失败、工具装到一半出错。
