# v0.0.39 发版说明

> ⚠️ **v0.0.38 已撤回**：那版安装器在「旧版还在运行时覆盖安装」会卡在「无法关闭，请手动关闭」（重启电脑也复现）。本版修掉后重新发布；已装 v0.0.38 的用户请直接更新到本版。

本版主题：修掉覆盖安装卡死 + 检查更新走国内镜像 + 自动更新链路补全。

## 一、修了什么

1. **覆盖安装卡「无法关闭」（本版主修）**
   - 现象：运行中覆盖安装 → 安装器弹「Codex Harness Desktop 无法关闭，请手动关闭它」，重启电脑后仍复现。
   - 根因：electron-builder 的运行中检查只发 `WM_CLOSE`，而本应用「关闭窗口 = 最小化到托盘」把这条消息吞了；应用若以管理员权限运行，安装器的 kill 还会被判成「高权限进程」而失败。
   - 修法：`build/installer.nsh` 用 **`preInit` 宏**（模板里最早的钩子，在运行中检查**之前**执行）按进程名 `taskkill /F /T` 强杀，含宠物浮窗/远程服务/协议桥的整棵进程树。
   - 若应用以管理员权限运行，请右键安装器「以管理员身份运行」。

2. **检查更新与下载走国内镜像**：`gh-proxy → ghfast → 直连` 三档依次尝试（更新检查、资产下载、第三方市场共用同一张镜像表）；安装包下载后按 GitHub 资产 digest 做 sha256 校验。

3. **自动更新链路补全**：后台静默检查（启动 30s 首查、之后每 6h、失败退避 5min→15min→1h→6h、断网跳过）；下载进度显示百分比 / 已下载大小 / 速度 / 剩余时间；可取消（断点续传保留已下部分）、可稍后安装、可跳过某版本；下载中不并发检查。

4. **随 v0.0.38 一并带来的能力**：免费模型网关、本地 HTML/CSS → MP4、图片分层引擎与图像工坊、委派链路、输入框动态状态灯、独立弹窗修复。

## 二、mac 适配审计结论

`scripts/mac-audit.mjs v0.0.37..HEAD`：正则自证通过；命中 19 条（exe/win32/darwin/ctrl-key/backslash/powershell），逐条判读均为断言夹具、平台门控内文案或跨平台安全的 `/[\\/]/` 切分；**winpath 0 条、appdata 0 条** ⇒ 无真缺口。本版的安装器修复为 NSIS（Windows 专用），mac 打包链路零改动。

## 三、mac 首次打开自救（带路径）

1. 在「下载」里解压 zip；
2. 把 **Codex Harness.app** 拖进「应用程序」；
3. 首次打开若提示无法验证开发者：打开「终端」，输入 `xattr -cr `（末尾有空格），**把 app 图标拖进终端自动填全路径**，回车后再双击打开；
4. 若提示已损坏（错误码 640）：同样是上面的 `xattr -cr <路径>` 命令，执行一次即可；
5. 仍打不开时：系统设置 → 隐私与安全性 → 仍要打开。
