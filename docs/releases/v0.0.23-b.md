# v0.0.23-b 发版说明

> 发布日期：2026-09-18　|　上一版本：v0.0.23

本版是 **0.0.23 的第二次构建（B 版）**：在 0.0.23 全部修复的基础上，补齐**飞书 / 钉钉 / QQ 的过程流式**。
**macOS 与 Windows 同步发布**；随包工具与下载表无变化。

## 本版新增：飞书 / 钉钉 / QQ 过程流式

此前只有微信与 Telegram 会「边做边推」，飞书、钉钉、QQ 要等整轮跑完才收到一次性汇总。现在三家也接上了：

- 任务执行中按节奏推送**进度正文**，最后一条是**完整汇总**（不会丢内容）；
- 发送条数按各平台自身的频控设定（钉钉 webhook 每分钟有限额、QQ 被动回复次数有限），
  因此进度是「少量分段」而不是刷屏；
- **顺带修掉一个串渠道隐患**：飞书 / 钉钉 / QQ 的绑定与会话映射复用同一张表，此前微信分支未做前缀过滤，
  存在「用错渠道发消息」的风险，现已隔离。

## 同时包含 v0.0.23 的全部内容（从 v0.0.22 或更早升级的用户一并获得）

- **机器人渠道排版**：回复里的表格 / 标题 / 粗体不再变成手机上的竖线与星号——
  表格转 `【列名】内容` 条目、标题转 `【】`、粗体去符号、链接去 URL。覆盖**微信、Telegram、飞书、钉钉、QQ**。
- **微信流式修复**：过程可见（「对方正在输入…」不占消息额度），修复「只收到第一条、正文丢失」。
- **模型与连接**：DeepSeek V4.1 Flash 规格入库（1M 上下文 / 384K 输出 / 思考强度三档）；
  连接测试会自动换协议通道实测并注明；**带图发送不再整轮失败**（降级为文字引用，配了视觉插件的由插件识图）。
- **工具安装**：修复全新安装「一键安装」必失败；安装转后台（弹窗收起、右下角角标显示进度、装完自动消失）。
- **会话**：升级后**老会话继续可用**（旧目录 `~/.codex` 的会话自动迁回，侧栏可见、复制会话 ID 引用、继续对话全部恢复）；
  消息刻度尺改为跟随滚动位置的滑动窗口。

## macOS 说明

- 安装包未签名，首次打开请右键 → 打开，或执行 `xattr -cr "/Applications/Codex Harness Desktop.app"`。
- 本版无新增平台差异（发版前 mac 适配审计：对本版新增行扫平台敏感写法，**0 命中**）；终端仍用系统 shell（zsh），
  PowerShell 7 检测项仅 Windows 启用。

## 升级提示

- 已装 v0.0.23 的用户同样会收到本版提示（版本号不同）——升级后即获得三渠道流式，其余行为与 v0.0.23 一致。
- 从 v0.0.21 / v0.0.22 升级：老会话自动迁回，无需手动操作；机器人渠道沿用已绑定状态即可。
