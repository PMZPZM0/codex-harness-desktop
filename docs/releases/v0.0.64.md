# v0.0.64 发版说明

本版主题：**降 token + 开发工具页收口**。首轮上下文明显变短，开发工具里重复的「知微」入口合并进精选技能包，技能包可以点开预览。

## 一、修了什么

### 1. 首轮上下文瘦身（用户感知：新会话更省 token、更快）

| # | 问题 | 根因 | 修法 |
|---|---|---|---|
| 1 | 基础指令被注入**两次** | `config.developer_instructions` 被三处整份拷进会话级 settings（`block + base`），与 config 级叠加（44,052 + 44,441 字符） | 去掉会话级重复拷贝，只保留 config 级一份 |
| 2 | 工具说明占满篇幅 | 62 个 MCP 工具 schema 全量随包下发 | 改懒加载网关：62 份说明 → 2 份，按需展开 |
| 3 | 工具面过宽 | 普通会话也拿到全部岗位工具 | 改白名单（CORE / 岗位 + MCP），其余收进网关 |
| 4 | 项目规则太重 | `AGENTS.md` 107,498 字符每轮全量注入 | 瘦身到 32,447 字符（−70%），查阅型内容外置到 `docs/` |

**实测**：14:21 的会话首轮 160,332 tokens（工具面 79 个）→ 14:53 的会话 117,926 tokens（工具面 58 个）。`AGENTS.md` 瘦身之后的新会话尚未实测，预期再降一档；本版装好后新开一个会话即可验证。

### 2. 开发工具页：知微合并进精选技能包

- 「拓展与集成」里的「知微 · 自媒体流量预测」卡**删除** —— 它已经以 `Cheat On 内容评分` 的身份出现在精选技能包里，同一件事两个入口。
- 原来那张卡里的「核心技能文件是否就绪 / 复制检查与修复提示词」**没有丢**：折进知微的预览弹窗（默认收起）。

### 3. 精选技能包：可以预览了

- 每行右侧新增**眼睛图标**：点开看包内技能、配套专家、「怎么用」三步、许可与体积、仓库链接，安装 / 更新 / 卸载也在弹窗里。
- 弹窗版式与「飞书 CLI」同一套：同款标题栏 + 独立滚动正文 + 底部固定动作条。

### 4. 别的

- 云助手项目正式下线归档：本产品收敛为「桌面版 + PPcode」两仓（不影响桌面版功能）。

## 三、mac 首次打开自救（带路径）

1. 在「下载」里双击解压；
2. 把 App 拖进「应用程序」；
3. 首次打开若提示"无法验证开发者"：右键 →「打开」；或把 App 图标拖进终端自动填好路径后执行：
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Codex Harness Desktop.app"
   ```
4. 错误码 640 表示系统仍在隔离态，重复上一步即可。

mac 更新：**每次都是完整包**（系统层面没有 NSIS blockmap，不是漏做）。

## 五、已知问题

- 首轮 token 的最终值（`AGENTS.md` 瘦身后）需要**新开会话**才准：老会话的 `session_meta` 已经把工具面定死，读老会话会读到旧口径。
- 技能包预览只读本地清单；上游仓库新增技能需要点「更新」重新同步，预览里不会实时反映远端变化。
- `lucide-react` 升到 1.76 后若有图标被上游改名，会在构建期直接报错（本版构建通过，说明现用图标都在）。
