# v0.0.46 发版说明

本版主题：**对话多媒体化——影视源搜索内播、MoeKoe 音乐接入、思考过程折叠，以及记忆 / 云端链路的一批加固。**

> 本版为 0.0.45 → 0.0.46 的正常递增，无跳号。

## 一、改了什么（按用户感知排序）

### 1. 对话里的媒体播放 + 影视源搜索（新功能）
- 工具产出的**视频 / 音频 / 3D 模型**直接在对话卡片里播放（本地文件流式播放，支持 Range 拖进度；m3u8 走 HLS；3D 复用现有模型查看器）。
- 新增影视源检索三件套（`media_source_search / detail / open`）：配好 LibreTV / TVBox 源后，让 Codex「找片看」会真去搜源、列剧集、选集播放——直链进应用内播放器，网页播放页交系统浏览器。⛔ 第三方源目录随时会变，Codex 不会凭记忆编片名。

### 2. MoeKoe Music（酷狗客户端）接入（新功能）
- 「开发工具」页新增 MoeKoe 安装卡：从官方下载源按**系统与架构**自动选包（Windows x64·ia32 / macOS arm64·x64，国内走 gh-proxy 镜像），装好后 Codex 通过本机 6521 API 搜歌、播放。
- 修标准音质完整播放（补客户端同款 ppage_id，付费歌可完整听）；下载源改用官方 release，按 OS / 架构匹配安装器。

### 3. 思考过程折叠演进
- 回合结束后思考内容**折叠进回合过程组**，不再常驻刷屏。
- 新增「思考长条」展示模式：折叠态下保留一条过程样式的横条 + 最新一行要点，并自动滚动；与自适应浮层两种模式并存可切。

### 4. 时间线上滚体验
- 历史回合按**真实高度**渲染并提前预取，上滚续载改内容坐标补偿 + 多帧收敛——翻旧消息不再被拽回上一页顶部。
- 会话主列自适应宽度（给右侧轨道让位）。

### 5. 云端记忆开通闸门（重要加固）
- 云端记忆**未开通 / 未接通时入口自动置灰**，并给出明确原因与「去开通」出口；开通中、已开通三态齐备。
- 修复「断网一次就把已开通用户的云端记忆上游清掉」的根因：网络瞬态（超时 / 5xx）不再降级，已开通状态不变。
- 换账号写隔离快照（不删文件），杜绝新账号被旧开通状态冒充。

### 6. 云端身份与账号
- 内部网关请求归属到**真实用户身份**，内部凭据双绑定；401 自愈 + 令牌轮换检测 + 重签后同步刷新记忆 key。
- 云账号页新增**模型连通测试**：成功自动保存并重启生效，失败走重签重试。

### 7. 记忆 / 知识库双后端统一路由（10-20 凌晨批次）
- 记忆三后端（内置金字塔 / 本地 MCP / 云端）与知识库（本地 / 云端）自由切换，**工具面、提示文案、技能启停三处联动**，不重启即时生效的部分当场生效。
- dynamicTools ↔ MCP 桥补 **stdio 传输**：MCP 记忆后端在引擎 0.157+ 的延迟暴露机制下也能真用上。

## 二、mac 适配审计结论

`node scripts/mac-audit.mjs v0.0.45 HEAD`：**命中 38 条，逐条判读后无真缺口。**

- **MoeKoe（exe / winpath / appdata / powershell 命中）**：Windows 探测分支在 `darwin` / `linux` 分支之后（`moekoe.ts:58/76`），mac 走 `findMoeKoeExe` 的 darwin 分支与 `/Contents/MacOS/` 判定（`moekoe-core.ts:123`、`moekoe.ts:302/312`）；安装包按 `platform × arch` 选（Windows `…-x64.exe` / macOS dmg）。命中的 `Program Files` / `LOCALAPPDATA` 字面量都在 win 分支内。
- **媒体路径（backslash / winpath 命中）**：`boot.ts`、`MediaPreview.tsx`、`media-kind.mjs` 三处路径判定**同时认** Windows 盘符（`/^[a-zA-Z]:[\\/]/`）与 Unix 绝对路径（`/` 开头），mac 本地媒体文件可正常进播放器。
- **ctrl-key 1 条**：守卫夹具，非交互代码。
- 其余为守卫断言夹具与描述性文案。

## 三、mac 首次打开自救（带路径）

未做 Apple 公证，首次打开会被 Gatekeeper 拦。

1. 在「下载」里解压 zip；
2. 把应用拖进「应用程序」；
3. 打开「终端」，**把应用图标直接拖进终端窗口**（自动填出真实路径）；
4. 在路径前加 `xattr -cr `，回车：

```bash
xattr -cr "/Applications/Codex Harness Desktop.app"
```

5. 重新双击即可。**只需执行一次**，升级后不用重复。

**提示错误 640**：当前用户对该 app 无写权限，改用 `sudo xattr -cr <路径>`。

**不想用终端**：在「系统设置 → 隐私与安全性」底部点「仍要打开」，效果相同。

## 四、已知问题

- **影视源为第三方公共源**：单源超时 / 失效属正常，Codex 会报告哪个源没响应而不是隐藏它；源清单随配置变化。
- **MoeKoe 付费内容**：仅标准音质完整播放得到修复；更高音质仍依赖客户端登录态与会员权益。
- **媒体播放不支持 DRM 内容**；HLS 直链要求源允许跨域。
- **亮色主题下部分边框偏弱**（`rgba(255,255,255,.0x)` 类硬编码），属观感级问题，延续自 0.0.45。
