# Codex Harness Desktop v0.0.22

> 本文件是应用内「发现新版本」弹窗展示的更新说明，由 `.github/workflows/release.yml` 读取。
> 每次发版都要新建 `docs/releases/v<版本>.md`（缺失会直接让发布 job 失败）。

## 修复：全新安装时「一键安装」必定失败（用户反馈）

**症状**：全新机器上首次进入主界面，环境体检弹窗点「一键安装」，得到一句
「安装失败：Error invoking remote method 'runtime:install': Error: 该工具正在安装」，
而且**清单原样不动** —— 缺的几项一个都没装上。再点一次大概率还是失败。

**原因**：首次启动时程序会**在后台自动补装 Git**（Git 已不再随包分发）。而体检弹窗里 Git 恰好排在可安装项第一位，
于是「一键安装」的第一个请求就撞上了"Git 正在安装"，旧版直接把整批安装中断了。

**现在**：
- 正在安装的工具会**自动排队等待**，装好后一起返回，不再报「该工具正在安装」。
- 批量安装改为**逐项独立**：某一项失败不再连累其它项；结束时如实告诉你哪几项装好了、哪几项没成。
- 体检清单里正在后台安装的项显示「**安装中…**」，并且不会被塞进「一键安装」（不用干等它）。
- 安装结束会重新读取一次工具状态 —— 装好的项立刻从「待安装」变成「已就绪」。

## 安装说明

### Windows

下载 `Codex.Harness.Desktop-0.0.22-win-x64.exe` 直接安装。安装包**未做代码签名**，首次运行若出现 SmartScreen「未知发布者」提示：点「更多信息」→「仍要运行」。

### macOS（未签名）

下载对应芯片的 zip，解压后把 App 拖进「应用程序」：

- Apple 芯片（M 系列）：`…-arm64-mac.zip`
- Intel：`…-x64-mac.zip`

首次打开若被 Gatekeeper 拦住：

1. **右键**点 App → 选「打开」（不要双击）；
2. 或在终端执行：`xattr -cr "/Applications/Codex Harness Desktop.app"`。
