# v0.0.47 发版说明

本版主题：**浏览器自动化换成 Ego Lite、云账号「登录即用」、长会话滚动重做；并修掉 mac 上「免费网关装不上」。**

> 本版为 0.0.46 → 0.0.47 的正常递增，无跳号。

## 一、改了什么（按用户感知排序）

### 1. 浏览器自动化换成 Ego Lite（替换 Playwright / CloakBrowser）
- 语音/Office 之外最大的一处底座替换：**接入 Ego Lite**，移除 Playwright 与 CloakBrowser 两条旧通道，**每个会话独立 Space**（互不串号、不互相抢标签）。
- 官方技能包同步进 Codex 技能目录；「检查更新」与更新入口收口到控制台，重检结果就在同一处给结论。
- 首次使用会给一条**一键安装**指引（611MB 不随包内置，按需装）。

### 2. 云账号「登录即用」+ 收起服务地址
- 在登录页或设置里登录云账号后，**模型 / 知识库 / 记忆一次配齐**，并给出逐步回执（哪一步成功、哪一步没成、下一步点哪）。
- 修「一键同步假成功」：同步完补一次真探活，结论看所有步骤，不再拿「接口 200」当成功。
- 云账户页不再暴露「服务地址」输入框，**默认就走本仓内置地址**；换服务器仍可用环境变量或重登（只是不给普通用户入口）。

### 3. 长会话滚动重做
- 滚动条长度按**真实回合总数**撑开（59 回合实测一次拿全），滚轮不再「转半天不动一屏」。
- 旧的回合按页水合（每页 2 屏、上滚才加载），DOM 里恒定只有几个回合：切回旧会话 2s → 0.5s。
- 切回历史会话时**停在原来的阅读位置**，不再被拽到底部；刻度尺波浪随窗口联动。

### 4. 语音播报
- 回合头新增 📢 **会话级播报开关**（只影响这个会话），并修长播报的音质与断句。
- 「会话级静音」随每轮下发给引擎，Codex 不再声称「我会播报」却不出声。
- 所有窗口最小化 ⇒ **严格静音**（把「一个窗口都没有」和「全都缩了」分开判断）。

### 5. 文件卡与右栏
- 新增**本轮产物文件卡**（Qoder 式），右栏同步预览工作区文件；正文里内联的文件引用升级为同一张卡。
- 「创建后又删除」的文件也进汇总卡（以前会凭空消失，看着像没干活）。
- 命令卡/操作卡折叠态只留中文短句，详情点开再看；展开箭头改成悬停浮现，去掉「展开/收起」字样。

### 6. 办公室与宠物
- 像素办公室的取景与 3D 版式收口：白色简洁工位板 + 6 工位分页，预览改交互式 3D 场景（人物可点）。
- 黑猫换成 3D 多角度渲染图；宠物气泡贴身显示，拖动不再瞬切穿透，活动跟随当前会话。

### 7. 侧栏与交互细节
- 侧栏重排：能力入口移到底部（用户名之下）、统一 4 字命名，新增「登录管理」直达账户。
- 矮窗口下底部两个板块不再互相挤压（列表保底、入口组可收缩）。
- 实时编辑行按内容收缩：`文件名 · 目录 · +N -N` 紧挨着，不再被推到行中间。
- 修「应用能重复打开 = 两个主窗口」：第二实例不再 boot，建窗防重入。
- 修「任务清单每一步显示两次」：显示层按文本归并 + 写入幂等窗口。
- 修「专家团成员叫不动」：后台团队会话的工具调用没人应答，现在按团队会话路由。
- 补「我是谁」「弹幕怎么说话」两段默认口径（客户代播时不再连自我介绍都不会）。
- 网关 5xx 不再被说成「账号未开通该模型」；精确诊断不再被 catch 吞掉。

### 8. 模型线路
- PPtoken 默认 API 改为**大陆线路** `cn.pptoken.cc`（国外线路偶发握手失败）。

## 二、mac 适配审计结论

`node scripts/mac-audit.mjs v0.0.46 HEAD`：**命中 96 条，逐条判读后 1 处真缺口，已修。**

**真缺口（已修）**：
- `electron/features/free-gateway-ipc.ts` 的免费网关解压写死了 `7za.exe`。darwin 随包的是 7-Zip 官方
  **`7zz`**（`scripts/install-runtimes.cjs` 的 sevenzip 分支 marker 就是 `7zz`）⇒ mac 上「安装免费网关」必失败
  （找不到或不可执行）。现按平台取名（win `7za.exe` / 其它 `7zz`），参数不变。

**判读为无害**：
- `[winpath]` 1 条：`toolchain.ts:98` 的 `process.env.ProgramFiles || "C:\Program Files"` 在
  `process.platform === "win32"` 分支内；ego lite 的 darwin 分支走 `~/.local/bin/ego-browser`、
  `/Applications/ego lite.app`。
- `[exe]` 18 条：`dev-runtimes` 的 `python.exe + DLLs\_tkinter.pyd` 在 `IS_MAC` 的 **else** 分支
  （mac 判 `bin/python3` + pip 模块）；`remote.ts:21` 是**已修的旧实现**注释，现实现按平台解析并认
  `/opt/homebrew/bin/cloudflared`；其余 `.exe` 命中都在 win 分支或验收脚本。
- `[win32]` 11 条：`toolchain.ts` 的 PATH 拼装明确分两套（darwin 那套把 `sevenzip` 加进 PATH，
  所以 `7zz` 能被找到），其余为 `process.platform === "win32"` 门控本身。
- `[ctrl-key]` 8 条：`ctrlKey || metaKey` 的正确跨平台写法 + 守卫夹具。
- `[backslash]` 47 条：`accept.mjs` / `guards` 断言夹具与 `replace(/\\/g, "/")` 归一（归一本身是对的）。
- `[powershell]` 10 条：写给模型的说明文本与 pwsh 工具名清单（mac 侧走无后缀 `pwsh`）。
- `[appdata]` 1 条：注释里的 Windows 路径示意。

## 三、mac 首次打开自救（带路径）

未做 Apple 公证，首次打开会被 Gatekeeper 拦。打开「终端」，**把应用图标拖进终端窗口**（会自动补全路径），
在路径前加 `xattr -cr ` 回车：

```bash
xattr -cr "/Applications/Codex Harness.app"
```

只需一次，升级后不用重复。若提示 **错误 640**（"Finder 无法完成操作"），是同样的 quarantine 属性，
上面的命令执行后重开即可。

## 四、已知问题

- mac 未做公证与签名，只有 `xattr -cr` 这一条路；分发包也没有做 universal 二进制，Intel 与 Apple 芯片是两个包。
- 免费网关的 mac 解压修复只做了代码审读与平台分支复核，**没有 mac 真机回归**（构建机之外无 mac 环境）。
- Ego Lite 是外部应用（611MB），首次使用需要下载；未安装时浏览器相关技能会给出「先安装」的明确提示，而不是静默失败。
