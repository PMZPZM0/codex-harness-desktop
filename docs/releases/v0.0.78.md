# v0.0.78 发版说明

本版：把首轮开销再压一截，同样的活能多干几步。

## 主要变化

- 首轮上下文更省：常驻说明、工具清单都做了瘦身，同样的问题占用明显变少。
- 技能清单只下发名字与位置，用到才读详情 —— 116 个技能的索引缩到原来的约三分之一，能力不缺。
- 记忆更干净：群任务的系统噪声不再被当成「用户纠错」长期注入。
- 修回上一轮瘦身时误删的两处规则细节（对结果判断更稳）。

## macOS

本版一并发布 arm64 / x64。首次打开被拦时：右键 → 打开；仍被拦就打开终端，输入 `xattr -dr com.apple.quarantine` 后**把应用拖进终端**补全路径，回车即可。
