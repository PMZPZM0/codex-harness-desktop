# v0.0.38 发版说明

本版主题：免费模型网关 + 本地 HTML/CSS 出 MP4 + 图片分层引擎，委派链路与界面细节一批。

## 一、修了什么

1. **免费模型网关（新功能）**
   - 现象/需求：想要免配置的免费模型入口。
   - 做法：设置页一键下载并启动内置网关（第三方开源 dsh-our-free-model 的本地 OpenAI 兼容侧车），注册后即可当供应商选模型；卸载/启停/模型清单全程界面化。
   - 修复记录：forwardKey 空值被当真 Key 传给引擎（模型全废的根因）、detached 独立进程（网关随应用重启死循环）、残锁清理、卸载正反向全链路、注册回调链。
   - ⛔ 免责：上游为第三方开源项目（MIT），渠道合规性与可用性由使用者自担。

2. **本地 HTML/CSS → MP4（新功能）**：零 ffmpeg 依赖，模型可直接调用导出视频。

3. **图片文档分层引擎 + 图像工坊（新功能）**：图片分层渲染/合成/调整，会话内直接修图。

4. **委派链路打通**：子任务工具注册（delegate-harness-tool）、进度汇报（delegate-report）与结算（delegate-settle）。

5. **界面细节**：独立弹窗不再"黑一下"（根因=首帧内联脚本漏排除 popout）、开机动画按窗口类型区分、壁纸星空密度与亮星层次、顶栏图标按窗口宽度自适应、输入框底栏动态状态灯（最多亮一盏、轮流展示）。

## 三、mac 首次打开自救（带路径）

1. 在「下载」里解压 zip；
2. 把 **Codex Harness.app** 拖进「应用程序」；
3. 首次打开若提示无法验证开发者：打开「终端」，输入 `xattr -cr `（注意末尾有空格），**把 app 图标拖进终端自动填全路径**，回车后再双击打开；
4. 若提示已损坏（错误码 640）：同样是上面的 `xattr -cr <路径>` 命令，执行一次即可；
5. 仍打不开时：系统设置 → 隐私与安全性 → 仍要打开。
