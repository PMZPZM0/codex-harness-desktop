# Codex Harness Desktop v0.0.21

> 本文件是应用内「发现新版本」弹窗展示的更新说明，由 `.github/workflows/release.yml` 读取。
> 每次发版都要新建 `docs/releases/v<版本>.md`（缺失会直接让发布 job 失败）。

## mac 适配（本轮重点）

- **「开发工具 → 修复安装」在 mac 上以前必定失败** —— 随包内置能力（桌面自动化 / 浏览器自动化 CLI）损坏后点「修复安装」，用的还是 Windows 的解压程序，mac 上必然报「缺少 python 与 7z」（把平台问题说成了缺依赖）。现在按平台选解压器：mac 用系统自带 `ditto`，回落到内置 Python，再回落到 `unzip`；Windows 行为逐字未变。
- **开发工具下载表逐条核对为双平台**：Node / Python / PowerShell 7 / FFmpeg / VS Code CLI / jq / Ninja / 7-Zip / yt-dlp / ripgrep / uv / CMake / Miniconda 都有对应 mac 构建；Git 在 mac 用系统自带（点安装会调起命令行工具安装程序）；MinGW 是 Windows 编译器，在 mac 上不显示（mac 用系统 clang）。预检新增守卫比对两张表的工具清单，缺一边就会在构建阶段报错。
- **设置页展示的用户数据目录按平台分隔符** —— 之前 mac 上会显示成 `/Users/…\codex-home\skills` 这种混搭路径。

## 首次启动引导（新）

- **环境体检**：首次进入主界面时检测缺什么工具，列出「缺什么、多大、缺了会怎样」，可**一键补齐**（串行安装、实时进度）。必备 5 项（模型 / 工作区 / Git / ripgrep / PowerShell 7，最后一项仅 Windows）；常用 3 项（Python / jq / 7-Zip）列出但不阻断。勾「不再提示」后不再打扰，仍可在「开发工具」页安装。
- **模型配置引导**：没配模型时给新手两条直达路径（官方订阅登录 / 添加供应商），配好后永不再弹。登录页不会被引导打断。
- **启动加载页**：盖到首屏数据就绪，不再出现「点了没反应」的空窗。
- **使用帮助**：设置页新增面向新手的说明（模型 / 插件 / 技能 / MCP / 专家团 / 语音 / 开发工具），设置总览按 6 组 23 页给出分组地图、点页名直达。

## 模型与思考强度

- **内置模型规格表更新**：新增 GPT-6 Astra、GPT-5.6 系列、Claude Fable 5 / Opus 4.8、Gemini 3.x、Kimi K3、GLM-5.3(-Flash)、Qwen3.8-Max、日日新 6.5、豆包 Seed 2.0、MiMo-V2.5；修正若干上下文/输出长度。规格表同时决定「能不能发图」（会变成给引擎的输入模态，所以纯文本模型不会误标成视觉）。
- **模型 ID 自动补全**：输入框打前缀就出候选（含内置规格 + 你供应商探测到的模型），↑↓ 选择、Tab / Enter 补全；补全瞬间自动填好上下文长度、最大输出与视觉支持（手动改过的字段不会覆盖）。
- **模型下拉更清楚**：每行带供应商色调圆点与参数徽标（上下文 / 输出 / 视觉），当前项右侧勾选。
- **思考强度滑块重做**：默认只有一条细线，鼠标移上去才出现圆点；已选段是按档位分色的液体流光 + 灯带，拉到最满有燃烧特效。档位改为**会话级**（不再写进模型配置），遇到模型不支持的档位会自动降档而不是报错。

## 安装说明

### Windows

下载 `Codex.Harness.Desktop-0.0.21-win-x64.exe` 直接安装。安装包**未做代码签名**，首次运行若出现 SmartScreen「未知发布者」提示：点「更多信息」→「仍要运行」。

### macOS（未签名）

下载对应芯片的 zip，解压后把 App 拖进「应用程序」：

- Apple 芯片（M 系列）：`…-arm64-mac.zip`
- Intel：`…-x64-mac.zip`

首次打开若被 Gatekeeper 拦住：

1. **右键**点 App → 选「打开」（不要双击）；
2. 或在终端执行：`xattr -cr "/Applications/Codex Harness Desktop.app"`。

> mac 版无需额外安装 Git（系统自带，首次用会提示装命令行工具），终端使用系统 shell（zsh）。
