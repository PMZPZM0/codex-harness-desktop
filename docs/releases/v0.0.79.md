# v0.0.79 发版说明

本版：删除确认不再重复弹、下载通道不再乱跳、mac 模型配置恢复可用。

## 主要变化
- 删除只确认一次：侧栏删会话/项目，确认气泡贴着那一行，点「永久删除」不再冒第二个。
- 下载不再来回跳：镜像探测 3 秒到点结算，分片任一段失败立刻停掉其余段。
- 新增「测下载通道」：开发工具 → 工具自检，逐条实测镜像，列出通不通与 KB/s。
- mac 模型配置修好：探测改双传输栈 + IPv4 优先，不再误报「上游没有 /models」。
- 开发工具页提示：下载/安装失败可直接让 Codex 用命令行装好。

## macOS
一并发布 arm64 / x64。首次打开被拦：右键 → 打开；仍被拦则终端执行
`xattr -dr com.apple.quarantine` 后**把应用拖进终端**补全路径。

## 其它
- 组件体检：引擎与内置工具（nuphus / computer-use / agent-desktop / ponytail）均最新，本版无组件更新；mac 审计 11 条命中全在平台门控与断言夹具内，无真缺口。
- 仍是完整包（Windows 约 670MB）。点「⬇ 更新」才会下载，不会在启动时自动下载或安装。
