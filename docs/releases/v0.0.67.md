# v0.0.67 发版说明

本版主题：**修掉「点重启就闪退、之后再也更新不了」** —— 上一版（0.0.66）在 Windows 上的安装链有三个硬缺陷，这一版全部堵住。

> ⚠️ **本版请手动装一次**（下载下面的 exe 直接运行）。原因：你那台机器的应用内安装链已经被 0.0.66 那次失败的安装弄坏了，它自己拿不到本版。装完这一版之后，应用内更新恢复正常。

## 一、修了什么

### 1. 点「立即重启」→ 安装窗闪一下 → 应用闪退 → 版本没变

- **现象**：更新提示里点「立即重启」，先看到安装小窗，接着应用直接消失，重新打开还是旧版本。
- **根因（第一处，最致命）**：`build/installer.nsh` 的 `customInit` 里有一段「旧版是按所有用户安装的 → 提示并退出」，用来避免装成两份。但更新器发起的是**静默安装**（`--updated /S`）：那个 `MessageBox` 没人看得见，跟着的 `Quit` 却照常执行 ⇒ **安装器自己在装之前就退出了**，应用已经被关掉，用户看到的就是「闪退 + 版本没变」。
- **修法**：静默模式下**不再拦路** —— 检测到旧的全机版就按当前用户目录继续装（保留一条 DetailPrint 记录），只有交互式安装才保留提示 + 退出。

### 2. 安装前只等 0.8 秒，文件还占着

- **根因**：`preInit` 里 `taskkill /F /T` 之后只 `Sleep 800`。主进程被强杀后，引擎子进程树（codex / 语音 worker / 远程隧道）退出要几百毫秒，文件仍被占用 ⇒ 解包覆盖失败 ⇒ 安装器静默退出。
- **修法**：连杀两次、中间留 400ms，再等 1200ms 才进解包阶段。

### 3. 安装小窗压根没出现 / 出现就没了

- **根因**：`updates:restart-install` 里先调 `quitAndInstall()`（它内部是「spawn 安装器 + `setImmediate(app.quit)`」，几毫秒后主进程就没了），**然后**才 `showUpdateSplash()` —— 小窗是独立 PowerShell 进程，但父进程已经退出，拉起动作经常来不及。
- **修法**：顺序反转 —— 先拉起独立进程的安装小窗，再让 updater 去装并退出。

### 4. 差分就绪时不再「双安装」

- **根因**：`quitAndInstall` 抛错时，代码会回退到 `spawn` 安装包。但此时 updater 可能已经把第一个安装器拉起来了 ⇒ 两个 NSIS 实例抢同一个安装目录，前一个删文件、后一个写不进去，症状同样是「安装窗闪一下、版本没变」。
- **修法**：差分已就绪时**禁止回退 spawn**，失败就如实回报错误、清掉「待安装」标记，让用户重试一次。

### 5. 「一次失手 → 永久停更」

- **根因**：`autoInstallOnAppQuit` 在 0.0.65 被改成 `true`（想「不点按钮、退出时也装完」）。它会让 electron-updater 在**每一次退出**（包括正常关应用）时自己调一次安装；一旦那次失败，`update-install-pending.json` 会残留，之后每次启动都判「上次安装失败」，更新状态机把自动安装永久挂起 —— 这就是「再无法更新」。
- **修法**：改回 `false`（只在用户显式点「立即重启」时装），并且「上次失败」**只报一次就清标记**，下一次点「检查更新」会重新走完整流程。

### 6. 安装链有日志了

新增 `<userData>\update-install.log`（通常是 `%APPDATA%\Codex Harness Desktop\update-install.log`），每次点「立即重启」都会记：目标版本 / 当前版本 / 走差分还是安装包 / 安装器路径 / 失败原因。下次再出问题不用猜。

## 二、你这台机器怎么恢复

1. 下载 `Codex.Harness.Desktop-0.0.67-win-x64.exe`，双击运行（会覆盖安装，数据不受影响）；
2. 打开应用 → 头像/设置 → 检查更新，确认显示「已是最新 0.0.67」；
3. 打开 `%APPDATA%\Codex Harness Desktop\update-install.log`，确认文件存在（下一次更新时它会有内容）。

**差分更新的时间线**（这次别再误解）：

| 版本 | 你会看到 |
|---|---|
| 0.0.67（本版，手动装） | 手装**不建立配对缓存**，所以下一版仍是整包 |
| 0.0.68（应用内更新） | 整包（同时由 updater 安装并**建立配对缓存**） |
| 0.0.69 起 | 只下变化的块（几十兆） |

判断配对是否建立：`%LOCALAPPDATA%\codex-harness-desktop-updater\` 里 `installer.exe` 与 `current.blockmap` **同时存在**。
