# v0.0.31 发版说明

> 发布日期：2026-10-02　|　基线版本：v0.0.30

## 本版修的全是「装不上」

### 1. 清华镜像 403 —— 文档转换 / 手机控制 / Laya 装不上的真凶

- **现象**：这三处安装全部报
  `ERROR: HTTP error 403 Client Error: Forbidden for url: https://pypi.tuna.tsinghua.edu.cn/packages/...`
  （涉及 openpyxl、phone-harness、triton 等，包不同、错误一模一样）。
- **根因**：不是源挂了，是**只有一个源**。清华镜像的**索引页正常（200）**，但具体 wheel 直链 403/404
  （镜像侧文件失效或按频率限流）。而 pip 下载 wheel 失败时**不会**自动换源 —— 加 `--extra-index-url`
  也不救（它在解析阶段就锁定了那个 URL）。于是同一句话报到底，用户看到的是一个跟自己操作无关的 403。
- **修法**：**多源顺序兜底** —— 清华 → 腾讯云 → 阿里云 → 中科大 → 官方 PyPI；每个源整体重跑一遍
  `pip install`，全失败才报错，并把**每个源的结果**列出来（不再让用户对着一个 403 猜）。
  `install-runtimes`（Python 依赖 / 文档转换）、Laya、手机控制三处统一走同一份源表。

### 2. 新增「检查工具」

- 设置 → 开发工具 → **检查工具**：点一次，主进程逐个**真跑**（可执行类跑版本命令，Python 额外验 pip 可用性），
  把不可用的挑出来连同原因显示。
- 卡片上的「已安装」只说明**文件在**；这个按钮回答的是「**能不能真跑**」。

### 3. 一并包含 v0.0.30 的全部修复（若你还没升过）

- **所有工具卡在 `@STAGE 解压 [fail] "tar"`**：解压器改为跟随真实系统盘 + 扫 PATH 解析，
  并按 **系统 tar → 随包 7-Zip → Windows 自带 PowerShell** 三级降级 —— **用户不需要装任何解压软件**。
- **坏缓存自愈**：校验不通过先删掉再完整重下（旧逻辑对坏文件续传，体积对、内容坏 ⇒ 永远装不上），
  下载完成后再校验一次。
- **随包 7-Zip 换成完整版 `7za.exe`**：原链下的是 `7zr.exe` 精简版（只认 7z 格式）还被改名成 `7z.exe`，
  连 zip / tar.gz 都打不开。
- 未配置模型时点发送会抛错（删除模型引导时漏改调用点）。
