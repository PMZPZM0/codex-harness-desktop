# v0.0.23 发版说明

> 发布日期：2026-09-18　|　上一版本：v0.0.22

本次以「修用户实测问题」为主，共 7 项；**mac 与 Windows 同步发布**，随包工具与下载表无变化。

## 机器人（微信渠道）

- **流式过程同步恢复**：任务执行过程中会先看到「对方正在输入…」提示（不占消息额度），正文按小段推送，最后一条是完整汇总；此前微信只收得到一条思考开头、正文丢失。
- 修复流式分段只到第一条的问题（服务端按消息 ID 去重，现每段独立编号）。

## 模型与连接

- **DeepSeek V4.1 Flash 规格入库**（1M 上下文 / 384K 输出 / 思考强度 low·high·max），输入 `deepseek-v4.1-` 可自动补全。
- **连接测试更准**：火山 Coding Plan 等网关对部分模型的 Responses 通道会拒绝——测试现在会自动换通道实测，并在结果里注明实际可用的协议；404 提示附带白话说明与替代接入点。
- **带图发送不再失败**：模型不支持图片时，自动改为文字引用——配置了视觉插件的，图片自动交给插件的视觉模型识图后继续对话；没配的也会明确告知，对话不再中断。
- 视觉声明与接入点不符时自动改正（首次失败后自动关闭该模型的图片输入）。

## 工具安装

- **修复全新安装「一键安装」必失败**：首次启动后台自装 Git 时点一键安装会报"该工具正在安装"并整批中断——现在会自动等待，单项失败不再连累其余项。
- **安装转后台**：一键安装点下去弹窗立刻收起，右下角小角标显示进度，可以继续用应用；装完自动消失，失败自动展开重试。安装挂住也不会再卡死界面（旧版只能重启）。

## 会话

- **升级后老会话继续可用**：更早版本（09-10 前）的会话存在旧目录 `~/.codex`，升级后会被自动搬回新目录——侧栏直接可见、复制会话 ID 引用、继续对话都恢复。
- 消息刻度尺改为跟随滚动位置的滑动窗口（不再把几百条刻度挤成一列）。

## 其他

- 内置插件页排版重做（能力卡片 + 三态状态：已启用/已停用/未配置）。
- 插件页刷新入口合并为一个。

## macOS 说明

- 安装包未签名，首次打开请**右键 → 打开**，或在终端执行 `xattr -cr "/Applications/Codex Harness Desktop.app"`。
- 本版无新增平台差异；终端仍使用系统 shell（zsh），PowerShell 7 项仅 Windows 需要。

## 升级提示

- 从 v0.0.21/22 升级：旧会话自动迁回，无需手动操作；微信机器人需重新扫码绑定（如此前已绑定则沿用）。
