# v0.0.23 发版说明

> 发布日期：2026-09-18　|　上一版本：v0.0.22

本版以「修用户实测问题」为主，**macOS 与 Windows 同步发布**；随包工具与下载表无变化。

## 机器人渠道排版（本版重点）

- **Markdown 自动转手机可读排版**：此前桌面端回复里的表格、标题、粗体会原样发到机器人渠道，
  在手机上变成一堆竖线（`| 方向 | 新闻 |`）与星号。现在发送前统一转换：

  | Markdown 原样 | 转换后 |
  |---|---|
  | `\| 方向 \| 新闻 \|` 表格 | `【方向】新闻`（逐行条目，分隔行丢弃） |
  | `## 行动向` 标题 | `【行动向】` |
  | `**重点**` 粗体 | `重点`（去符号） |
  | `[OpenAI](https://…)` 链接 | `OpenAI`（去 URL） |
  | `- 条目` 列表 | `• 条目` |

  覆盖渠道：**微信、Telegram、飞书、钉钉、QQ**。
- **微信流式过程同步恢复**：任务执行中会先看到「对方正在输入…」（不占消息额度），正文按小段推送，
  最后一条是完整汇总；修复了「只收到第一条、正文丢失」的问题（服务端按消息 ID 去重，现每段独立编号）。

## 模型与连接

- **DeepSeek V4.1 Flash 规格入库**（1M 上下文 / 384K 输出 / 思考强度 low·high·max），输入 `deepseek-v4.1-` 自动补全。
- **连接测试更准**：火山 Coding Plan 等网关对部分模型的 Responses 通道会拒绝——测试会自动换通道实测并注明；
  404 提示附带白话说明与替代接入点。
- **带图发送不再失败**：模型不支持图片时自动转为文字引用——配了视觉插件的由插件识图后继续对话，
  没配的也会明确告知，对话不中断；视觉声明与接入点不符时自动改正。

## 工具安装

- **修复全新安装「一键安装」必失败**（首次启动后台装 Git 时并发冲突 → 现在自动等待，单项失败不再连累整批）。
- **安装转后台**：点一键安装弹窗立刻收起，右下角角标显示进度，可继续用应用；装完自动消失，失败自动展开重试。
  安装挂住也不再卡死界面（旧版只能重启）。

## 会话

- **升级后老会话继续可用**：更早版本（09-10 前）的会话存在旧目录 `~/.codex`，升级后自动搬回新目录——
  侧栏可见、复制会话 ID 引用、继续对话全部恢复（只拷贝、不改动旧目录，官方 Codex CLI 不受影响）。
- 消息刻度尺改为跟随滚动位置的滑动窗口（不再把几百条刻度挤成一列）。

## macOS 说明

- 安装包未签名，首次打开请右键 → 打开，或执行 `xattr -cr "/Applications/Codex Harness Desktop.app"`。
- 本版无新增平台差异（发版前 mac 适配审计：对新增行扫平台敏感写法，0 命中）；终端仍用系统 shell（zsh），
  PowerShell 7 检测项仅 Windows 启用。

## 升级提示

- 从 v0.0.21 / v0.0.22 升级：老会话自动迁回，无需手动操作；微信机器人沿用已绑定状态即可。
