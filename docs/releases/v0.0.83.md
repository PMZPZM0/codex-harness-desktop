# v0.0.83 发版说明

本版：右栏更全能 —— 3D、图像、媒体、剪辑、自媒体、动效都能在侧栏里开。

## 主要变化
- 3D 预览、图像工坊、媒体预览、影片剪辑都改成右栏标签页，不再弹整屏浮层。
- 新增 OrenCut 动效工坊：33 个可编辑的静音动效组件，按需下载（约 57 MB），右栏预览、改标题、导出 MP4。
- Codex 会用 OrenCut：说「用 27 号做个竖屏片段」，它会列出组件编号并在右栏打开对应画面。
- 自媒体工作台接入右栏，与独立窗口共用同一份数据。
- 安全加固：群成员命令模板加校验、六类机器人凭据改为加密存储、浏览器弹窗与本地协议收紧。
- 两处行为变化：密码本「复制密码」现在需要写入权限；预览弹窗不再共享主窗口登录态。

## macOS
本版一并发布 arm64 / x64。首次打开被拦：右键 → 打开；仍被拦则终端执行
`xattr -dr com.apple.quarantine` 后**把应用拖进终端**补全路径。

## 其它
- 组件体检：引擎 0.172.0 / open-computer-use 1.1.6 / agent-desktop 1.3.1 均已最新；nuphus 0.3.4、ponytail v5.3.3 沿用上版。
- 依赖 9 项落后，其中 electron 45 / @xyflow 13 / jimp 2 / TypeScript 7 属跨大版本（ABI 与 peer 约束），单独一轮处理；本版不动依赖。
- mac 审计命中 8 条，全在 `[backslash]` 类（`split(/[\\/]/)`、`replace(/\\/g,"/")` 这类**同时处理两种分隔符**的跨平台写法），逐条判读无真缺口。
- 仍是完整包（Windows 约 670MB）。点「⬇ 更新」才会下载，不会在启动时自动下载或安装。
