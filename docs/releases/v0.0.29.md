# v0.0.29 发版说明

> 发布日期：2026-10-01　|　基线版本：v0.0.28

## 核心新增

- **组件库**：设置 →「组件库」，内置 Uiverse 3800+ 现成 HTML/CSS 组件（MIT），按类目浏览、点开看代码、一键复制；Codex 写前端会自动查库复用
- **桌面宠物**：桌面浮窗宠物，兼容 Codex 官方 pet.json 格式与 `~/.codex/pets` 生态，内置三只自产宠物，状态跟着任务走
- **像素办公室**：专家团成员实时映射成虚拟办公室——工位落座、打字动画、喝水/查资料等休息活动
- **思考等级自动档**：内置 Laya 本地决策模型（33ms），发送前自动选 低/中/高/极高；手选档立即覆盖；未安装时静默回落手选档
- **插件市场换源**：Gitee 官方镜像（Claude Code 官方市场中国版，48 个兼容插件），名称与简介全中文
- **首启引导 2.0**：首次启动只弹「开发工具」引导；工具安装统一国内镜像加速，带进度条/下载速度/并行队列，失败可重试
- **编辑卡数字动态化**：编辑文件卡片的 +N −N 统计随 diff 流式实时累计，不再完成后一次性出现
- **AI 画布多参考图**：支持多图参考、三列网格、逐图删除
- 另含大量修复与体验优化（办公室浮层关闭钮遮挡、Laya 判定延迟治理、e2e 端口退让等）

## macOS 说明

- 安装包**未签名**：**在「下载」里解压**（别在「应用程序」里解压，会报错误 640；报 640 用 `cd ~/Downloads && ditto -x -k "<zip 文件名>" .`）→ App **拖进「应用程序」** → **右键 → 打开**（不要直接双击）
- 仍提示「已损坏」时终端执行（App 图标拖进终端自动填路径）：
  `xattr -cr "/Applications/Codex Harness Desktop.app"`
- 磁盘建议留 10 GB（解压与首次启动按需下载运行时）
