# v0.0.29 发版说明

> 发布日期：2026-10-02（覆盖重发）　|　基线版本：v0.0.28
>
> 与上一版同名资产相比：内置 Python 换成**完整版**（自带 pip + Tkinter），
> **下载体积 50MB 以内的小工具全部随包内置**，开发工具页的卸载改为**真删**，
> 首启推荐清单改为 5 项。

## 核心新增（本次覆盖重发）

- **内置 Python 换完整版（python-build-standalone）**：自带 pip 与 Tkinter，
  `requests` / `httpx` / `flask` / `fastapi` / `playwright` 随包装好 ⇒
  **Laya 智能判断 / 手机控制 / 文档转换 不再出现 `No module named pip` 装不上**。
  首次启动检测到旧的不完整 Python 会自动整目录换装。
- **≤50MB 工具随包内置**：Python、ripgrep、uv、CMake、7-Zip、jq、Ninja、yt-dlp、
  Android 平台工具（adb）—— 装机即可用，不再等在线下载。
  大件（PowerShell 7 / Git / FFmpeg / Miniconda / MinGW + 两类浏览器内核）仍走「开发工具」页按需下载。
- **卸载是真删**：除「内置」外每一项都可卸载（内置项不给卸载键，删了只能靠随包资源恢复）。
  修了 CloakBrowser 卸载只删 shim 文件、包体残留的旧 bug。
- **首启推荐 5 项**：Laya 智能判断 / 手机控制 / 文档转换 / PowerShell 7 / FFmpeg；
  已内置的工具不再进引导清单。
- **开发工具「装不上」修好了（重要）**：部分机器上所有工具都卡在「解压失败」——
  根因是解压器写死了 `C:\Windows\System32\tar.exe`（系统盘不是 C: 的机器、精简版系统上不存在），
  且坏掉的下载缓存会一直续传、永远修不好。现在：解压器跟随真实系统盘并从 PATH 兜底解析，
  解压按「系统 tar → 7-Zip → Windows 自带 PowerShell」三级降级，缓存校验不过会先删再完整重下。
  同时把随包的 7-Zip 换成**完整版**（原来那个只认 7z 格式，打不开 zip / tar.gz）。

## 核心新增（上一版已有，保留）

- **组件库**：设置 →「组件库」，内置 Uiverse 3800+ 现成 HTML/CSS 组件（MIT），
  按类目浏览、点开看代码、一键复制；Codex 写前端会自动查库复用。
- **桌面宠物**：桌面浮窗宠物，兼容 Codex 官方 pet.json 格式与 `~/.codex/pets` 生态，
  内置三只自产宠物，状态跟着任务走。
- **像素办公室**：专家团成员实时映射成虚拟办公室——工位落座、打字动画、喝水/查资料。
- **思考等级自动档**：内置 Laya 本地决策模型（33ms），发送前自动选档；手选立即覆盖。
- **插件市场换源**：Gitee 官方镜像（48 个兼容插件，名称与简介全中文）。
- **首启引导 2.0**：首次启动只弹「开发工具」引导；带进度/速度/并行队列。
- **编辑卡数字动态化**：+N −N 统计随 diff 流式实时累计。
- 另含大量修复与体验优化（办公室浮层关闭钮遮挡、Laya 判定延迟治理、e2e 端口退让等）。
