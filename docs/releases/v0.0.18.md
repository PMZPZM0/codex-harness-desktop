# Codex Harness Desktop v0.0.18

> 本文件是应用内「发现新版本」弹窗展示的更新说明，由 `.github/workflows/release.yml` 读取。
> 每次发版都要新建 `docs/releases/v<版本>.md`（缺失会直接让发布 job 失败）。

## 新功能

- **专家调度**：Codex 现在可以把活派给内置专家 / 专家团 / 子智能体去干。独占调度锁（同一时刻只有一个调度方）、受保护会话（专家与专家团会话不会被误调度）、顶栏独立入口 + 头像轨。
- **内置代码审查专家「洞明」**：纯角色 + 自带技能包，直接对话即可审查代码。
- **目标与进程面板**：随时看到当前目标与正在跑的子进程。
- **任务运行状态行**：执行时显示「正在执行命令 · 一句话」，词库 61 句（通用 40 + 活动专属 6 组）。
- **思考等级改为 低 / 中 / 高 / 最高 / 极高**：档位跟着模型保存，不用再二次保存，菜单也更紧凑。
- **本地协议桥**：只支持 chat 协议的网关（火山 coding、Kimi Coding 等）现在能直接在应用里对话。
- **Windows 11 原生圆角外边框**：走系统级 DwmSetWindowAttribute，保留原生阴影/拉伸/系统按钮。
- **自动化工具拆细**：开发工具页由一张大卡拆成逐条能力卡（Nuphus / Playwright CLI / CloakBrowser / 两类浏览器内核 / ponytail），各自独立显示状态、体积与动作。
- **Nuphus 桌面自动化 + Playwright CLI + ponytail 插件随包开箱即用**；**CloakBrowser 与浏览器内核改为按需下载**（不再占安装包体积），日常浏览默认走内置浏览器视图。
- **首次启动自动安装 Git**（瘦身后不再随包，自带兜底安装）。

## 修复

- **mac 全面适配**（09-16 实测反馈集中修复）：
  - **开发工具在 mac 上全部安装失败** —— 已修。mac 包此前缺少安装脚本、且下载的全是 Windows 二进制；现已按平台分叉（原生 mac 构建的 Node/PowerShell/Python/ffmpeg/jq/7-Zip/CMake/rg/uv/Ninja 等，解压后自动补执行权限），git 走系统开发者工具。「装没装」的判定也全部按平台修正。
  - **界面动画全部静止** —— 已修。macOS 系统开了「减少动态效果」时应用动画会被整体关掉，现已恢复。
  - **窗口红绿灯（左上角）没有适配、右上角一大截空白** —— 已修。mac 走原生红绿灯布局，右上空白区归还内容。
  - **实时语音闪退（Windows 也有）** —— 已修。语音引擎换成独立子进程，崩溃不再带死整个应用，界面会提示并可重开。
  - **切换供应商后旧会话不可用** —— 迁移失败不再被静默吞掉，会显示引擎的具体报错，便于进一步定位。
- **Windows 顶栏「目标」按钮与「⋯」按钮挤成竖排** —— 已修（宽度不足时由任务名省略号吸收）。
- **应用内「检查更新」下载报 HTTP 302、更新走不完** —— 已修（下载现在正确跟随重定向，完整性校验不变）。
- **配置写入面**（一轮审计后集中修复）：
  - 在连接器页点一下权限格，会写出引擎判定为**非法**的 config.toml，导致整份配置静默作废、`config/read` 与 `mcpServerStatus/list` 全部硬报错 —— 已改为写引擎真支持的机制（`disabled_tools` 硬阻断 + `[mcp_servers.X.tools.<名>] approval_mode`）。
  - 名字带空格/中文/`@scope` 的**合法** MCP 服务器会被静默删除 —— 已修。
  - 手写的顶层键（如 `approval_policy`）被拼进 MCP 段、引擎读不到；`features` / `otel` / `windows` 等段里用户自己写的子键被整段丢掉 —— 已改为键级保留。
  - 带换行的地址会把整份配置写成非法 TOML —— 已修；数值字段裸插值可被注入任意段（引擎会执行）—— 已强校验。
- **会话面**：导入原生 `.jsonl` 会话后「报成功、看得见、点不开」；设置页「会话记录」占用恒为 0；侧栏标题显示内部编排提示词 —— 均已修。
- **安装包瘦身**：有国内加速源的工具链与浏览器内核全部改为按需下载，安装包体积大幅下降，下载更快。
- **供应商**：新增的模型选不了、每次发送都重启引擎；协议不再被静默改写。
- **阅读体验**：打开会话全白卡死、滚到底全白、消息滚过时闪一下、正文与状态行之间的整行留白、缩放窗口后刻度线变成方块、更早消息与内容顺序错乱 —— 均已修。
- 接力成功后旧会话自动删除（只保留新的）；模型上下文窗口不再被「只对默认模型生效」的全局值覆盖。

## 安装说明

### Windows

下载 `Codex.Harness.Desktop-0.0.18-win-x64.exe` 直接安装。安装包**未做代码签名**，首次运行若出现 SmartScreen「未知发布者」提示：点「更多信息」→「仍要运行」。

### macOS（未签名）

下载对应芯片的 zip，解压后把 App 拖进「应用程序」：

- Apple 芯片（M 系列）：`…-arm64-mac.zip`
- Intel：`…-x64-mac.zip`

首次打开若被 Gatekeeper 拦住：

1. **右键**点 App → 选「打开」（不要双击）；
2. 或在终端执行：`xattr -cr "/Applications/Codex Harness Desktop.app"`。

### 应用内更新

Windows 版可直接在应用内「检查更新」下载并安装。
