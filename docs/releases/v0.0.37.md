# v0.0.37 发版说明

本版主题：语音播报全链路重构（播报稿制）+ 中转站管理能力 + 「轮询」板块
> 版本号说明：0.0.36 为**跳过号**（编号保留未使用），本版直接从 0.0.35 → 0.0.37，不是漏装了版本。

## 一、修了什么 / 新增了什么（按用户感知排序）

### 语音播报（本版最大的一块，整链重构）

- **一个总开关**控制全部播报（原先「实时正文 / 结束汇总」两个开关容易配乱）；
- **播报内容由 Codex 自己写**：运行中念的是它为本轮写的「播报稿」（只装本轮重点），
  不再机械复读全文；旧「怕听不到就写进正文」的约定已删除；
- **自动播报两条硬规则**：单轮工具调用 >10 次、或同一问题返工 ≥2 次时强制念正文——
  长任务不用盯着屏幕等；
- 新工具 `voice_speak_reply`：每段内容是否出声由 Codex 逐条决定；
- **同回合去重改句子级**：同一段内容不再连续播放两次；
- **通话避让**：实时语音通话期间独立播报静音，两个声音不再叠在一起（已钉成守卫）；
- 实时语音通话：只保留一个通话面板并贴输入框居中；外放回声剔除；麦克风默认开增益；
- 修 zipvoice「下载失败却显示已安装」的假状态。

### 中转站账户（自 PPcode 同步回本仓）

- 自动建密钥按「**已生效套餐 → 余额分组**」候选链依次尝试，失败原因不再被吞掉；
- 已建密钥支持**删除**与**切换分组**（三级弹窗、portal 到 body，不再嵌套被裁切）；
- 修登录凭据混入全角字符 / 空白导致的「密码明明对的却报错」。

### 其它

- 对话流新增独立**「轮询」板块**；后台任务胶囊扩展到长命令；
- 开发工具装不上时的**备用方案**：一键复制预置提示词交给 Codex 自己装；
- 品牌文字改**流动渐变**（`:root --brand-ink` 单一渐变源，mac 字体渲染适配）；
- 修宠物「拖不动 / 透明罩挡桌面」：穿透翻转改由主进程光标轮询判定，透明窗默认鼠标穿透；
- 引擎 `clientInfo.version` 改取 `app.getVersion()`，消除版本号漂移（0.0.16 那次排查难的根因）。

## 三、macOS 首次打开（安装包未签名，Gatekeeper 会拦）

1. 把下载的 zip 解压，把 App 拖进「应用程序」；
2. **右键**点 App → 选「打开」（不要双击）；如仍被拦，
3. 打开「终端」，输入 `xattr -cr `（注意后面有个空格），**把 App 图标从「应用程序」拖进终端**
   （路径自动填上，不用手敲），回车。完整命令形如：
   `xattr -cr "/Applications/Codex Harness Desktop.app"`；
4. 若启动报错且错误码含 **640**：那是 Gatekeeper 隔离属性没清干净，重做第 3 步即可。

Apple 芯片（M 系列）请下 `…-arm64-mac.zip`，Intel 请下 `…-x64-mac.zip`。
