# v0.0.25 发版说明

> 发布日期：2026-09-18　|　上一版本：v0.0.23-b（中间无 0.0.24，本版直接跳到 0.0.25）

**macOS 与 Windows 同步发布**。本版主题是**输入框与消息附件的形态统一**，外加两项性能/正确性修复。
随包工具与下载表无变化。

## 输入框：文件与图片统一成内联 chip

- **文件不再挂在输入框上方**，与图片一样以「图标 + 文件名」的 chip 内联在输入框里——
  点主体打开文件、点 × 移除，两种 chip 同高同圆角。原先输入框上方那条方块卡附件条已删除。
- **粘贴超 200 字的纯文本自动转成 `.txt` chip**：不再把长文本铺满输入框。内容按内容哈希落盘，
  同一段文本粘两次得到**同一个文件**；纯空白不会生成文件。
- **`.txt` chip 点开是大窗口，可直接编辑**：显示行数与字数，`Ctrl/Cmd+S` 保存不关窗，
  按 Esc / 点关闭 / 点空白处**自动保存**并提示。
  ⛔ 只有应用自己保存的粘贴文本可编辑——你自己目录里同名的 `.txt` 不会被误改。
- **输入框高度随内容自适应**：下限 48px、上限约 42vh（360px），到上限后在框内滚动，
  不会把上方正文顶出视野。

## 消息里的附件：内联可点、可悬停预览

- **附件内联在正文文字流里**，形态与输入框里粘贴时逐字一致（发送前看到的样子 == 发送后显示的样子）。
- **图片支持悬停小预览**：鼠标移上去立即弹出，横图竖图都按原始宽高比缩放、不变形、不占布局；
  靠近聊天区顶部时自动改从下方弹出，不会被滚动容器切掉。
- **点击开大图**沿用灯箱（滚轮缩放 / 拖拽平移 / 复制图片 / 打开所在位置）。
- 修掉一个真缺陷：**`data:` 形态的图片（粘贴进来的图多是这种）此前打不开预览**——
  它被当成磁盘路径去解析，现在按来源正确分流。
- **agent 查看过的图片（`imageView`）改为随过程折叠**：此前它一张一张常驻铺满消息区，
  现在"查看"算过程、"生成"才算产出（生成图仍常驻）。

## 性能：切会话不再重复做语法高亮

切换会话时消息区整体卸载再挂载，原先**每段代码都要重新高亮一遍**。真机 CPU profile 实测那个
递归建元素的函数单次自耗 **2.2 秒**，且切换耗时几乎正比于会话的 DOM 规模：
六千元素的会话约 0.7 秒、**两万三千元素的会话要 3.6 秒**。

现在高亮结果按内容寻址缓存（同语言+同代码+同主题+同行号设置 → 复用上次算好的元素树），
**再次切回同一会话从 1.9 秒降到 0.15 秒（约 15×）**，外观逐像素不变。
配套：**代码块懒高亮**——没进视口、且折叠在过程组里的大块先渲染等价外观的纯文本，
滚到跟前或展开时才现算（小块直接高亮，不引入颜色变化风险）。

## 会话与回合

- **永久删除会话现在连磁盘记录一起清**：此前引擎只把线程从索引摘掉、磁盘文件还在，
  于是**删掉的会话重启后又冒出来**（真机实测：索引 11 条、磁盘 18 个，其中 12 条"已删但文件还在"）。
  ⚠️ **这是破坏性变更**：删除是**真的删除**磁盘上的会话记录，不再只是隐藏。文件被占用删不掉时会记「墓碑」兜底，同样不会复活。
- **修「编辑消息 → 保存并重新发送 → 消息不见了」**。
- **回合结束说清「为什么停」**：被中断的回合不再显示成「耗时 Xs」；对 GPT 系模型
  「正文给完了但上游迟迟不发结束信号」的情况，如实写「正文已完整，等待模型收尾」，不再假装还在生成。
- 修掉一个会**误伤其它会话**的隐患：图片自愈原先在后台改配置时会**重启引擎**，从而打断所有正在跑的回合；
  现在有回合在跑时直接跳过并提示你（任务跑完再改，或到「设置 → 模型」手动改）。

## 模型与生图

- **生图插件内置热门生图模型参数表**，模型字段补全（Tab 可切换），选择模型时带出对应的参数规格。
- **图片一律正常发送**：移除「按本地元数据预判 → 把图吞掉换成一段说明文字」的降级链路
  （模型其实支持视觉、只是没勾「图片」时，图会被白白吞掉；那段文字还会被模型照抄进你的消息里）。
  真遇到接入点不支持，引擎会明确报错，那时才自动摘掉该模型的图片模态。
- 收尾提示不再同屏重复两次（计时条只报时，收尾状态只由状态行说一次）。

## macOS 说明

- 安装包未签名，首次打开请**右键 → 打开**，或执行
  `xattr -cr "/Applications/Codex Harness Desktop.app"`。
- **发版前 mac 适配审计（对本版自 v0.0.23-b 起的全部新增行）结论：0 处真缺口。**
  - 唯一命中的快捷键写法是 `ctrlKey || metaKey`（**同时支持 Windows 的 Ctrl 与 mac 的 Cmd**，正确）；
  - 其余命中均为**断言夹具里的路径样本**（纯字符串处理，不碰文件系统）与扫描器误报；
  - 已逐行人工复核 `electron/` 全部新增行（路径与文件系统操作）：一律走 `path.join` 与
    `app.getPath("userData")`，无平台硬编码；
  - 渲染层新增行里**没有任何平台分支**（天然跨平台）。
  - ⚠️ 审计过程中发现并修正了扫描脚本自身的缺陷（Windows 绝对路径那条正则对"源码里的转义形态"失效），
    修正后重扫仍为 0 命中；已补人造样本自证扫描器有效，该 0 可信。
- 本版新增的落盘目录（粘贴文本、删除墓碑）都在**应用数据目录**下，**不改变引擎家目录**，
  升级后老会话照旧可见可续聊。
