# v0.0.53 发版说明

本版主题：让 Codex 真正会用你内置的影视源，并把「装/卸工具」这条链路补成闭环。

## 一、修了什么（按用户感知排序）

### 1. Codex 现在能搜片、放片

**现象**：让 Codex 放电影，它回「该会话不是被调度 / 团队会话，无权使用宿主能力网关」。

**根因**：`media_preview` / `media_source_open` 只注册在 `harness-dispatch` 这个 MCP 里，而那条链路有身份硬闸（`delegate-harness-tool.ts:97`），只放行「被委派 / 团队会话」；普通对话会话一个条件都不满足。

**修法**：把影视能力提到宿主 `dynamicTools`（`electron/media-tools.ts`，`thread/start` 注入），新增三个工具：`media_search` / `media_detail` / `media_preview`。身份硬闸**一行没改**，安全边界保留。

### 2. 开发工具支持一键装 / 一键卸

- 面板顶部：一键安装全部 / 一键卸载全部
- 每个分类：本组一键安装 / 本组一键卸载
- **串行执行**（一个装完再下一个，避免同时解压互相踩 staging 目录），带「正在安装 2/5：MinGW」进度与取消按钮，结束汇总「成功 N / M」

### 3. 卸载不再「假成功」

**现象**：点卸载弹「已卸载」，状态仍是「已安装」。

**根因**：删除目标只解析到可写根（`%APPDATA%\…\tools`），而工具实际解在 `resources/tools`，删的是一个不存在的路径。

**修法**：删完**回读判定**——文件还在就如实报错（不再谎报）；pip 包（文档转换）改走 `python -m pip uninstall -y`，能清掉 `dist-packages / dist-info / entry-points`；卸载徽章加百分比进度。

> 打包安装版**不会**去删 `resources/tools`（那是安装目录，删了更新又回来）——该分支仅在开发态启用。

### 4. 用户人格一次填齐

选中一个行业身份后，职业 / 专业领域 / 兴趣爱好 / 生活习惯 / 自我介绍**一起写入**档案（10 个人格各写了一套，不是通用模板）；重进用户中心仍记得选中项；同时打上「引导已完成」标记，登录后不再重复询问。

> 顺带修掉一个长期问题：「专业领域」「自我介绍」在 `UserCenter` 里绑的是 `field` / `bio`，而保存时只提交了 `nickname/occupation/interests/habits` —— 这两栏从来没被存过，所以永远是空的。

### 5. 音色模型装不上（解压失败）

**现象**：`解压失败（随包 Python 不可用，tar: Can't initialize filter; unable to run program "bzip2 -d"），且未找到随包 7z`。

**根因**：Windows 自带 tar 不带 bzip2；而 7z / python 都在**随包根** `resources/tools`，代码却只在自己可写根里找。

**修法**：统一走 `existingToolPath()`（它本来就负责两个根都找）。

### 6. 基础语音模型不再闪「下载模型」

`status` 初值为 `null` 时 `ready` 算作 `false`，卡片先渲染成「未安装 + 下载模型」，与标题的「读取中…」自相矛盾。现在状态没回来之前只显示「读取中…」。

### 7. 办公室预览压住悬浮浮窗

播报收纳图标（`event-broadcast`，`z-index: 880/881`）会盖在办公室预览上。办公室浮层 400 → **890**（高于广播件，仍低于引导 900 / 确认框 950）。

## 三、mac 首次打开自救（带路径）

下载的是 `.zip`，macOS 默认会拦一下。按顺序做：

1. 在「下载」里双击解压，得到 `Codex Harness Desktop.app`；
2. 把它拖进「应用程序」文件夹；
3. 打开「终端」，输入 `xattr -dr com.apple.quarantine ` （**末尾留一个空格**），
   然后把**应用图标直接拖进终端窗口**——路径会自动填好，不用自己找；
4. 回车，再回到「应用程序」双击打开。

若提示 **错误 640**（"没能打开，因为 Apple 无法验证"），说明隔离属性没清干净：重复第 3 步，确认拖入的是「应用程序」里那个图标（不是「下载」里的）。

## 四、已知问题

- **影视播放依赖公网片源**：`media_preview` 已加私网/回环地址拦截，内网片源（NAS 直连）暂不支持；
- **视频卡片的源清单是展示副本**：单一真相源在 `electron/media-sources-core.ts`，界面那四行是静态副本，源变更时需同步（后续改由后端下发）；
- **EmotiVoice 已移除**：其生成器 ONNX 托管地址未配置，下载必失败，本版起不再展示（后端通道保留，配好地址即可恢复）。
