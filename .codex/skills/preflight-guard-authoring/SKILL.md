# 预检守卫编写守则（scripts/guards/*.mjs）

## 何时用
- 要给某条不变量加机器判据（改完代码顺手补守卫）；
- 守卫出现「预检自身异常（断言未跑完）」、或某条断言**一条都没打印**；
- 看到两套同号断言（`【1xx】`）在输出里并存。

## 步骤
1. **查编号占用**（必做，09-23 撞过车）：`resources/tools/rg/rg.exe -o --no-filename "【1[0-9][0-9]】" scripts/guards/` ⇒ 取最大值 +1 起编号。编号全仓唯一，跨文件也算。
2. **选落点**：`scripts/guards/` 下**对应域**的文件（记忆 → `10-memory-audit.mjs`；回合/流 → `07-turn-fold.mjs`；结构 → `09-structural.mjs`…）。⛔ 别往聚合入口 `scripts/check-preflight.mjs` 加断言。
3. **优先写行为断言**（真跑实现），结构断言只作补充。行为断言 = 直接 `import` 产物（`dist-electron/*.js`、`src/lib/*.mjs`）喂样本、比结果。
4. **结构断言的正则先用真实文件实测命中数**，再写进守卫：`node -e "…(readFileSync(f).match(RE)||[]).length"`。09-23 教训：正则漏了一个 `]` 前的反斜杠 ⇒ 四处断言全假红、白跑一轮 build。
5. **产物读不到必须红**：`await import(...).catch((e) => { fail(\`产物读不到：\${e?.message}\`); return null; })`。⛔ 写成 `.catch(() => null)` + `if (mod) {…}` ⇒ 断言一行都不打印、`npm run check` 依旧绿（假绿面）。
6. **别引用块级作用域变量**：`{ let mod = … }` 里的变量出块即不可见；引用它会让**整块**抛「预检自身异常（断言未跑完）」，后面的断言全部不执行。需要时在守卫块里自带引用。
7. **改完必跑** `npm run check`，并**确认新断言逐条出现在输出里**（不是只看"通过"）。

## 坑
- **编号撞车**：09-23 我用了【115】【116】【117】，全被 `07-turn-fold.mjs` 占用 ⇒ 输出里两套同号、定位困难。
- **假红/假绿都源于"没实测"**：结构断言不实测正则 ⇒ 假红；产物 import 静默吞 ⇒ 假绿。两者都白烧一轮构建。
- **断言写对了但没打印**：`(cond ? ok : fail)("消息")` 是对的；写成 `cond ? ok : fail("消息")` 则 cond 为真时**根本不调用 ok** ⇒ 静默漏检。
- **改守卫前先看目标文件 mtime**：本仓多会话并行，几十秒内变过 = 有人在写（等它停）；写回后立刻读回验证。
- **守卫要指向真源**：例 `electron/rollout-worker-source.ts` 是 `scripts/gen-rollout-worker.mjs` 的生成物（build 无条件重写、gitignore）⇒ 断言必须查真源 `electron/rollout-worker.cjs`。

## 判据
- `npm run check` 退出码 0，且新断言的每一条都在输出里出现（数量与预期一致）；
- 编号与全仓既有编号无重复；
- ⛔ **不做反证**（用户 2026-09-19 明令：「把你的反证流程删了，以后不需要再反证了」）：断言写完**直接跑正式那轮**。此前这里要求「故意改坏一次确认变红」，**已作废**。确认断言真的有效的替代办法：**确认它在输出里出现了** —— 写成 `cond ? ok : fail(msg)`（缺外层括号）时它一行都不打印、静默通过，守卫【135】已静态钉死这种形态；
- 产物缺失路径也验证过：临时把 `dist-electron` 改名跑一次，断言应报红而不是静默通过。
